# G3_INDOOR — 闭环：MP3D（10 个 episode × 150 步，5 个场景）

**协议**：与历史 G3 完全相同（FROZEN_PROTOCOL §4）。
- 5 组历史配置直接复用：G0 闭环 10/10 个 episode 逐位复现，重算的 AUC / Final 与报告值一致。
- 7 组新配置用 `da_*` 包装运行，输出完整性检查 0 个异常。
- 统计为场景级配对 bootstrap 95% CI，附胜 / 负；episode 级胜负见 `results/g3_summary.json`。
- **闭环不同配置的轨迹不同，结果只用于评价系统收益，不用于单步归因。**

## 4. 解读（MP3D）
**已证实**（场景级 CI 不含 0）：
- **D100 推理对 D100 训练的 E2D 有益**：E2D\|D100\|S10 − E2D\|S10\|S10，AUC +0.019 [+0.010, +0.035]（5/0），Final +0.061 [+0.020, +0.101]。
- **D100 推理对多训练了 5k S10 的 E2S 有害**：E2S\|D100\|S10 − E2S\|S10\|S10，Final −0.081 [−0.138, −0.020]（1/4）；评分为 D100 时 Final −0.086。
- **同为 D100 推理，E2S 比 B2 差**：AUC −0.017 [−0.032, −0.006]（0/5），Final −0.092。也就是说，继续在 S10 上训练让模型更依赖 S10 输入。
- **B2 换成 D100 推理**：Final +0.061 [+0.014, +0.108]（4/1），AUC +0.012 不显著。
- **D100 评分**在闭环中没有带来室内收益：E2D\|D100\|D100 − E2D\|D100\|S10，Final −0.121 [−0.258, −0.032]（0/5）；B2\|D100 的 Cov@20 −0.016（显著）。固定状态中 D100 评分提高的秩相关（G2_RANKING K2）**没有转化为闭环覆盖**。
- **训练密度与推理密度不匹配时变差**：E2D\|S10\|D100 − E2S\|S10\|D100，AUC −0.037 [−0.058, −0.016]（0/5）。

**趋势**（方向一致，但 CI 含 0）：
- 训练密度与推理密度匹配的两组最好：E2D\|D100\|S10 = 0.3645，E2S\|S10\|S10 = 0.347。两者之差 +0.017 [−0.002, +0.037]（4/1）。
- 室内闭环的偏好是**“训练密度与推理密度一致”**，而不是某一种密度本身更好。

**限制**：5 个场景、10 个 episode、单次运行；多数 AUC 差异的 CI 包含 0。
