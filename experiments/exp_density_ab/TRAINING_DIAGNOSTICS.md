## 1. 判定依据（FROZEN_PROTOCOL §5，四项条件全部满足；证据见 CHECKPOINT_AUDIT §2–§3）
| 条件 | 证据 | 结果 |
|---|---|---|
| 两组 E2 初始化逐位相同 | 两组配置的 init sha 都等于 B2（343f41ab…）；两组 `ema_000000.pt` 与 B2 权重逐张量相等 | ✅ |
| 采样器结构逐位相同 | 417 对训练分片的 t、a、R、T、jitter、block、heldout、k_M、tstar、n_blocks 逐位相同；日志中每步 views / views_indoor 相同 | ✅ |

| 主终点固定在 5k | `e2_pilot/protocol.md:50`：两组都固定为 EMA@5k，不做选择 | ✅ |

**因此**：历史 E2-S10 / E2-D100 已经构成用户要求的严格 5k 配对（FT-S10 / FT-D100）。按同样设置重训只会逐位重复，没有信息增量。

**这对配对不能回答的问题**（只能靠新训练，见 NEXT_TRAINING_RECOMMENDATION）：
1. 种子方差：每组只有 1 个种子。
2. 从零开始（而不是从 S10 预训练的 B2 微调）时，训练密度的作用。
3. “输入密度”和“监督集合”各自的贡献。在 E2 中两者是一起变化的：D100 训练同时改变了输入 BAND 和哪些射线算 UNKNOWN、b / y 标签。

## 2. 历史训练诊断（只读，来自 `e2/training/{s10,d100}/eval.jsonl` 与 `log.jsonl`）
验证集为 MP3D VALSEL（in_val）和 Macarons++ S-c（out_sc），每个 arm 都在**自己密度的标签**上评估。所以两个 arm 的绝对值不能互比，只能看各自随训练的变化。

| step | E2-S10：FM in_val / out_sc | E2-S10：ES in / out（体素） | E2-D100：FM in_val / out_sc | E2-D100：ES in / out | E2-D100：预测命中率 / 标签命中率（in） |
|---|---|---|---|---|---|
| 0（= B2 权重） | 0.1876 / 0.0749 | 5.996 / 3.150 | 0.1063 / 0.0211 | 7.287 / 3.435 | 0.307 / 0.262 |
| 1000 | 0.1874 / 0.0748 | 6.011 / 3.153 | 0.0913 / 0.0180 | 6.598 / 3.280 | 0.280 / 0.262 |
| 3000 | 0.1870 / 0.0748 | 6.080 / 3.170 | 0.0871 / 0.0172 | 6.378 / 3.229 | 0.272 / 0.262 |
| 5000 | 0.1866 / 0.0747 | 6.094 / 3.173 | 0.0865 / 0.0171 | 6.363 / 3.224 | 0.270 / 0.262 |

**已证实**：
1. **E2-S10 的继续训练在 S10 验证集上几乎没有变化**：FM −0.5%（室内）/ −0.3%（室外）；ES 反而略变差，5.996 → 6.094、3.150 → 3.173。说明 B2 在 S10 目标上已经基本收敛，这 5k 步基本是低学习率（2e-5）下的扰动。
2. **B2 权重直接用 D100 输入和 D100 标签评估（E2-D100 step 0）时明显失配**：
   - 室内预测命中率 0.307，标签命中率 0.262，**过度预测命中 17%**；室外 0.141 vs 0.133，**过度预测 6%**。
   - E2-D100 训练后，室内过度预测降到 3%，室外降到 2%。
   - ES 室内 7.29 → 6.36（−12.7%），室外 3.44 → 3.22（−6.1%）。**室内的失配和修复幅度都约为室外的两倍。**
3. 这与监督集合的差异方向一致（CHECKPOINT_AUDIT §4）：S10 标签中约一半的 HIT 在 D100 下已经是已观测表面，所以 S10 训练出的模型在 D100 输入下仍倾向于“预测命中”。

**仍是假设**：G3 上 E2-S10 相对 B0 的提升（MP3D +0.025）是否真的来自“多训练”。按上表，E2-S10 的预测指标几乎没有变化，这个闭环差异也可能主要是闭环噪声。固定状态 K5（E2S − B2）用于检验这一点，见 G1_PREDICTION / G2_RANKING。
