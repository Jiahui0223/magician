## 4. S10 与 D100 的监督集合差异（逐射线，全部训练分片）
**监督掩码**与训练代码完全相同：`lmask = (cls == UNKNOWN) & (b ≠ 0)`（`task1/v2_data.py`、`task2/t22_data.py`）。
- b = +1 为 HIT；b = −1 为 NOHIT 或“首个 GT 命中已在已知区”。

| 指标（单位：射线；室内 = MP3D train 228 条轨迹，263,358 views；室外 = Train-6 去 S-c 138 条轨迹，98,887 views） | 室内 train | 室外 train |
|---|---|---|
| S10 有监督射线 | 855.3M（占全部射线 44.5%） | 207.6M（28.8%） |
| D100 有监督射线 | 516.0M（26.9%），**−39.7%** | 166.4M（23.1%），**−19.9%** |
| 两者都监督 | 502.4M | 164.6M |
| 只有 S10 监督（D100 下已知或为空） | 352.9M，占 S10 监督的 41.3% | 43.1M，占 20.7% |
| 其中 D100 下变为 KNOWN | 302.7M | 40.6M |
| 只有 D100 监督 | 13.6M，占 D100 监督的 2.6% | 1.8M，占 1.1% |
| S10 的 HIT 目标 | 498.8M（占 S10 监督的 58.3%） | 69.9M（33.7%） |
| D100 的 HIT 目标 | 127.5M（24.7%），**−74.4%** | 24.1M（14.5%），**−65.6%** |
| S10 HIT 中，D100 下已不再监督的 | 279.0M，**占 S10 HIT 的 55.9%** | 33.5M，**占 48.0%** |
| 两者都监督时 HIT → NOHIT/KNOWN | 92.5M（占共同监督的 18.4%） | 12.3M（7.5%） |
| 两者都监督时 NOHIT → HIT | 0.09M | 0.01M |
| 共同监督射线的 b 标签一致率 | 81.6% | 92.5% |
| 共同 HIT 射线的 \|Δy\| 均值（y 是在 UNKNOWN 采样中的分位，两张图的分位基准不同） | 0.124 | 0.064 |
| 粗网格 BAND 占比（domain 内格均值，全部分片） | 0.0081 → 0.0182（×2.2） | 0.0051 → 0.0106（×2.1） |
| 粗网格 EMPTY 占比 | 0.405 → 0.402 | 0.345 → 0.343 |

held-out 集合（MP3D VALSEL 9 条轨迹、Macarons++ S-c 42 条轨迹）方向相同：
- 室内：S10 HIT 中有 57% 在 D100 下不再监督，HIT 目标减少 77%；
- 室外：S10 HIT 中有 42% 不再监督，HIT 目标减少 61%。

**由此确认的事实**：
1. **S10 训练的 HIT 监督中，约一半（室内 56%、室外 48%）是 D100 地图里已经观测到的表面。** 也就是说，S10 地图的 BAND 是“多孔”的（与 memory 中 P1 porous 的记录一致），模型在 S10 上学到的“补全”，有很大一部分是在**重新预测已经观测过、但被稀疏 BAND 漏掉的表面**。
2. **D100 训练的 HIT 目标只剩 S10 的约 1/4（室内）到 1/3（室外）**，并且集中在真正未观测的区域。监督集合的变化在室内远大于室外：有监督射线 −40% vs −20%，共同射线的标签一致率 82% vs 93%。
3. 两种训练的输入差异是粗网格 BAND 占比约 ×2.1–2.2。T3_E1_GEOMETRY 报告的室内 ×2.2、室外 ×1.6 是在闭环状态上测的，这里是全部训练分片，两者分母不同。

E2 的训练损失因此不可比：最后 50 步均值 E2-S10 0.130，E2-D100 0.049。每步有监督射线（rank 0 日志均值）：

| | 室内 | 室外 |
|---|---|---|
| E2-S10 | 29.9k | 17.2k |
| E2-D100 | 16.6k | 12.9k |

E2-D100 损失中室内的权重因此从 0.63 降到 0.56。

## 6. B0 与 B2 是否共享同一权重（已证实）
- 历史 Task 3 的 B0、B1、B2 三组闭环都没有设置 `T3_CKPT`，使用 Task 2 V2M 组的 checkpoint（`eval_indoor_v1.json`，sha 343f41ab… = B2）。
- 规划器日志记录的 P1 模式分别是：
  - B0：Task 2 原始运行，sparse；
  - B1：full；
  - B2：b2。
- E2S、E2D 的日志分别记录了 `T3_CKPT=…/s10/ema_005000.pt`（模式 sparse）和 `T3_CKPT=…/d100/ema_005000.pt`（模式 b2）。
- **结论**：B0、B1、B2 是同一模型，只有推理和评分的 P1 不同；它们对应矩阵中 B2 checkpoint 的 S10/S10、D100/D100、D100/S10 三格。
