## 2. 问题逐条回答

### Q1 从 B0 直接换成 Geometry Query 后，AUC@20、AUC@100、Final 变了多少？——**基本不变，Final 略降。**
| 范围 | ΔAUC@20 | ΔAUC@100 | ΔFinal |
|---|---|---|---|
| Dev-3（15 ep），F1-B@5k − B0 | +0.012 [−0.028, +0.040] 2/1 | −0.003 [−0.008, +0.006] 1/2 | **−0.012 [−0.026, −0.002] 0/3 ✱** |
| Pilot（6 ep），F1-B@5k − B0 | +0.042 [−0.000, +0.076] 2/1 | +0.006 | −0.024 |
| All-14（Table 1），F1-GQ@5k − B0 | −0.001 [−0.014, +0.013] 7/7 | −0.003 [−0.018, +0.010] 7/7 | −0.009 [−0.033, +0.012] 4/10 |
| Dev+Test（8 个非训练场景） | −0.002 | −0.005 | −0.011 |

- Pilot 中的 +0.042 AUC@20 扩到 15 个 episode 后降为 +0.012，在 All-14 上为 −0.001。**小样本 Pilot 的早期优势没有保持下来。**

### Q2 相对同预算的 B0-Continue，Query 有没有独立贡献？——**同为 5k 步时 Dev-3 上有，但主要来自对照分支变差；对 B0 没有净增益。**
- **Dev-3，F1-B@5k − F1-A@5k**：AUC@20 +0.023 [−0.004, +0.048] 2/1；**AUC@100 +0.023 [+0.011, +0.034] 3/0 ✱**；Final +0.025 [−0.011, +0.076] 2/1。单调口径同样是 AUC@100 +0.025 ✱。
- **2k 时**：F1-B@2k − F1-A@2k 为 −0.007 / +0.005 / +0.034，都不显著。
- **原因在对照分支**：F1-A 只用室外 S10 数据续训后**单调变差**。
  - F1-A@5k − B0：AUC@100 −0.026 [−0.042, −0.005] 0/3 ✱；
  - F1-A@5k − F1-A@2k：AUC@20 −0.014 ✱，AUC@100 −0.016 ✱。
  - F1-B@5k 基本保持在 B0 的水平。
  - 所以“Query 比 Continue 好”主要是 F1-B 没有像 F1-A 那样退化，而不是 Query 超过了父模型。
- **All-14 上两个选定 checkpoint 的比较**（F1-GQ@5k − F1-CONT@2k，不同步数）：+0.008 / +0.004 / +0.002，都不显著。Test-3 的 AUC@100 +0.018 [+0.009, +0.034] 3/0 ✱，但只有 3 个场景。
- **注意**：F1-A 与 F1-B 的优化路径不同（F1-B 的继承参数只训练 3k 步，并有冻结阶段），这是系统级配对，不是纯架构消融。

### Q3 G1 的几何预测改善是否与 G2 的真实选点收益一致？哪些错误在限制性能？——**几何预测没有改善；G1 / G2 与闭环排序不一致。**
- **G1 深度**（pooled，全部状态）：所有微调模型的 unknown 射线 MAE 都比 B0 差。
  - B0 2.618；A2k 2.660；A5k 2.733；B2k 2.685；B5k 2.735。
  - B5k − B0 +0.117 [+0.058, +0.160] 3/0；
  - F1-B 与 F1-A 在相同步数上几乎相等（B5k − A5k +0.001）。
- **G1 命中 / 无命中**：Query 的主要可测效应在这里。
  - F1-B 的无命中校准比 F1-A 更接近 B0：UNKNOWN 射线 Brier B0 0.102、B2k 0.106、B5k 0.108、A2k 0.119、A5k 0.122；
  - 假无命中率：B0 0.117、F1-B 0.121、F1-A 0.13 左右；
  - 命中一致率：B5k − A5k +0.006 [+0.002, +0.011] 3/0。
  - 也就是说，F1-A 续训后更倾向于把有命中的未知射线预测为无命中，F1-B 较少这样。
- **G2**：没有模型在全部状态上超过 B0。
  - 一步增益（pp）：B0 1.275、B2k 1.290、B5k 1.206、A5k 1.206、A2k 1.176；
  - 早期（t ≤ 20）：B2k 2.531 是最高的，B0 2.488；
  - B5k − A5k 的 G2 增益为 −0.001 pp。
  - G2 的排序（B2k 最好）与 G3 的排序（B5k 的 AUC@20 最高、B2k 的 Cov@20 最低）**不一致**：固定状态的一步指标不能预测闭环的早期排序。
- **主要误差来源**：
  - unknown ∩ new 射线的深度误差（5.4–5.9）远大于 known 射线（1.8–1.9）；
  - 未知射线上的假无命中率约 12–15%。
  - Query 没有降低前者，只是在后者上没有像 Continue 那样变差。

### Q4 哪些场景或起点有收益、哪些退化？前 20 步与 20–100 步有什么不同？
- **Dev-3**（AUC@20 / AUC@100 / Final，起点均值）：

- **曲线形状**（`figures/coverage_curve_0_20.png`、`coverage_curve_0_100.png`）：

  - 20 步以后 F1-A@5k 一直最低，F1-B@5k 与 B0 接近，100 步时 Final 略低。

### Q5 与历史 V5 相比，去掉 L_surf / L_bridge 后趋势是否不同？（训练条件不同，谨慎归因）
- **同一 Dev-3 的 15 个 episode**（Table 1 记录）：V5 − V4C 为 −0.004 / +0.005 / +0.012；F1-B@5k − F1-A@5k 为 +0.023 / +0.023 / +0.025。
- **All-14**：V5 − V4C 为 −0.008 / −0.006 / +0.000；F1-GQ@5k − F1-CONT@2k 为 +0.008 / +0.004 / +0.002。
- **差别主要来自续训对照本身**：历史上 V4C 相对 V4 是变好的（Dev-3：+0.011 / +0.010 / +0.013），而 F1-A 相对 B0 是变差的。
- 两边的 Query 模型相对各自的父模型都接近 0：V5 在 Dev-3 上为 0.393 / 0.717 / 0.864，F1-B@5k 为 0.393 / 0.714 / 0.842。
- 两者还有父模型（V4 vs B0）、推理密度（D100 vs S10）、步数（12k vs 5k）的差异，**不能把差别归因于去掉 L_surf / L_bridge**。

### Q6 Query 的代价是多少？——**很小。**
- **参数**：+166,533（+0.67%）；条件模块 76,224 → 242,757。
- **每步决策时间**：0.541 → 0.588 s（×1.09；barts_s0，独占一张 L40）。
- **规划器峰值显存**（barts）：3.23 → 2.42 GB。
- **训练**：78 min vs 49 min（同为 5k 步、4 × L40）。
- **dunnottar**：同卡并行时 F1-GQ 与 F1-CONT 都出现过 OOM，自动重试后成功。

### Q7 下一步：保留、简化、调整什么？只推荐**一个**两天内最值得做的实验
- **保留**：Query 实现与 F1 流水线。成本小，比同步数的 Continue 更稳健：无命中校准更好，闭环中没有出现 Continue 那样的退化。
- **不要做**：继续只用室外数据续训 B0（F1-A 已证明有害），或为追小幅波动去改 Query 配置。
- **唯一推荐：F1-B-Mix**。
  - 做法：用 B0 原来的**混合数据配方**（MP3D + 室外，32 + 32，S10）做同样的 5k 步 Query 适配；
  - 对照：直接用**现成的 E2-S10**（B0 + 5k 混合 S10 续训，已经在 Table 1 登记：0.394 / 0.747 / 0.895）作为同预算对照，不必再训练对照分支；
  - 好处：去掉了让 F1-A 退化的数据域变化，Query 的独立贡献可以直接与 E2-S10 配对；
  - 成本：约 1.5 h 训练加 1 h 评估。
