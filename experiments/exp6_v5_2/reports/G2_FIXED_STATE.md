## 4. 结论
- 直接几何可见评分（λ = 0）在 MP3D 的早期选点上有收益（early 增益 1.36 vs V5 1.11），全部状态的增益与 V4C 持平、略高于 V5（CI 含 0），但 Top-1 与 Spearman 明显更差；在 Macarons++ 上全面低于 V5 / V4C / B2 / E2-D100（增益 −0.24 pp，CI 不含 0）。
- Potential（λ = 0.1）在归一化后只占被选候选总分的约 8 %，几乎不改变选择（MP3D 0 次、Macarons++ 1.8 % 的状态），没有可分辨的作用。
- 原因线索：首中头在评估场景泛化差（G1：众数误差 55–104 vox，UNKNOWN 区域过度自信地预测无命中），评分只能看到模型认为"有表面"的地方；V5 的 Flow 采样 + DistP1 在同样的场景上排序更好。
- 预注册放行规则 (a)（某 λ 的 G2 增益在某一域 ≥ 0.9 × V5）在 MP3D 上满足（0.565 ≥ 0.437），因此按协议进入全量 G3。
