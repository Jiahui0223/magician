# EXP6 V3 Ablation Summary — Experiment A（GT-Depth Oracle Decomposition）与 Experiment B（Depth Uncertainty Planner）

> 状态：**COMPLETED**（2026-10-31 09:30–10:45）。协议 `../protocol.md` v1.0（09:55 冻结，运行前）；偏差 `V3_ABLATION_DEVIATIONS.md`（#1）；资源 `V3_ABLATION_RESOURCES.md`；统一表格 `V3_ABLATION_COMPARISON_TABLES.md`（表 1–7）；逐状态 / 逐候选数据 `experiment_*/results/*.csv`、`*_summary.json`；图 `experiment_*/figures/`。不训练、不改模型、不启动 V4；所有数字来自真实运行；Test-3 非盲，诊断均为 exploratory。

## 1. 一句话结论
- **Experiment A**：室内（MP3D）一步选点的错误**主要不是预测**——所有学习模型（B2 / E2D / T0 / T1）的一步 regret 相同（0.11–0.12 pp），完美未来深度也只能降到 0.064，即约 57% 的 regret 来自 DistP1 评分 / 规划区域 / 候选空间；MP3D 中期停滞是**候选空间 / 视野限制**（合法候选的最优增益中位数仅 0.019 pp），不是预测或评分错误。室外（Macarons++）**预测误差占主导**（B2 的 regret 66% 可归因预测），V3 把它减半（T1 0.319 vs B2 0.468 pp，GTD 上限 0.160），但这一改善**没有兑现到闭环**（G3 AUC T1 0.712 vs B2 0.730）。
- **Experiment B**：用同一候选 K = 4 样本的预测分歧选点（DepthU）**无效**：单独使用使 regret 恶化 65–200%；与 DistP1 归一化融合（λ = 1）在两个数据集的 dev 集上中性或更差；预注册 Gate 8 / 8 组合 FAIL，不进入 G3。唯一的正信号（T1、Macarons++、λ = 0.5：−0.023 pp [−0.051, −0.001]）属于敏感性设置，量级仅 P0 的 7%。

## 2. 做了什么（复用与新算）
- 固定状态池：**Pool CL** = EXP5 A1 / A2 的 1,461 个 Task 2 闭环状态（MP3D 368、Macarons++ 1,093；来源 V2O / V2M / MAG-G / MAG-B 轨迹）；**Pool FX** = EXP6 G2 的 365 个状态（VALSEL 90、Dev-3 B2 层 125；Dev-3 B0 层 150 ⊂ CL 作回归）。oracle 增益、GT 深度 t\*、GTD、V2O / V2M 原始样本 100% 逐位复用（`CACHE_REUSE_AUDIT.md`）。
- 新算：B2 / E2-D100 / V3-T0 / V3-T1 在 1,676 个状态上的 D100 输入 K=4 预测（原始样本保存）与稀疏 DistP1，同一噪声种子与历史样本配对；FX 的 GTD。8 × L40S，36 min ≈ **4.8 GPU-h**；总成本（含分析）≈ 5 GPU-h，0 训练。
- 校验（`A_G0_VALIDATION.md`）：1,460 次与 EXP6 / E2 行的回归 **1,460 / 1,460 数值等同**（1,427 逐位，33 个差 ≤ 7e-12 的 GPU float64 求和噪声——同时解释了 EXP6 偏差 #10 的根因）；GTD 与 EXP5 1,461 / 1,461 数值等同；`legal_idx` 一致；GT 在规划侧分数之后读取；单测 5 passed。

**拆分 Δ = r_pred − r_gt（换成完美深度的净收益）**：MP3D Δ/r_pred = 0.42–0.47（B2 0.047 [0.024, 0.068] pp）；Macarons++ B2 0.66（0.308 [0.128, 0.555] pp）→ T1 0.50（0.159 [0.094, 0.209] pp）。选错状态里"GTD 也选错"（评分 / 候选可归因）MP3D 26–28%、Macarons++ 24–25%；"GTD 选对"（预测可归因）MP3D 15–18%、Macarons++ B2 21% → T1 17%。

**室内 / 室外分别的主导因素**
- **MP3D**：评分 / 区域 / 候选占主导。T1 − B2 +0.002 [−0.014, 0.026]，T1 − T0 +0.001；GTD − B2 −0.047（5/0 楼层）。Early 相位占 regret 的大部分（B2 0.206 / mid 0.096 / late 0.044；GTD early 仍 0.117）。**中期停滞**（53 / 368 状态，41 个来自 MAGICIAN 轨迹）：66% 有正收益合法候选，但 G\* 中位数 0.019 pp（非停滞 0.65 pp），各模型停滞态 regret 0.02–0.05 pp、Top-1 0.67–0.69，选中候选 78.5% 就是区域内最优（GTD 88%）；oracle 最优候选 31% 的增益在规划区域外，未覆盖表面只有 27% 在区域内 → 停滞时**该合法集合里几乎无事可做**，根因是候选 / 视野限制（与 T0.12-C 一致）。
- **Macarons++**：预测占主导（V2 族 66%），V3 的 3D latent 表示把预测可归因 regret 减半并接近 GTD 上限（T1 0.319 vs 0.160）；逐场景 T1 − B2：alhambra −0.339、barts −0.692、neuschwanstein −0.030、bridge +0.003、pantheon +0.011、**colosseum +0.152**（CI 含 0：−0.149 [−0.400, 0.049]）。高 regret（≥ 0.5 pp）状态 B2 20% / T1 16%，几乎全在 early / mid；其中 GTD 也选错的 43% / 52%，GTD 在这些状态平均 regret 0.49 / 0.61 pp；被选候选新表面 86–89% 与评估相关（虚假 / 无关表面不是主因；距离权重与 P1 空洞的作用见 EXP5 A1 的历史诊断）。Test-3 / Dev-3 一致（T1 0.272 / 0.366 vs B2 0.394 / 0.543）。
- **一步 vs 闭环**（表 7）：Macarons++ 上 T1 一步 regret 比 B2 低 32%、Top-1 +0.035，闭环 AUC 却 0.712 vs 0.730；MP3D 上一步全部相同，闭环 T0 0.311 / T1 0.331 / B2 0.334 / E2D 0.364。**一步排序质量已不是闭环差异的来源**；E2-D100 在固定状态上并不比 B2 好（MP3D 0.122、Macarons++ 0.505）却是 MP3D 闭环最佳，说明闭环结果受规划动态（候选集演化、停滞、重访）支配。

**失败案例**（`A_FAILURE_CASES.md`，自动规则）：预测失败典型 = 早期大场景起点（barts s2 t=5：B2 选候选 1 增益 1.8 pp，oracle 最优 18.1 pp，GTD 选对）；评分失败典型 = GTD 与模型选同一候选但 oracle 最优在别处（TbHJ s112 t=0：G\* 4.62，GTD / B2 / T1 都拿 2.05）；停滞案例 TbHJ s112 t=105：G\* 1.18，T1 选 0.33、B2 / GTD 选对。

## 5. 对下一版架构（V4）的证据与建议（建议，Scratch vs Warm-start 由你另行决定）
1. **室内的收益上限在规划侧，不在预测侧**：完美深度只能把 MP3D 一步 regret 从 0.11 降到 0.064；停滞态几乎无合法收益可拿。任何只改预测网络（3D U-Net、Cross-Attention、更多 K）的 V4，在 MP3D 上的一步收益上限约 0.05 pp，且不触及停滞。**优先级最高的实验是规划侧的 counterfactual**：用已有 oracle（`cand_pts`、区域内外增益）离线评估"整层 / 扩大区域候选"、"超出区域的收益估计"、"多步前瞻"，这些可在同一批固定状态上零训练完成。
2. **室外预测仍有空间，但兑现需要闭环证据**：V3 的 3D latent（VAE μ + Ray Encoder）相对 V2 的粗网格条件，在室外固定状态上有大而一致的收益（barts / alhambra），说明**3D 场景表示本身有用**；但 T1 − T0（Cross-Attention）在固定状态上 ≈ 0（MP3D +0.001，Macarons++ +0.011 [−0.004, 0.028]，VALSEL −0.014），其 EXP6 G3 的小增量不来自一步排序。若做 V4，3D U-Net 式的更强 3D 表示比再加一处 Cross-Attention 更有证据支持；但必须以 G3 闭环而不是固定状态作为验收，因为两者在本轮明显脱节。
3. **不要在评分器里用预测分歧**（Experiment B 阴性）；K = 4 的价值仍只是选点稳定性（EXP5 K 消融）。
4. **Scratch vs Warm-start 的事实**：从零 V3（65 GPU-h）在固定状态上 ≥ B2，闭环 ≈ B2；warm-start 的 E2-D100 固定状态 ≤ B2 却闭环最佳（MP3D）。两种评价不一致 → 这个决定不能由固定状态数据给出，需要你结合预算与风险判断；若选 warm-start，建议从 B2（V2-Mix）出发并保留 D100 输入 / 稀疏打分。
5. **室外高 regret 的下一步**：早期（t ≤ 15）大场景起点占绝大多数，GTD 也错的占一半 → 一半是评分 / 候选问题；EXP5 A1 的历史诊断指向 P1 空洞与评估无关表面；可在同一状态上离线试"评估相关表面"的计分 counterfactual（需另留场景验证，防按指标调参）。

## 6. 局限与偏差
- 场景数少（MP3D 5 楼层、Macarons++ 6 场景），CI 宽；Test-3 非盲；状态池来自特定策略的轨迹（CL 含 MAGICIAN 轨迹的停滞态）；一步 oracle 不等于长期价值；B 的 α / λ 只用冻结值与两个敏感性值；B 未跑任何闭环。
- 偏差 #1：回归比对改为"数值等同（相对 ≤ 1e-9 且 argmax 相同）"，原因是 GPU float64 归约顺序（EXP6 #10 同根因）；不影响任何指标。
- 成本：≈ 4.8 GPU-h（打分）+ CPU 分析；无训练；gpu117 / gpu115 的既有分配，未新申请。
