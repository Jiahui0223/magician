# Experiment U — Generative Disagreement for NBV：最终报告

2026-11-13 · 协议 U-v1（`configs/u_config.yaml`，sha256 `8a62ffec…`）· 任务书 `TASK_BOOK.md` · 过程文件 `reports/U0_PIPELINE_AUDIT.md`（审计与冻结设计）、`reports/U1_FIXED_STATE_ANALYSIS.md`（固定状态诊断）

## 结论先行
- **分歧不是更好的探索信号**。在同一个 V3-T0@40K、同一组 K = 4 假设、同一模拟器和候选集下，只把打分从“预期新增覆盖”换成“假设间分歧”：
  - 三个分歧策略在 All-14 的每一个场景、每一个指标上都低于同为一步前瞻的覆盖策略 C1。唯一例外是 U2 的 Final 在 2 个场景高于 C1。
  - 差距从**第 1 步**就出现，并在前 20 步内持续扩大，所以“分歧在前 20 步更有效”的假设被否定。
- 最好的分歧策略 U2（预注册的 U-best）：All-14 AUC@20 / AUC@100 / Final = 0.258 / 0.571 / 0.780。
  - C1 为 0.399 / 0.740 / 0.889，差 −0.141 / −0.168 / −0.109，三个 CI 都不含 0。
  - D1 为 0.420 / 0.763 / 0.911。
  - U2 高于 Table 1 的 Random Walk（0.144 / 0.353 / 0.517），14/14 个场景。
  - U1、U3 只比 Random 略好：U3 在 Test-3 的 AUC@20 甚至低于 Random。
- **固定状态诊断事先预测了闭环结果**。755 个固定状态上，各打分所选候选的官方一步增益排序与闭环 AUC@100 的排序完全一致：
  - 固定状态：C1 1.116 > U2 0.704 > U3 0.582 ≈ U1 0.568 > 随机 0.477；
  - 闭环 AUC@100：C1 0.740 > U2 0.571 > U1 0.438 ≈ U3 0.424 > Random 0.353；
  - 固定状态上三个 U 相对 C1 都是 0/10 个场景更好，闭环是 0/14。
- **原因（数据支持）**：
  - 分歧的主体是互相矛盾的推测表面。U3 的分歧质量只有 7.6% 落在含真实未知表面的单元里；U1 只有 36% 落在真实表面确实位于未知段的射线上。
  - 按支持大小归一化的分歧，会偏向“未知区域很小、却有几条射线互相矛盾”的视角。闭环中 44–52% 的选择只有不到 100 条参与 U2 计算的射线（≥ 2 个样本命中）。
  - 保留规模的版本则退化为覆盖面积的代理，不提供新信号。
- **术语约束**：本文所说的“分歧”是 K = 4 个生成首次命中深度假设之间的经验差异，**不是经过校准的信息增益**。V3-T0 生成的是视角条件化的首次命中深度假设，**不是完整三维场景**。

## 1. 实验目的与研究假设
- 教授提出的假设：对同一部分地图和候选相机，模型生成 K = 4 个可能的未来几何观测；假设之间差异越大，说明该视角下未知几何的预测歧义越大，真实观测越可能消除歧义。因此“最大化生成假设之间的分歧”可能比“最大化预期覆盖”更有效，尤其在前 20 步。
- 检验问题（任务书 §0）：Does maximizing disagreement among generated future surface hypotheses improve active mapping efficiency compared with coverage-driven planning?
- 受控设计（任务书 §4）：
  - D1 是两步前瞻，不能直接和一步的分歧策略比；
  - 因此加入同为一步的覆盖策略 C1，主比较是 **U-best vs C1**（相同前瞻深度）；
  - D1 作为主系统参照。

## 2. V3-T0 实际生成什么
- 对每个候选位姿的 7,296 条打分射线，V3-T0（3D VAE 编码器 → 潜变量射线编码器 → 2D 条件整流流 U-Net，Euler 10 步）为每条“UNKNOWN 射线”生成 `(b̂, ŷ)`。
  - UNKNOWN 射线指：在当前部分 TSDF 中，射线在已知表面之前穿过未知体素。
  - `b̂ > 0 ∧ ŷ < 1` 表示该样本在未知段上生成了一个表面；`ŷ` 是该表面在这条射线未知弧长上的相对位置。
- 解码（`seen2scene/futureview/geometry.py: decode`）把它变成首次命中距离 `t`。非 UNKNOWN 射线或无命中的样本，取已知表面 `t_known` 或无穷远。
- K = 4 个样本共用 4 张图像空间噪声图，所有候选共享同一组噪声（公共随机数）。
- 所以模型输出是“**每个视角各自的 4 张首次命中深度图**”，没有跨视角一致的三维场景。Phase D 实测：同一噪声编号在两个相邻视角之间的单元一致度只比不同编号高 10%（0.349 vs 0.318）。
- 本文的全部分歧都在这些深度及其反投影点上计算。

## 3. 分歧指标：数学定义与代码
冻结于 `configs/u_config.yaml: metrics`（写入时间早于任何 Experiment U 的模型运行）。实现在 `scripts/u_metrics.py: view_metrics`（规划器和离线分析共用同一函数）。

| 符号 | 定义 | 代码 |
|---|---|---|
| R_c | `n_u > 0 且 valid` 的射线：在 `t_known` 前、量程内、网格与定义域内至少穿过一个 UNKNOWN 样本；补齐射线、无效射线、纯已知或纯空射线都不计入 | `u_metrics.ray_set` |
| h_r^(k) | `hit_u[k, r] = (b̂ > 0) ∧ (ŷ < 1) ∧ (n_u > 0)`（解码器的实际规则；命中已知表面不算） | `geometry.decode` 的 `hit_u` |
| **U1** 命中分歧 | `(1/|R_c|) Σ_{r∈R_c} 4 p_r (1 − p_r)`，`p_r = mean_k h_r^(k)`；`|R_c| = 0 → 0` | `view_metrics` U1 段 |
| **U2** 深度分歧 | 只用 ≥ 2 个样本命中的射线 `R2_c`：`(1/|R2_c|) Σ Var_{ddof=1}{ t_r^(k)·k_M : h_r^(k) = 1 }`。单位为运行时单位²（官方覆盖单位），等于同一射线上反投影三维点的方差；无命中样本不参与；`|R2_c| = 0 → 0` | `view_metrics` U2 段 |
| U2-rel（**仅离线诊断**） | 同上，改用未知弧长坐标 `s = clamp((ŷ+1)/2, 0, 1−1e−6)` | 同上，`diag=True` |
| **U3** 几何分歧 | `S_c^(k)` = 样本 k 在 R_c 上的生成命中点 `o + t^(k) d`，转到运行时坐标后落入的 1.0 单元格集合（与 D1 的 `h_policy.value_cov` 同一网格和键；只含生成的未知表面）；`V_c = ∪_k S_c^(k)`，`p_v = (1/K) Σ_k 1[v ∈ S_c^(k)]`；**`U3 = (1/|V_c|) Σ_{v∈V_c} 4 p_v (1 − p_v)`**（归一化规则冻结为对并集求平均）；`|V_c| = 0 → 0` | `view_metrics` U3 段，`u_metrics.cell_keys` |
| C1 一步覆盖 | D1 的单样本价值 `h_policy.value_cov`（距已观测点 > 1.0 的新单元、1.0 单元格、权重 w(z)）对 K 个样本求和后取平均 | 冻结 `d_policy.score_state` 的 `s_one` |
| U4 两步分歧 | **未定义**：预注册检验没有通过（§5.3） | `u_metrics.overlap_agreement`（只用于检验） |

**规划器适配层**（`scripts/u_policy.py: install`）：
- 原样导入冻结的 `d_policy.py`，把前瞻换成一步（与 Table 3 的 `kd_policy._lookahead_depth1` 相同，不预测任何第二层视角）。
- 外层包一层 `score_state`：用**同一批** V3 预测（`keep_hits=True`）算 U1–U3，再把所选指标写进 `out["distp1"]`。
- `m_score.choose` 不变：argmax，并列取最小下标，全 0 时用种子化随机回退。
- 每步把 `u_c1 / u_u1 / u_u2 / u_u3 / u_metrics` 全部写进规划器日志。
- 闭环入口：`scripts/sim_out_u.py → u_out_planner.py`；官方覆盖回放：`scripts/u_out_cov.py`（`t25_out_cov` 原样调用）。

### 5.2 任务书 §5 的六个问题（要点）
1. **能否区分候选**：U1 / U2 能拉开差距，但与增益的状态内相关很低（0.09 / 0.31，C1 0.44）。U3 几乎不能区分：状态内变异系数中位数只有 0.10，值集中在 0.63–0.82，因为大多数单元只被 1–2 个假设命中。
2. **是否几乎全为 0**：否。候选为 0 的比例 16–21%，整状态全为 0 的比例 4–7%。
3. **是否来自噪声 / 伪表面**（离线 GT 归因，5,355 个候选）：
   - U1 只有 36% 落在真实表面确实位于未知段的射线上，36% 来自“4 个样本只有 1 个命中”的射线；
   - U3 只有 7.6% 落在含真实未知表面的单元；
   - U2 有 77% 在真实表面射线上，且离散度与深度误差相关（0.46），但随距离变大（0.44），并会被极少数射线放大。
4. **高分歧视角是否对应有意义的未知区域**：否。U 选出的视角未知区域更小、支持更少；增益不到最优 10% 的选择占 27–38%（C1 20%）。
5. **与未知区域规模的相关**：U2 强（状态层面 0.75），U3 中等（0.51），U1 无（−0.22）。保留规模的 U3-sum 与预测单元数的状态内相关 0.97，等同于覆盖代理。
6. **高分歧、低收益案例**：U1 111 个、U3 100 个、U2 68 个状态（共 755）。典型例子 eiffel s0 t=10：U2 = 1,590 只来自 3 条射线，增益 0.57 pp，而 C1 的选择是 3.34 pp。

### 5.3 预注册决定的执行结果
- **U-best = U2**（固定状态增益 U1 0.568 / U2 0.704 / U3 0.582）。在任何闭环运行之前确定。
- **U4 未定义**：同编号与不同编号的单元一致度为 0.349 vs 0.318，差 +0.031 [+0.023, +0.041]，比值 1.10，低于预注册门槛 1.25。同一噪声编号不对应同一个三维世界，所以没有构造跨视角联合单元，U4 不进入闭环。

## 10. 分歧是否优于覆盖？在哪些场景有效？
- **否**。主比较 U-best（U2）vs C1（同一步前瞻）：AUC@20、Cov@20、AUC@100 都是 0/14 个场景更好，Final 是 2/14。U1、U3 在所有场景、所有指标上都低于 C1。三个分歧策略也都低于 D1。
- **唯一的“有效”是相对随机**：U2 在 14/14 个场景三个指标都高于 Random Walk，说明 U2 不是纯噪声，它确实偏向有未知区域的视角，但远不如直接估计新增覆盖。U1 只略好于随机；U3 在 Test-3 的 AUC@20 低于随机（−0.008，0/3）。
- **相对 C1 的个别场景**：
  - U2 的 Final 在 redeemer（+0.017）和 neuschwanstein（+0.059）高于 C1；
  - 此前的审计发现 neuschwanstein 有部分官方起点位于 GT mesh 内部（相机在表面背后），这个差值不宜解读；
  - 没有任何场景在 AUC@20 或 AUC@100 上出现分歧策略优于覆盖。
- **失败原因**（来自固定状态的直接测量，不是推测）：
  1. 分歧主要来自推测表面，不是“观测一下就能消除的真实歧义”（U3 92% 的分歧质量在没有真实表面的单元里）；
  2. 平均型定义在小支持上方差大，argmax 偏向未知区域小的视角（闭环中半数选择 < 100 条参与 U2 计算的射线）；
  3. 把规模保留下来，分歧就变成覆盖面积的代理（U3-sum 与 C1 不可区分），不再提供新的信息；
  4. 先前证据一致：Experiment B（T1 / B2）的 DepthU 在固定状态上 regret 变差 65–200%；多视角研究中跨视角冲突的 84–86% 是幻觉表面。
- **固定状态诊断准确预测了闭环**：方法排序与 0/10 → 0/14 的方向在两个阶段一致。在本系统里，固定状态的官方一步增益是一个可靠的、便宜得多的闭环前置门槛（固定状态 ≈ 3.5 GPU-h 对闭环 ≈ 13 GPU-h）。

## 11. 对 CVPR 消融的建议
- 在规划消融表（与 Table 3 同一协议）中加入 **一行“Generative disagreement（U2，一步）”**，与 “Coverage 一步（C1 = `V3-T0-K4D1`）” 和 D1 并列：
  - All-14 AUC@20 / AUC@100 / Final = 0.258 / 0.571 / 0.780 vs 0.399 / 0.740 / 0.889 vs 0.420 / 0.763 / 0.911；
  - 三行使用同一模型、同一组假设，只有打分不同，最能支持“把生成假设转成**预期新增覆盖**、而不是用假设间分歧，是规划有效的关键”。
- U1 / U3、固定状态诊断（Table U3、GT 归因）放在补充材料。只报告预注册的 U-best（U2），避免在测试集上挑最好的分歧变体。
- 措辞：
  - 写 “disagreement among generated view-conditioned first-hit depth hypotheses”；
  - 不写 “information gain”，不写 “generated 3D scenes”；
  - 注明 C1、D1 是同协议的归档行，U2 是同一模拟器、同一噪声键下新跑的。

## 12. 是否值得研究 Hybrid Coverage + Disagreement？
本实验**没有运行**任何混合策略。仅从已有数据判断：**不值得作为主线**。
- 能带来新信息的那部分分歧，本身就不对：与覆盖不冗余的分歧主要是伪表面（U1 64% 的分歧质量不在真实未知表面射线上，U3 92% 不在含真实表面的单元里）。
- 能和覆盖对得上的那部分分歧，又和覆盖重复：U2 与 C1 的合并秩相关 0.72，U3-sum 与预测单元数的状态内相关 0.97；这部分已经被 C1 / D1 用上。
- 在决策质量上没有任何分歧变体超过 C1。U2 的状态内 Spearman 0.31 低于 C1 的 0.44；U3-sum 与 C1 打平（−0.001 [−0.040, +0.035]）。
- 先前的混合尝试同样不乐观：Experiment B 的 DistP1 + DepthU（预注册 λ = 1）固定状态门槛 8/8 FAIL；非预注册的 λ = 0.5 只有约 7% 的 regret 改善（T1、Macarons++，探索性）。
- 前瞻更有用：本系统里 D1 相对 C1 有 +0.024 AUC@100 [+0.012, +0.037]，比任何分歧信号都更有效。
- 如果仍要尝试：只做低风险的平局打破（例如只在覆盖分数相差 < ε 的候选间用 U2 排序），并且必须先过固定状态门槛（Table U3 的增益与 Top-1 显著优于 C1）再考虑闭环。按目前数据，预期收益很小。
