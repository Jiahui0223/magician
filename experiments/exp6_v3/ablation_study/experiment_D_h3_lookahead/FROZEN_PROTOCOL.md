**搜索**（细节见 `reports/SEARCH_AUDIT.md`）：
- 第 1 层是全部合法候选。
- 第 2 层与 H3 相同：设置网格邻居，未访问优先，路径上的位姿视为已访问，已知 D100 表面带上的线段视为阻挡，不读取 GT 碰撞；穷举。
- 第 3、4 层：每个第一步候选只保留前 B 条路径（按 Q 排序），再用同一邻居规则展开。
- 每条路径在每个样本上取各位姿新格子的并集（每格取最大权重），Q = mean_k − λ·std_k。
- 第一步候选的分数取其在最深一层各路径 Q 的最大值；没有第 2 层子节点时，用单步 Q。
- 同一步内每个位姿的预测只计算一次（同一组特征与噪声），所有路径复用；只执行第一步，真实观测之后重新规划；虚拟集合不写回 P1。

## 3. 评估与选择
- **主版本选择**（预注册）：在 D1 / D2 / D3 中取 Dev-5 官方 AUC@100 最高者，差值 < 0.002 时取计算更便宜的；AUC@20 与 Final 一并报告。
- **跑满 All-14**：选中的主版本；D1 很便宜，若有预算也跑满 All-14 作为锚点。
- **D4**：最后运行；预测完成时间超过剩余预算的 0.8 时记为 NOT_RUN_COST。
- **诊断**：colosseum 与 pisa 的 H0 / H3 / D1 / D2 / D3 逐步轨迹（只在执行之后用 GT 覆盖评价）。
- **G3 门槛**：没有 G2 门槛；所有变体都跑完整的 100 步。
