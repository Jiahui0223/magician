# Experiment G2 协议 G2-v1：生成式头到底多给了什么（冻结）

冻结于 2026-11-15，在 G2 的任何计算之前。冻结后本文件只读；任何改动作为偏离记入 `logs/EVENTS.md`，并在报告里列出。sha256 记在 `reports/G2_PROTOCOL.sha256`。

不论结果有利还是不利，都如实报告。只计算本文列出的指标和分层；事后不再增加。

## 0. 对象与样本
| 名称 | 权重 | 预测 |
|---|---|---|
| D0 | `work_dirs/exp6_v3/experiment_G/d0/checkpoints/final.pt`（G-v1，EMA @40K） | 一次前向，`DetPredictor` |
| G4 | V3-T0 `final.pt`（sha `7ed0ddd7…`） | 部署配置：flow，Euler 10，噪声图 k = 0..3 |
| G16 | 同上 | 敏感性分析：噪声图 k = 0..15，前 4 个就是 G4 的 4 个 |
| G1 | 同上 | G16 中 k = 0 的那一个样本（= Table 3 的“噪声图 0”） |

K = 1、4、16 是同一组样本的嵌套子集，不额外抽样。G0 不在 G2 的范围内。

**评估集**
- **VALSEL-in**：`eval_dev` 的室内验证子集（训练器用的 `fixed_states("exp6-V3|eval|in_val", 2048, per_scene=True)`，2048 个视角，9 条轨迹）。
- **S-c-out**：`eval_dev` 的室外验证子集（`fixed_states("exp6-V3|eval|out_sc", 2048, per_scene=True)`，2048 个视角，42 条轨迹）。
- **F-pool**：Experiment F 的 755 个室外状态，按 CT / U 的回放链回放，取每个状态的全部第一层合法候选视角。
  - GT 只在离线使用：`gt_first_hit` → `geometry.encode_labels`，即训练标签规则，作用于该状态自己的 D100 地图。

**噪声**
- 验证集：K = 4 这一块完全用 `eval_dev` 的生成器（键 `exp6-V3|evalsample|<set>|<ti>|<t>`，每块 32 个视角，128 行一次 `sample`），因此 G4 必须逐位复现 T0 `eval.jsonl` 第 40,000 步的 `samp_*`；D0 必须复现 D0 `eval.jsonl` 第 40,000 步的 `samp_*`。k = 4..15 分三块，每块 4 个，键为 `…|kb<j>`（j = 1, 2, 3），每块同样 128 行一次。
- F-pool：规划器自己的键 `seed_key(scene, start, 0, t_r, k)`，k = 0..15（Experiment F 用的同一方案，扩展到 16）。k = 0..3 必须与回放链给出的 `eps4` 逐位相同。

**射线集合**：带标签的 UNKNOWN 射线，即 `lmask = (n_u > 0) ∧ (b ≠ 0)`；`b = +1` 记为 GT 命中，`b = −1` 记为 GT 未命中。

**弧长**（`eval_dev` 的定义）
- `lu = n_u · 0.5`：UNKNOWN 弧长，单位体素。验证集用分片中半精度存储的 `lu`，F-pool 直接由 `n_u` 计算。
- 样本 k：`hit_k = (b_k > 0) ∧ (y_k < 1)`，`ℓ_k = s_k · lu`（命中时 `s_k = clamp((y_k + 1)/2, 0, 1)`，否则 `s_k = 1`）。
- 真值：`ℓ* = s* · lu`（命中时 `s* = (y* + 1)/2`，否则 `s* = 1`）。

## 1. 第 1 项：概率预测质量（主要证据）
每个评估集、每个方法（D0 / G1 / G4 / G16）计算：
1. **fair ES（逐视角）**：`eval_dev.eval_samples` 的原式，逐视角取弧长 RMS，`e1 − Σ_{i≠j} rms(ℓ_i − ℓ_j) / (2K(K−1))`；K = 1 时配对项为 0。取视角均值。
2. **fair CRPS（逐射线）**：`(1/K) Σ_k |ℓ_k − ℓ*| − Σ_{i≠j} |ℓ_i − ℓ_j| / (2K(K−1))`；K = 1 时就是 `|ℓ − ℓ*|`。取射线均值。
3. **hit_ratio**：预测命中率 / 标签命中率（`eval_dev` 定义，命中率按 K 个样本平均）。
4. **命中概率 p**
   - G：K 个样本中命中的比例。
   - D0 soft：`clip((b̂ + 1)/2, 0, 1)`。
   - D0 hard：部署解码的 0 / 1，与 `eval_dev` 的 Brier 一致。
5. **Brier** `mean (p − 1[命中])²`：G、D0 soft、D0 hard 都报。
6. **log-loss**：p 截断到 [0.01, 0.99]，所有方法同一截断；D0 用 soft。
7. **可靠性曲线与 ECE**：[0, 1] 上 10 个等宽箱，每箱的平均 p 与实际命中频率；`ECE = Σ_b (n_b/N) |p̄_b − f_b|`；D0 用 soft。
8. **AUROC 与 AP**（不依赖阈值的命中检测）：G 的分数 = 命中比例；D0 的分数 = b̂。
9. **spread–skill（G4 与 G16）**
   - `spread = Σ_{i≠j} |ℓ_i − ℓ_j| / (K(K−1))`，`error = (1/K) Σ_k |ℓ_k − ℓ*|`；
   - 按 spread 的 10 个分位箱给出平均 error；
   - 报全体射线合并的 Spearman ρ，以及“每个聚类内的 ρ 再取均值”。

**统计**：聚类 bootstrap，聚类单位 = 轨迹（验证集用轨迹编号，F-pool 用轨迹标签），10,000 次，seed 0，95% 百分位区间；在同一组射线 / 视角上做配对差。
- 可加的指标按“和 / 计数”重采样。
- AUROC / AP 用每个聚类的分数直方图来重采样：G 的分数是精确的 K + 1 个取值；D0 在 [−1.5, 1.5] 上分 3,000 箱，箱外截断到两端；点估计用精确排序。
- Spearman 的 CI 只给聚类均值版本。

**预注册假设**
- **H1（主假设）**：在三个评估集上，D0 − G4 的 CRPS 和 fair ES 都 > 0（G4 更好），且 CI 不含 0。“支持”= 三个集都满足；任一集 CI 落在反方向则写“反对”；其余写“不确定”。
- **H1b**（双侧，只报告）：G1 vs D0 的 CRPS / ES。
- **H1c**（双侧，只报告）：soft Brier、log-loss、ECE、AUROC、AP、|1 − hit_ratio|。
- **H1d**：G4 的聚类均值 Spearman ρ(spread, error) > 0，且 CI 不含 0。

## 2. 第 2 项：歧义分层（只用 GT / 已观测几何定义，从不用模型输出）
分位边界在每个评估集上只用标签计算，并在任何模型前向之前写入结果文件。
- **A. UNKNOWN 弧长 `lu`**：全部带标签射线的四分位 → A1–A4（A4 最长）。
- **B. GT 命中离已观测前沿的弧长 `ℓ*`**：只取 GT 命中射线，四分位 → B1–B4；另设 B0 = GT 未命中射线。
- **C. GT 轮廓边缘**：在 64 × 114 射线网格中，带标签射线若有一个 4 邻居是带标签且 GT 标签相反（+1 vs −1），记为 C-edge，否则 C-int。
- **D. GT 深度不连续**（只在 F-pool，那里有 GT 深度 z*）：GT 命中射线若有一个 GT 命中的 4 邻居满足 `|z* − z*'| / min(z*, z*') > 0.10`，记为 D-edge；其余 GT 命中射线记为 D-smooth。

每个分层、每个方法报：
- 命中召回率、命中精确率（B 层全是 GT 命中，不报精确率）；
- 真阳性上的弧长误差 `|ℓ_k − ℓ*|`；
- CRPS；
- **“真值被至少一个假设覆盖”**：GT 命中射线上，存在 k 使 `hit_k` 且 `|ℓ_k − ℓ*| ≤ 1.0` 体素；GT 未命中射线上，存在 k 使 `¬hit_k`。
  - 这一项与 K 匹配的 fair 指标并列报告，并注明：best-of-K 按构造偏向 K > 1，不能单独作为生成式优于确定性的证据。

**H2**（预注册）：生成式在分布指标上的优势随歧义增大。差距 `Δ = CRPS(D0) − CRPS(G4)`，检验以下对比（聚类 CI）：
- (i) Δ(A4) − Δ(A1) > 0；
- (ii) Δ(B4) − Δ(B1) > 0；
- (iii) Δ(C-edge) − Δ(C-int) > 0；
- (iv) Δ(D-edge) − Δ(D-smooth) > 0（只在 F-pool）。

每个对比的判定：在它有定义的所有集上 CI 都不含 0 且方向一致 → “支持”；任一集 CI 落在反方向 → “反对”；其余 → “不确定”。

## 3. 第 3 项：闭环时间分析（CPU，现有曲线）
- **曲线来源**：D0 = `closed_loop/D0`，G1 = `V3-T0-K1D2`，G4 = `V3-T0-D1`（都是已重放验证的官方覆盖曲线）。
- **逐步差值**：每个 t = 0..100，`ΔC(t)` 取 D0 − G4 和 D0 − G1，场景等权均值（每个场景先对 5 个起点取均值）；95% 逐点带由场景 bootstrap 得到（10,000 次，seed 0）。
- **交叉步**：满足“对所有 t' ≥ t 都有 ΔC(t') ≤ 0”的最小 t，即从 t 起 G 不差于 D0；不存在则记为“无”。另报 ΔC 最后一次变号的步。
- **后期新增覆盖**：每个 episode 的 C[100] − C[50]，取场景均值，再做配对差与 CI。
- **分组**：All-14、Dev+Test-8（D0 / G 训练时没见过的场景）、Unseen-6（alhambra、neuschwanstein、eiffel、bridge、barts、sestino_museum）。
- 不做假设检验，只描述。

## 4. 第 4 项：可视化（真实模型输出）
- **数据**：F-pool 回放时，为每个状态存下“歧义分最高”的那个第一层候选视角的数组：GT z*、GT 标签、D0 的解码深度与 b̂、G 的 4 个样本深度与命中、射线几何。
- **视角歧义分** `a(v)`：该视角带标签 UNKNOWN 射线中属于 C-edge ∪ D-edge 的射线数。只用 GT。
- **状态分** `A = max_v a(v)`；同分取合法列表中第一个视角。
- **选状态**：按 A 降序取前 N = 4 个，每个场景最多一个；A 相同按 seed 0 的随机排列定先后。不看任何模型结果挑图。
- **每行一个状态**，各面板为：GT 首次命中深度；D0 单一预测深度；G 的 4 个样本深度；K = 4 中命中样本数的地图（叠 GT 命中轮廓）；反投影点（GT 命中点、D0 点、4 个样本点）。
- **标注两类射线**：(a) GT 命中但 D0 未命中，而至少一个样本覆盖到的射线；(b) 样本之间命中与否不一致的射线。
- **输出**：`figures/g2/`，PDF 与 PNG。

## 5. 第 5 项：室内闭环 MP3D-150
- **协议**：EXP7 原样，22 个验证层 × 2 个起点 × 150 步，层尺度 C_obs，与 EXP7 OURS 同样的起点（manifest 中的 OURS 行）。
- **新跑两组**：
  - **G1-in**：V3-T0 + D1，K = 1（噪声图 0：键 `exp5-V2|task0cl|<tag>|t<t_r>|k0`）；
  - **D0-in**：D0 + D1，K = 1。
  - 各 44 条。
- **G4-in**：存档 EXP7 OURS 记录，不重跑。
- **实现**：EXP7 文件不改，只加一层包装。新的规划器子进程 = `d_in_planner.py` 的链路 + t06 Planner 的 K 改成 1 + D0 模式下的 `GCore`。EXP7 的 D 配置与位姿表不变。
- **验证**：每个 episode 用 `collect_mp3d150.validate()` 原函数检查 V1–V3 与 V5。
  - V5 以 `method = "OURS"` 运行：D0 只把期望 sha 换成 D0 的 sha；
  - V4：起点必须与同一层 / 同一起点的 OURS 记录相同；
  - 另加一项：`planner.err` 中有 `G_MODE` 行，且 K = 1。
- **冒烟（精简）**：
  - G4R（包装器、flow、K = 4）前 10 步的分数与选择，必须与存档 OURS `planner.jsonl` 逐位相同；
  - G1-in、D0-in 各跑 10 步。
- **汇总**：起点均值 → 层均值 → 层等权均值。指标 AUC@20 / 50 / 100 / 150 与 Final = C[150]，主指标 AUC@150。配对层 bootstrap（10,000 次，seed 0）对 G4 与 G1；分组 ALL-22 / HO-12 / VALSEL-10。
- **H5**（预注册）：室内生成式的优势更大。ALL-22 上 G4 − D0 的 AUC@150 > 0 且 CI 不含 0，同时 G1 − D0 ≥ 0。
  - 室外对应差值为 −0.002（AUC@100）与 −0.009；
  - hit_ratio 差距“室内更大”这一部分在训练日志里已经能看到，不算独立检验。
