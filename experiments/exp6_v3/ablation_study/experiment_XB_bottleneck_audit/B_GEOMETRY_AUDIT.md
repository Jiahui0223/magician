## B1 观测几何保真（8 条室外轨迹 × 20 个状态）

对每个状态只用历史观测：把同一组历史深度图直接反投影成点云，检查这些点在 S10 P1、D100 P1、4× 聚合网格、8× 潜变量网格上是否还"存在"（所在格子为 BAND / 有观测支持），按到相机的距离分层（0–10 / 10–25 / 25–45 / 45–70）。

| 项 | 结果 |
|---|---|
| 已观测点在各级网格的保留率（S10 体素 / D100 体素 / 4× / 8×） | **100%**，8 条轨迹、4 个距离层全部如此 |
| 4× 网格里"薄"的 BAND 格子（64 个子体素中 ≤ 2 个为 BAND） | 占 BAND 格子的 **1.4–3.6%**（bannerman 末状态 2,959 / 81,125 = 3.6%） |
| UNKNOWN 边界格子的 8× 父格子有观测 | **43–77%**（bannerman 末状态 20,712 / 34,228 = 60.5%） |

结论：编码器的输入没有丢掉任何已观测表面的**存在性**；8× 压缩丢的是**位置精度和薄结构**（薄格子在 8× 上与邻近 EMPTY 混合），以及 UNKNOWN 边界附近约一半的格子在 8× 上被"有观测"的父格子覆盖，边界位置在潜变量里是模糊的。

## B2 反事实上界（CT 的 `ct_cf.py`；T1 / XA-SR / XA-MI；一步 = 官方增益 regret，两步 = D1 路径 regret）

regret = 按预测分数选出的候选与真值最优候选的差；`no_fp` = 去掉误报命中，`no_fn` = 补上漏报命中，`hit_oracle` = 命中 / 不命中全对但深度用预测，`depth_oracle` = 命中判断用预测但深度全对，`perfect` = 两者全对，`perfect_all` = 全部射线（含非 UNKNOWN）全对。Δ 为对 `pred` 的配对差，[ ] 为 bootstrap 95% CI。

| 集合（T1） | pred regret / Top-1 | no_fp Δ | **no_fn Δ** | **hit_oracle Δ** | depth_oracle Δ | perfect Δ（剩余 regret） |
|---|---|---|---|---|---|---|
| 室外 Dev 一步（n 80） | 0.272 / 0.525 | −0.009 | **−0.123 [−0.452, −0.022]** | **−0.142 [−0.466, −0.030]** | −0.053 [−0.185, +0.107] | −0.162（0.110） |
| 室外 Dev 两步（D1，n 80） | 0.258 / 0.562 | −0.006 | **−0.113 [−0.462, −0.005]** | **−0.126 [−0.462, −0.015]** | −0.013 [−0.204, +0.076] | −0.078（0.179；perfect_all 0.154） |
| 室内 一步（n 90） | 0.155 / 0.467 | +0.004 | −0.040 [−0.094, 0.000] | −0.040 [−0.096, +0.001] | −0.036 [−0.161, +0.080] | **−0.095 [−0.202, −0.013]**（0.060） |
| 室外 Train 一步（n 60） | 0.141 / 0.500 | −0.009 | −0.056 [−0.103, 0.000] | **−0.074 [−0.134, −0.019]** | +0.016 | −0.067（0.074） |
| 室外 Train 两步（D1） | 0.110 / 0.500 | +0.016 | −0.018 | −0.031 [−0.087, 0.000] | **+0.064 [+0.020, +0.106]** | +0.039（0.148） |

XA-SR / XA-MI 的阶梯形状相同（室外 Dev 一步：XA-MI hit_oracle Δ −0.124、XA-SR 两步 −0.045，XA-SR 两步 depth_oracle **+0.078 [+0.006, +0.286]**；室内 perfect Δ −0.10 ~ −0.12；室外 Train 两步 depth_oracle Δ +0.04 ~ +0.08）。加入 colosseum / sestino 后室外 Dev 的 n 从 40 到 80，pred regret 从 0.43 降到 0.27（这两条轨迹的状态更容易），阶梯形状与 CI 结论不变。

结论：
1. **杠杆在"命中 / 不命中"的判断，尤其是漏报。** 补上漏报（no_fn）几乎拿到 hit_oracle 的全部收益；去掉误报（no_fp）几乎没有收益。
2. **深度精度不是瓶颈。** 只把深度改对（depth_oracle）在室外没有收益，在室外 Train 的两步前瞻上反而变差（+0.064）：更准的深度让新覆盖体素落到更远处，与 D1 的距离加权和 1 m 格去重相互作用，不等于更好的决策。
3. **即使预测完美，regret 也不为零**：室外 Dev 一步剩 0.11、两步剩 0.15–0.18；室内剩 0.06；室外 Train 两步剩 0.15。剩余部分是价值函数（预测命中 → 新覆盖体素）与官方覆盖增益之间的不一致，与 Experiment F 的结论一致。室外 Dev 的"完美"上界 CI 很宽（少数状态主导）。
4. 51 / 51 任务完成（colosseum、sestino_museum × 3 模型的 6 个在 Task C 结束后补跑，09:35 完成）。

## 对协议问题的回答

- **Q-B1 输入几何有没有丢信息？** 存在性没有丢（100%），丢的是位置精度 / 薄结构 / UNKNOWN 边界位置（8× 上 43–77% 的边界格子被"有观测"的父格子覆盖）。这与 Task A "局部 F4 样本是唯一有用的 K/V" 互相印证：更细的沿射线几何是现成可补的信息。
- **Q-B2 预测完美能涨多少？** 命中 / 不命中全对可把室外 Dev 的一步 regret 从 0.27 降到 0.13、两步从 0.26 降到 0.13，室内从 0.155 降到 0.115，室外 Train 一步从 0.14 降到 0.07；深度全对不涨（室外两步反而变差）。完美预测后仍有 0.06–0.18 的 regret 属于价值函数 / 规划器。
- **Q-B3 误差在哪？** 漏报，集中在：UNKNOWN 段短、起点离相机远、极近或极远的表面、以及训练场景后期的残余区域。命中判断主要由 UNKNOWN 段长度这个几何投影通道驱动，说明先验更多是"段长统计"而不是"场景内容"。
