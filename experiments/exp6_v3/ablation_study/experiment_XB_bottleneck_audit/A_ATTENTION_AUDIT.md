## 结论

1. **T1 的交叉注意力是惰性的。** 三个域、六种干预，预测误差和候选选择全部与未干预相同（室外 Train 的 zero_wo 只在 FNR 第三位小数上差 0.001）。T1 在推理时功能上等于 T0；T1 对 T0 的闭环差别不能归因于注意力。
2. **XA 的注意力在被使用，但不是系统性有益。** XA-MI 室内 zero_wo 使 regret 0.158 → 0.266，而室外 Dev zero_wo 使 regret 0.258 → 0.218（变好）；shuffle_tok 室外 Dev regret 0.258 → 0.182（变好）。方向在域之间相反，与 XA 闭环“持平”一致。
3. **最有用的 K/V 内容是沿射线的局部 F4 样本，而不是全局 token。** XA-MI drop_local 使室外 Dev FNR 0.257 → 0.436、室内 0.196 → 0.264；drop_f16（去掉最粗的全局 token）反而降低 FNR（Dev 0.257 → 0.208，室内 0.196 → 0.164）。这些是对已训练模型的测试时干预，不等价于重训消融，但方向一致：更细的沿射线几何有用，粗粒度全局上下文没有表现出价值。
4. **漏报是主导误差。** 三个模型未干预时 FNR 0.20–0.27（留出）/ 0.14–0.15（训练场景），Brier 0.10（室内）/ 0.08（室外 Dev）/ 0.02（训练）。训练场景上的 FNR 也有 0.14，不是过拟合，而是先验对未观测几何的召回不足。

对协议问题的回答：Q-A（T1 的注意力贡献）= 0；Q-A'（XA 注意力依赖什么）= 局部 F4 样本 > F8 > F16，band 与 free token 均有被读取但去掉后影响互相抵消。
