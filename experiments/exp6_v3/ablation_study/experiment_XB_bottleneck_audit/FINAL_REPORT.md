## 对任务书 7 个问题的回答

**1. XA 的新 Attention 是否真正改变模型预测？**
部分改变，但不系统性有益。对训练好的 T1，六种推理期干预（输出置零、token 打乱、位置编码打乱、去 band / free token）在 230 个状态上**预测误差与候选选择完全相同**，注意力熵 5.84 对均匀熵 5.88，残差只占输入 RMS 的 6.9%：T1 的交叉注意力惰性。XA-SR / XA-MI 的注意力被使用（残差 31–45%，熵低 1.2–1.4 nat），置零后预测会变，但方向在域间相反（XA-MI 室内 zero_wo 使 regret 0.158 → 0.266，室外 Dev 反而 0.258 → 0.218）。唯一一致有用的 K/V 内容是**沿射线的局部 F4 样本**（去掉后 Dev FNR 0.257 → 0.436），而全局 F16 token 去掉后 FNR 反而下降。闭环上的验证：T0 + D1（无交叉注意力）在 Table 1 All-14 为 0.420 / 0.646 / 0.633 / 0.763 / 0.911，对 T1 + D1 五项差全在 CI 内。（`A_ATTENTION_AUDIT.md`）

**2. 当前 3D VAE / P1 是否丢失重要的已观测几何？**
存在性没有丢：历史观测反投影的点在 S10 / D100 / 4× / 8× 各级的保留率为 **100%**（8 条轨迹 × 4 个距离层）。丢的是**位置精度与薄结构**：4× 上 1.4–3.6% 的 BAND 格子是"薄"的（≤ 2 / 64 子体素），UNKNOWN 边界格子有 43–77% 在 8× 上被"有观测"的父格子覆盖。这与问题 1 的"局部 F4 样本是唯一有用的 K/V"互相印证：更细的沿射线几何是现成可补、且有证据的信息。（`B_GEOMETRY_AUDIT.md` B1）

**3. GT First-Hit 与模型预测之间还有多少 Oracle Headroom？**
在"命中 / 不命中"上很大，在"深度"上没有。T1 室外 Dev（80 个状态）：一步 regret 0.272 → 补上漏报 0.149 → 命中全对 0.130；两步（D1）0.258 → 0.145 → 0.131；室内 0.155 → 0.115；室外 Train 0.141 → 0.067。只把深度改对：室外无收益，室外 Train 两步反而 +0.064 变差。预测完美后仍剩 0.06–0.18 的 regret，属于价值函数 / 规划器与官方覆盖的不一致。（B2）误差本身的分布：漏报集中在 UNKNOWN 段短（L_u < 10%：FNR 0.34–0.42 对长段 0.08–0.10）、UNKNOWN 起点离相机远（0.32–0.46 对 0.12–0.22）、极近 / 极远表面（室外 Dev 2 单位内漏报 0.64，Train 同层 0.02）和训练场景后期的残余区域（late FNR 0.53）；命中判断基本跟着 UNKNOWN 段长度走。（B3）

**4. 将 Outdoor 训练场景从 6 个减少到 3 个，是否明显影响完整闭环？**
没有。Reduced-3（bannerman / fushimi / liberty，室外有标签视角 49%，其余与 T1 完全相同）70 条室外 D1 + 6 条室内：All-14 AUC@20 0.422 / Cov@20 0.654 / AUC@50 0.642 / AUC@100 0.767 / Final 0.908，对 T1 + D1 为 −0.003 [−0.011, +0.005] / +0.000 / +0.004 / +0.002 [−0.007, +0.011] / −0.002 [−0.007, +0.005]；仅 Dev-5 AUC@20 −0.009 [−0.020, −0.001] 与 Train-6 Final −0.008 [−0.014, −0.003] 通过 CI，量级与 XA 六个变体对 T1 的差相同。保留的 3 个场景与去掉的 3 个场景没有差异模式。而同一模型的**验证**室外 fair ES 变差 6.7%（6.92 对 6.48，从 15k 步起持续落后）。即：数据减半让预测变差、闭环不变。（`C_DATA_SCALING.md`）

**5. 目前有没有充分证据支持"数据集太小是主要瓶颈"？**
对闭环覆盖：**没有**。减半无变化是直接证据；训练场景上的 FNR 也有 0.14–0.15（不是过拟合）；B2 显示只有 oracle 级别的命中召回改善才换来决策改善。对预测指标：**有**，验证误差随数据量系统性变化。本轮没有分离样本数与场景多样性，也没有做"加倍"方向的外推，所以结论是"同类几何数据的数量不是当前闭环的限制"，不是"数据永远无用"。

**6. 下一阶段是否值得引入 UrbanScene3D、BuildingNet、BlendedMVS？**
以提升 Table 1 覆盖为目标：**不优先**，问题 4 / 5 的证据不支持同类几何数据能改变闭环。值得引入的情形有两个：(a) 目标改为预测质量或跨域泛化的论证（验证误差确实对数据敏感）；(b) 作为**外观 / 语义信息源**的载体——BlendedMVS 和 UrbanScene3D 带 RGB，可用于给射线编码器接入冻结 2D 基础模型特征（见问题 7），这才是 XB 唯一没有被排除的新信息来源。BuildingNet 是无纹理网格，只能补几何，按本审计的结论价值最低。无论哪种，域差（地标建筑 vs 城市航拍 / 室内）和 MAGICIAN 协议的 14 个评测场景都要先核对。

**7. 若需要继续训练，应优先扩充数据，还是修改 Geometry Representation / Training Objective？**
优先级：**几何表示 > 训练目标 / 规划器价值对齐 > 数据**，并且不再做注意力变体。
- 几何表示：射线编码器直接采样 4× 特征（Task A 的 drop_local 与 B1 的薄结构证据一致，改动最小）；接入外观 / 语义特征作为第二信息源（问题 1 的"K/V 要有不同信息"，可用投影 gather 而不必用注意力）。
- 训练目标 / 规划器：漏报是唯一有上界支持的方向（B2），命中判断现在由 L_u 驱动（B3），可以在目标上做命中校准，但 V5 的首次命中头过拟合在前，须谨慎；预测完美后剩余的 0.06–0.18 regret 要在规划器价值函数上处理（Experiment F 的方向）。
- 数据：只有在上面两项之后、或为了外观特征而引入 RGB 数据时才值得。
- 注意力：T1 的块应从主模型删除（Table 1 主行改为 `V3-T0-D1`，T1 作对照），XA 路线关闭。
