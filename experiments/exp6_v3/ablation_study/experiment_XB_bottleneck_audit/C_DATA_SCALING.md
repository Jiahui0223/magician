## 3. 结论

1. **室外训练数据减半（场景 6 → 3），验证预测误差变差 6.7%，闭环覆盖不变。** All-14 的 AUC@20 / AUC@100 / Final 差为 −0.003 / +0.002 / −0.002，全部在模型间噪声内；唯一通过 CI 的差是 Dev-5 AUC@20 −0.009 和 Train-6 Final −0.008，量级与 XA 六个变体对 T1 的差相同。
2. **预测质量与闭环覆盖再次解耦**，方向与 XA 相反但结论相同：XA-MR 验证变好闭环不变，Reduced-3 验证变差闭环不变。在当前预测质量附近，D1 的决策对预测误差 ±7% 不敏感——与 B2 一致：只有命中 / 不命中判断的大幅改善（oracle 级别，regret −0.25）才能换来决策改善，渐进的预测改善换不来。
3. **"数据太少"不是闭环成绩的瓶颈**——至少在"同类几何数据、同一域"这个意义上：把数据加倍（从 Reduced-3 回到 Train-6）只换来 6.7% 的验证误差和 0 的闭环变化，继续加同类数据不太可能改变闭环。它仍然是预测质量的瓶颈（验证误差确实随数据变化），所以如果目标是预测指标，数据有用；如果目标是覆盖，瓶颈在别处（新信息源、或规划器的价值对齐，见 B2 / B3）。
4. 本轮没有分离"样本数"与"场景多样性"（任务书 §4.3 的"6 场景匹配样本量"对照未跑），也没有"更多数据"方向的外推；上面第 3 点是对"减半无变化"的解读，不是对"加倍一定无用"的证明。

对协议问题 Q-C 的回答：数据量影响预测质量（是），不影响当前规划器的闭环覆盖（否）。
