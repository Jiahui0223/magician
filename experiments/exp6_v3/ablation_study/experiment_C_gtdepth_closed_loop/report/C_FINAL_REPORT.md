## 0. 一句话结论
- **完美未来深度（C1）只能带来早期、不显著的闭环收益**：MP3D AUC +0.023 [−0.003, +0.065]、Macarons++ +0.011 [−0.008, +0.029]（相对 B2），Final 反而 −0.017 / −0.012；按冻结判定 C1 − B2 在两个数据集都算"退化"（ΔFinal ≤ −0.010）。对 V3-T1 则 Macarons++ 上"有意义"（AUC +0.029、Cov@20 +0.063）。**未来深度预测不是 Final Coverage 的瓶颈。**
- **DistP1 评分本身是主要损失源之一（C2 vs C1）**：同样用 GT，把 DistP1 换成真实单步增益后 MP3D AUC +0.043 [−0.004, +0.096]、Final **+0.101 [+0.043, +0.195]**（5/0 楼层），Macarons++ AUC **+0.030 [+0.007, +0.052]**（5/1）、Final +0.024。C1 在闭环内的 Top-1 率只有 0.63 / 0.645，错误集中在前 20% 步。
- **候选空间 / 视野是剩下的上限**：即使单步 oracle greedy（C2），MP3D Final 也只有 0.615；MP3D 任一时刻平均只有 25–29% 的剩余可见表面在当前规划区域内；停滞窗口里合法候选的最优增益中位数 0.03 pp，而 28–42% 的步骤里被 GT 线段阻挡的邻居比全部合法候选更好；Macarons++ 有 9–10% 的步骤没有任何合法候选能新增覆盖（落入种子随机 fallback）。
- **一步 regret 与 G3 不一致的原因**：C1 的闭环内一步 regret（0.068 / 0.113 pp）远低于 Experiment A 里 B2 的固定状态 regret（0.112 / 0.468 pp），Final 却与 B2 持平；regret 集中在早期（早 / 中 / 晚 = 0.139 / 0.060 / 0.022 pp 室内，0.347 / 0.067 / 0.017 室外），早期选对只换来早期覆盖领先，后期由候选空间支配，排序质量不再起作用，轨迹分叉又使 Final 对早期小错误高度敏感（室内 C1 regret 与 C2 − C1 的 ΔAUC 相关性 −0.15）。

## 3. 研究问题
### R1 Perfect depth 是否显著提高 G3？——**否（Final）；只有早期、不显著的 AUC 收益**
C1 − B2 的 AUC 增量 +0.023 / +0.011 的 CI 都含 0，Final 为负；对 E2D（MP3D 闭环最佳的学习模型）C1 甚至 Final −0.040。C1 比 T1 / E2D / T0 / B0 / MAG-B 多数情况下好，说明 GT 深度在当前规划器里**不是没有价值**（Macarons++ 早期 Cov@20 +0.058，6/6 场景一致；MP3D 的 TbHJrupSAjP +0.104），但其价值被后续机制抵消。因此，**在不改 DistP1 / 候选 / Greedy 的前提下，任何预测网络的改进（含 V4 的 3D U-Net + Cross-Attention）在 Final 上的可得空间约为 C1 − B2 ≈ 0，在 AUC 上约 +0.01–0.02，且不显著。**

### R2 DistP1 是否限制最终 Coverage？——**是，且是可量化的主要损失之一**
- 同样拥有 GT，C2 − C1：MP3D Final +0.101 [+0.043, +0.195]（5/0），AUC +0.043；Macarons++ AUC +0.030 [+0.007, +0.052]（5/1），Final +0.024。
- 闭环内 C1 的一步 Top-1 率 0.630（MP3D）/ 0.645（Macarons++），平均 regret 0.068 / 0.113 pp，而 G\* 均值 0.40 / 0.97 pp：**完美深度下 DistP1 在 1/3 以上的步骤选的不是真实增益最大的候选**。错误集中在早期（表 §4）。
- 失败模式：colosseum 起点 0——C1 Top-1 率 0.11、平均 regret 0.573 pp，AUC 0.567（B2 0.740，C2 0.779）；colosseum 起点 2 的 t=1 / 5 / 15 / 16 是全实验 regret 最大的状态（4.0–4.8 pp）。DistP1 的"新体素数 × 距离权重"偏向远处 / 大面积但对评估点集无贡献的表面（与 EXP5 A1 的相关性诊断一致：被选候选新表面只有 74–89% 与评估相关），在大场景起点处尤其严重。
- 逐 episode：Macarons++ 上 C1 的平均 regret 与 C2 − C1 的 ΔAUC 的 Spearman 相关 0.52（n = 30）；MP3D −0.15（n = 10）——室内 Final 的差异主要来自轨迹分叉而非 regret 大小（例：Z6MFQCViBuw 起点 6，C1 平均 regret 仅 0.030 pp，Final 0.321 vs C2 0.667）。

### R3 候选空间限制是否显著？——**显著，且是 C2 之后剩下的主要上限**
| 诊断（评估侧，每步） | MP3D C1 | MP3D C2 | Macarons++ C1 | Macarons++ C2 |
|---|---:|---:|---:|---:|
| 平均合法候选数 | 8.3 | 8.3 | 6.9 | 7.3 |
| G\*（合法集最优真实增益）pp，均值 / 中位 | 0.397 / 0.156 | 0.396 / 0.188 | 0.971 / 0.263 | 0.882 / 0.176 |
| 剩余未覆盖（可见）表面，均值 | 64.4% | 60.2% | 39.0% | 36.1% |
| 剩余表面在规划区域内（室内）/ 在某合法候选 70 单位射程内（室外）的比例 | **0.25** | **0.29** | 0.63 | 0.70 |
| G\* = 0 的步数（没有候选能新增覆盖） | 15 / 1,500 | 0 / 1,500 | **273 / 3,000** | **315 / 3,000** |
| fallback（全 0 分 → 种子随机）步数 | 3 | 0 | 120 | 315 |
| MP3D 停滞 episode（≥ 30 步增长 < 0.01）| 5 | **1** | — | — |
| MP3D 停滞窗口内：G\* 中位 pp / 剩余 / 区域内比例 / 阻挡邻居优于合法集的步数比例 | 0.031 / 57.5% / 0.23 / **0.28** | 0.038 / 50.4% / 0.35 / **0.42** | — | — |
- **MP3D**：任一时刻 70–75% 的剩余工作在当前 n_win = 5 区域之外；停滞时合法候选几乎无事可做（G\* 中位 0.03 pp），而被 GT 线段阻挡的邻居（1 m 步长碰墙）在 28–42% 的停滞步里比全部合法候选都好 → 限制来自**规划区域 + 单步邻域 + 碰撞合法性**的组合，不是评分或预测。C2 把停滞 episode 从 4–5 条降到 1 条，但 Final 仍只有 0.615：单步 oracle 也走不出局部。
- **Macarons++**：9–10% 的步骤任何合法候选都看不到新表面，规划器只能随机走；30–37% 的剩余表面不在任何合法候选的射程内 → 需要多步 / 全局目标，不是更好的一步评分。

### R4 为什么一步 regret 与最终 G3 不一致？
| 量 | B2（Exp. A 固定状态） | T1（Exp. A） | C1（闭环内，自身状态） | C2 |
|---|---:|---:|---:|---:|
| MP3D 一步 regret pp | 0.112 | 0.114 | 0.068（早 / 中 / 晚 0.139 / 0.060 / 0.022） | 0 |
| Macarons++ 一步 regret pp | 0.468 | 0.319 | 0.113（0.347 / 0.067 / 0.017） | 0 |
| G3 AUC（MP3D / Macarons++） | 0.334 / 0.730 | 0.331 / 0.712 | 0.357 / 0.741 | 0.400 / 0.771 |
| G3 Final | 0.530 / 0.906 | 0.508 / 0.883 | 0.513 / 0.894 | 0.615 / 0.919 |
1. **regret 是前期现象**：C1 的 regret 在前 20% 步是后 20% 步的 6–20 倍；B2 / T1 在固定状态上的差异（Macarons++ T1 比 B2 低 32%）同样集中在 early 相位（Experiment A）。早期选对只换来早期覆盖（Cov@20），后期（Final）由 §R3 的候选空间支配，那时 G\* 本身就小，排序对错几乎不改变结果。
2. **分叉放大**：不同方法从第一步起走不同轨迹；室内 Final 的 episode 间差异（C1 与 C2 在 Z6MFQCViBuw 起点 6 相差 0.35）远大于单步 regret 能解释的量，且室内 regret 与 C2 − C1 的增益无相关（−0.15）。固定状态比较（共享状态）消除了分叉，所以 Experiment A 的 regret 差异与 G3 的 Final 差异无需一致。
3. **评分器误差是系统性的**：C1 在 colosseum 起点 0 上连续选错（Top-1 0.11）；这类场景级的系统误差对固定状态均值的贡献被稀释，对闭环却是灾难性的（AUC 0.567 vs B2 0.740）。
4. 因此 Experiment A 中 T1 在 Macarons++ 上更低的 regret（0.319 vs 0.468）**不能换算为 Final 的提升**；它最多预示早期覆盖的提升，而 EXP6 G3 里 T1 的 Cov@20 也并未高于 B2（0.566 vs 0.572）。

## 6. 对下一版架构的证据（建议；V4 的具体架构与 Scratch / Warm-start 由你决定）
1. **预测侧的闭环上限已经测出**：在当前 DistP1 + 区域 + 单步 greedy 下，完美深度 = AUC +0.01–0.02（不显著）、Final ≈ 0。V4 若只换预测网络（3D U-Net + Cross-Attention），在 Final 上不可能超过这个上限；在固定状态上它可能逼近 GTD 的 regret，但 Experiment A/C 共同表明这不会兑现为 Final。
2. **评分器是第一个可动的杠杆**：C2 − C1 给出了"把 DistP1 换成与评估口径一致的增益估计"的收益上限（MP3D Final +0.10，Macarons++ AUC +0.03），且这一步不需要新训练——可在已有 oracle / cq 数据上离线拟合或规则化（评估相关表面、去掉远距离 / 大面积偏置、按 P1 覆盖口径计数）。colosseum 起点 0 一类的系统性失败是首要测试用例。
3. **候选 / 视野是第二个杠杆，且决定 Final**：MP3D 75% 的剩余工作在区域外、停滞时阻挡邻居更优；Macarons++ 10% 的步无候选可用。需要的是规划器改动（整层 / 多区域评分、更长的位移动作或目标驱动的多步前瞻），不是生成模型。EXP5 A1、Experiment A 和本实验三次指向同一结论。
4. **Scratch vs Warm-start**：本实验不提供新的区分证据；两者在固定状态和闭环上都与 B2 相当，而 C1 / C2 说明差异来源在规划侧。若 V4 仍要训练，建议先做 2–3 的零训练 counterfactual（同一批固定状态 + 同一闭环协议），再决定是否值得投入大规模训练。

## 7. 局限
场景数少（5 楼层 / 6 场景），CI 宽；Test-3 非盲；C2 是候选集单步 oracle，不是长期最优；C1 的每步诊断使其模拟器耗时增加但不影响决策；历史组的每步时间不可比；一次工程失败（C-1）已记录并重跑。
