## 解读与决定（人工，2026-10-31 10:40）
- **P1（只用 DepthU）在所有 dev 集、两个模型上都显著变差**（regret +65% ~ +200%，Top-1 −0.13 ~ −0.14，所有场景一致）：样本间分歧本身不是好的选点信号。
- **P2（冻结 λ = 1.0）**：MP3D VALSEL B2 −3.6%（CI 含 0）、T1 +40%；Macarons++ Dev-3 B2 +20%（CI 不含 0，恶化）、T1 +5%。无一满足 (a) 或 (b)；多个组合违反 (c)（最差场景恶化 > 25%）。
- **敏感性 λ = 0.5**（非冻结，不用于 Gate）：T1 在 Macarons++ 全部 1,093 状态上 P2_λ0.5 − P0 = −0.023 [−0.051, −0.001]（5 / 6 场景更好，Early −0.065 [−0.111, −0.015]），MP3D 上 −0.011 [−0.030, 0.004]；B2 上均为恶化或中性。这是唯一方向为正的信号，量级约为 P0 regret 的 7%，远小于 GT 深度上限留下的空间（T1 0.319 → GTD 0.160）。按协议它只能作为探索性观察，不能据此放行。
- **DepthU 诊断**：候选 DepthU 与 oracle 增益的状态内相关 0.38–0.51（P0 为 0.56–0.64）；与 GT 未来深度误差的相关只有 0.13–0.25；DepthU 最高 1/4 的候选中 17–20% 实际零收益；oracle 最优候选的 DepthU 只有状态内最大值的 0.68–0.72 → 分歧有信息量，但主要是"可见未知区域多"的代理，与 DistP1 高度冗余，叠加后以噪声为主。
- **决定**：Gate 不通过 → **不进入正式 G3**；也**不运行 exploratory 闭环**（固定状态上 λ = 1 的 P2 在两个数据集都未改善，闭环不可能给出可用的正结论，且需在规划服务里新增评分路径；省下的算力无需申请）。Experiment B 结论为**阴性**：在当前 K = 4 预测与 DistP1 框架下，预测分歧不是可用的一步选点改进方向。
