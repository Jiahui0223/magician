## 1. 结论

1. **六个变体没有一个在室外 All-14 上超过 V3-T1 + D1。** 四个主指标的配对差都在 ±0.013 以内；六个变体的平均差是 AUC@20 −0.004、Cov@20 −0.001、AUC@100 −0.003、Final −0.008。XA-SR、XA-SI、XA-M2D、XA-MR、XA-MI 与锚点持平（区间含 0）；XA-S2D 略低（AUC@20 −0.008、AUC@100 −0.007，区间刚好不含 0）；XA-MI 的 Final −0.011 区间触 0。
2. **两个设计因子都没有可检出的闭环效应。** Query：Ray / Interval 对 2D 在单尺度下有 +0.005 的正向趋势（9 / 14 场景变好），在多尺度下没有；Ray 与 Interval 之间没有差别。记忆：多尺度对单尺度在三种 Query 下都是 ±0.006 以内。没有交互效应。
3. **预测质量的改善没有转化为覆盖。** XA-MR 是唯一在验证指标上明显拉开的变体（fair ES 比 T1 低 7.8% / 4.7%，室内 Brier 低 11%，从 10,000 步起每个里程碑都领先），它的 All-14 覆盖与 T1 + D1 持平；分组上 Dev-5 变差、Test-3 变好，互相抵消。
4. **室内 sanity**：五个变体没有塌陷；XA-MI 的室内 AUC@150 / Final 比 T1 低 0.025 / 0.062，3 个楼层一致（样本太小，只作记录）。
5. **解释**（证据见 §7）：注意力能读到的信息，射线条件和 U-Net 的卷积已经覆盖；唯一新的信息通路（沿 Query 射线采样的 4× 特征）确实提高了预测质量，但当前这种幅度的预测改善对 D1 的决策没有影响。瓶颈在模型能拿到的信息（6 个室外训练场景、多孔的 P1 输入、对漏报偏保守的决策），不在它混合信息的方式。
6. **建议**：不把任何 XA 变体用于论文主结果；不再堆叠注意力变体；先测 T1 的种子方差，再把力气转向信息瓶颈。

每个变体只有 1 个训练种子，没有重训方差的估计；0.01 量级的差别都在这个实验的分辨率以内。Test-3 不是盲测集。

### 3.3 怎么读

- **持平是主结果。** 曲线图（`EARLY_CURVES.png`）里六条曲线与 T1 + D1 基本重合，都明显高于 MAGICIAN Beam；差别集中在个别场景（colosseum 的后期停滞、neuschwanstein、pantheon）。
- **XA-MR 的 Dev-5 / Test-3 相反**：Dev-5 AUC@20 −0.023 [−0.034, −0.009]（colosseum −0.037 / Final −0.106、eiffel −0.034、pantheon −0.022、sestino −0.022），Test-3 AUC@100 +0.023 [+0.010, +0.031]（3 / 3）。colosseum 的后期停滞在 Experiment E 里已确认是噪声触发的现象，T1 + D1 也有；Test-3 只有 3 个场景。两头抵消后 All-14 持平。
- **Test-3 上三个变体有小幅正值**（SI +0.012、M2D +0.008、MR +0.014 的 AUC@20，区间不含 0），但 Test-3 不是盲测集、只有 3 个场景，不单独作结论。
- **噪声下限**：每个变体 1 个种子，没有 T1 重训方差的估计；闭环对噪声敏感（colosseum 的停滞是噪声触发的）。这个实验只能发现 ≥ 0.02 的效果，而没有出现。

## 7. 为什么没有提升

证据链（细节在 `../logs/EVENTS.md` 和各实验报告）：

1. **验证集上，不带注意力的 T0 一直不比带注意力的差**（40k：T0 6.37 / 6.44，T1 6.42 / 6.48）。从 T1 开始，交叉注意力就没有提高过预测质量；S / M2D 变体也没有。
2. **架构改动 ≈ 0，规划器改动 > 0，完美预测 ≫ 0**：Table 1 里 V3 / V4 / V5 对 B0 没有增益，XA 对 T1 没有增益；D1 对 H0 带来 AUC@20 +0.041；GT 深度 oracle（Experiment A / F / CT）把 Top-1 从 0.47–0.53 提到 0.54–0.69。预测质量是瓶颈，但换架构没有改变预测质量。
3. **注意力拿不到新信息**：每条射线的条件向量已经沿射线采样了 μ 的 32 个点；邻居射线的信息由 U-Net 的卷积混合；注意力的 key 又限制在视锥内。S 记忆 × 任何 Query 都是在用另一种方式读同一份信息。M 记忆里唯一新的信息是 F4 的 4× 局部采样——正是 MR / MI 这两个变体在验证上拉开的原因。
4. **但预测改善没有转化为覆盖**：XA-MR 的预测明显更好，D1 闭环却持平。CT 的反事实显示决策损失主要来自漏报命中（模型在未观测处不敢预测表面），这是先验 / 校准问题；当前幅度的预测改善没有改变 D1 的选择，或者被闭环的随机性淹没。
5. **信息瓶颈在上游**：室外训练只有 6 个场景（138 条轨迹）；P1 输入是多孔的（BAND 只沿 10% 采样射线写入，25–54% 的自观测射线穿透）；决策对漏报偏保守。

## 8. 建议

1. 不把任何 XA 变体用于论文主结果；V3-T1 + D1 仍是基准。
2. 不再堆叠注意力变体（任务书里的第七组 Hybrid 和几何偏置也不建议做）。
3. 先补一个便宜的诊断：对训练好的 XA 模型在固定状态上把 `W_o` 置零再评估，并统计注意力权重集中度，确认注意力块在推理时的实际作用。
4. 再训 1–2 个 T1 种子（各 16 小时），得到重训方差；没有这个数，任何 ±0.01 的架构结论都站不住。
5. 把力气转向信息瓶颈：补 P1 的空洞、增加室外训练场景、针对漏报做校准——每一条都有现成的反事实证据支持。
