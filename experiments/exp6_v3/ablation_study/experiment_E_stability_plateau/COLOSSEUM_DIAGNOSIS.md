# COLOSSEUM_DIAGNOSIS — colosseum 低覆盖平台诊断（Task 2）

**协议**：E-v1（`PROTOCOL.md`）。低平台 = Final < 0.70；脱困 = 续跑 Final ≥ 0.75（运行前固定）。所有 GT 量只在评估侧离线计算，从未进入任何规划器。

**证据等级**：
- **【事实】** = 直接测量；
- **【推断】** = 实验支持但不是直接测量；
- **【假设】** = 尚未验证。

## 1. 平台是什么：失败起点、分叉步、轨迹
- **【事实】双峰**：colosseum 每条 episode 的 Final 要么 ≥ 0.75，要么停在 0.58–0.66。两者之间的空档 0.665–0.749 只有一个例外，即 D1 s2 的 0.749。
- **【事实】平台起得早**：低平台 episode 的平台开始步为 14–20，此时 Cov@20 ≈ 0.58–0.61；成功 episode 的平台开始步在 34–61。
- **【事实】分叉很早，且不决定结局**：
  - 与 H0 首次执行不同动作的步：H3 为 1–5，D1 为 1–5，YBEST-H3 为 1–5；
  - D1 与 H3 首次分叉在第 2、21、65、4、24 步（s0–s4）；
  - 很早分叉之后，同一策略在不同起点上结局各异。
- **【事实】空间形态**（`FIGURES/colosseum_trajectories.png`，`colosseum_spatial_s0.png`）：
  - 低平台 episode 都走到位姿网格北边界（z = 55–65）后沿边界来回，z 方向范围只有 4 格（成功 episode 为 12–13 格）；
  - 平台阶段零增益步（Δcov < 0.001）占 67–100%；
  - 原地转向率与往返率和成功 episode 相近，不是简单的原地打转；
  - 平台阶段往南（远离边界）的移动只占所选动作的 1–5%。
- **【事实】缺失的是远侧**（C 节）：
  - 低平台 episode 比同起点 H0 少覆盖 17–22% 的 GT 点，位于归一化半径 0.6–1.1、高度 −3 到 15，即南侧外立面及其周边；
  - H0 主要在第 20–50 步覆盖这一区域，覆盖进度为：t = 20 时 3–21%，t = 30 时 17–32%，t = 50 时 68–92%。

## 2. 局部是否还有可得的增益（GT 反事实，B 节）
| 步集合 | 每步最佳一步真实增益（pp） | 选中动作的真实增益（pp） | 最佳候选 ≥ 0.5 pp 的步比例 |
|---|---|---|---|
| 低平台 episode 的平台阶段（H3 / D1 / YBEST-H3） | 0.11 / 0.12 / 0.12 | 0.05 / 0.05 / 0.06 | 5% / 2% / 5% |
| 低平台 episode 的平台前 | 3.96 / 4.00 / 4.20 | 3.26 / 3.35 / 3.38 | 100% |
| 成功 episode 的 t < 50（H0 / D1） | 2.02 / 1.67 | 1.45 / 1.48 | 84% / 63% |

**【事实】**平台阶段，所有合法候选的真实一步增益都接近 0。规划器想象的最佳两步路径，其真实两步增益也只有约 0.1 pp。

**【推断】**离开平台需要一段多步绕行：沿两侧 x = ±65 的列下行，或升高后越过场馆。途中几乎没有中间增益，一步或两步前瞻在真实信号上看不到这条路。

## 3. 预测是否高估、高估了什么（预测重建 + 遮挡检验）
**【事实】规划器的预测值远高于真实值**：
- 选中动作的预测 h_mean，与其真实视图在 GT 评估面附近部分的 value 之比：
  - 平台阶段：98.5×（H3）、94.8×（D1）、98.3×（YBEST-H3）；
  - 平台开始前：1.8–2.1×；
  - 成功 episode 的后半程：40–94×。
- 只要局部真实增益耗尽，预测值就不随之下降。

**【事实】预测值的构成**（选中动作，容差 2.0；F 节）：

| 步集合 | 命中（真实新增） | 已见（GT 面，但真实视图不新增） | 空（2.0 内无 GT 评估点） |
|---|---|---|---|
| colosseum 平台阶段 | 0.01 | 0.22 | 0.78 |
| colosseum 平台前 | 0.18 | 0.38 | 0.45 |
| 全部场景 t < 20 | 0.17 | 0.37 | 0.46 |
| pisa / alhambra（全部步） | 0.21 / 0.37 | 0.24 / 0.29 | 0.54 / 0.35 |

**【事实】视线遮挡检验**（`scripts/occlusion_check.py`）：把执行视图的预测 cell 与智能体在下一帧真实看到的点比较，视线方向 1.5° 以内。

| 步集合 | 预测值中位于真实表面之后（被遮挡）的比例 |
|---|---|
| colosseum 平台阶段 | 0.93（空 0.74 + 已见 0.19） |
| colosseum 成功 episode t ≥ 50 | 0.91 |
| 全部场景 t < 20 | 0.44 |
| pisa / alhambra t ≥ 20 | 0.56 / 0.39 |

- 平台阶段的“空”cell 位于北立面底部、高度约 −10 到 −4，比智能体已观测到的地面（约 −3 到 0）低 4–8 个单位，距最近的已观测点 4–8 个单位。
- 它们在执行视图里反复出现：执行视图的预测 cell 中，此前的执行视图已经预测过的比例在 colosseum 平台阶段为 92%，在全部场景 t ≥ 20 为 80%（`results/REFUTE_TABLES.md`）。

**【推断】**主要的预测错误是**看穿已观测表面**：预测射线越过智能体已经观测到的地面和立面，命中其后的表面。这些表面在真实视图中永远不可见，所以永远不会被新增检验排除，每一步都被重新计为新增。这与此前审计记录一致：P1 已观测表面带只沿 10% 采样射线建立，且自由空间雕刻提前 3 个体素停止，25–54% 的自观测射线会漏过。本诊断没有逐射线验证这条因果链，所以“P1 多孔导致看穿”记为**推断**；“预测值主要在真实表面之后”是**事实**。

## 4. 风险惩罚的作用；去掉后为何能恢复
- **【事实】已有闭环**：
  - colosseum 低平台 episode 数（rep 0）：H1（一步，无风险）1/5，H2（一步，λ 0.25）3/5；H3（两步，λ 0.25）4/5，D1（两步，λ 0）1/5（s1 0.618；另有 s2 0.749 落在空档内，既不算低平台也不算脱困）；
  - D1 的 s4 在第 75–91 步晚期脱困（0.591 → 0.816），s2 在第 88–99 步部分回升（0.639 → 0.749）；H2 / H3 的低平台 episode 都没有在平台之后脱困。
- **【事实】分支续跑**：同一状态换策略续跑（E-C，`PLATEAU_TABLES.md` D 节；脱困 = Final ≥ 0.75）。

  | 源（低平台） | T | 换成 h0 | 换成 d1 |
  |---|---|---|---|
  | H3 s0 / s1 / s2 / s4 | 10 | 0.831 / 0.614 / 0.809 / 0.803（脱困 3/4） | 0.640 / 0.618 / 0.749 / 0.816（1/4） |
  | H3 s0 / s1 / s2 / s4 | 20 | 0.754 / 0.615 / 0.821 / 0.732（2/4） | 0.640 / 0.618 / 0.749 / 0.816（1/4） |
  | H3 s0 / s1 / s2 / s4 | 50 | 0.626 / 0.730 / 0.820 / 0.609（1/4） | 0.628 / 0.617 / 0.749 / 0.622（0/4） |
  | YBEST-H3 s0 / s1 / s4 | 20 | 0.613 / 0.605 / 0.860（1/3，Y50K 权重的 h0） | — |
  | D1 s1 | 20 / 50 | 0.615 / 0.731（0/2） | — |

  - **反向**：从 H0 的成功状态换成 h3 续跑，T = 10 时 5/5 脱困，T = 20 时 4/5 脱困（s4 停在 0.624）。
  - **关键现象**：从 H3 的平台状态换成 d1 后，续跑往往与 H3 原轨迹**逐步相同很长一段**。与源轨迹首次不同的步：s0 第 42 步，s1 第 21 步，s2 第 65 步，s4 第 24 步。所以在平台状态下，去掉风险项通常**不改变**所选动作（μ − 0.25σ 与 μ 的最大值落在同一候选上）。
- **【事实】噪声重复（E-D）**：每个策略 15 条 episode（5 起点 × rep 0 / 1 / 2，rep 只改规划器噪声键）。

  | 策略 | 低平台次数（Final < 0.70） | 各 rep 的 colosseum 平均 Final（rep 0 / 1 / 2） | 与 H0 的 Fisher 精确检验 |
  |---|---|---|---|
  | H0（DistP1，一步） | 1 / 15 | 0.824 / 0.808 / 0.791 | — |
  | H3（两步，λ 0.25） | 8 / 15 | 0.671 / 0.738 / 0.743 | p = 0.014 |
  | D1（两步，λ 0） | 5 / 15 | 0.771 / 0.799 / 0.699 | p = 0.17 |
  | YBEST-H3（50K，两步，λ 0.25） | 7 / 15 | 0.705 / 0.799 / 0.695 | p = 0.035 |

  - H3 vs D1：p = 0.46；YBEST-H3 vs D1：p = 0.71。
  - 低平台事件分散在所有起点上（H3 每个起点 1–2 次，D1 每个起点 1 次），同一起点在不同 rep 中结局不同。
  - **平台由早期轨迹上的微小分数差异触发，不是某个起点固有的；rep 0 中“H3 4/5 vs D1 1/5”的差距大部分是随机性。**
- **【推断】**去掉风险项提高了脱困的概率，但并不消除平台：一步的 H1 与两步的 D1 都有低平台起点，D1 从 H3 的平台状态续跑时多数仍不脱困（分支结果）。
- **【假设，未验证】**风险项为何更容易让智能体停住：它按样本分歧惩罚候选，而平台阶段吸引智能体的看穿幻影可能在 K 个样本间较一致，离开边界的候选分歧较大。本实验没有逐候选检验这一点。

## 5. 前瞻机制检查
- **【事实】想象位姿的可达性**：H3 系列想象的第二步 c2* 在真实执行 c1 之后仍合法的比例：
  - 平台前为 100%；
  - 平台阶段为 80–83%（选中动作）与 84–89%（全部候选）；
  - 成功 episode 为 82–96%（选中动作）。
  - 不可达的比例在平台阶段（17–20%）与成功 episode 后半程（4–17%）同一量级，属于次要因素。
- **【事实】想象与真实的一致性**：H3 / D1 的两步分数（并集，同一冻结 P1，不写回想象观测）与真实两步增益在平台阶段都接近 0；按构造，并集按 cell 取最大权重，不会重复计分。
- **【事实】实现正确性**：d0ref 与 V3-H3 逐位一致；本实验的预测重建与日志 h_mean 一致（最大相对误差 2.2e-9）。**没有发现实现错误。**
- **【推断】多步误差累积不是主因**：一步的 H1 / H2 同样陷入平台；D2–D4 更深的搜索仍有 1–2 / 5 个低平台起点。

## 6. 结论：平台的成因
**回答：低覆盖平台主要由什么造成？证据是否足够？**

1. **【事实】直接表现是“近侧耗尽后，智能体被困在远离剩余表面的边界上”**：
   - 约第 15 步时，智能体已经看完北侧，停在北边界；
   - 剩下约 20% 的 GT 在南侧外立面，从边界出发需要一段多步绕行；
   - 绕行途中所有局部动作的真实一步增益约为 0，想象的最佳两步路径真实增益约 0.1 pp。
2. **【事实】此时规划器的预测值并不下降，反而系统性地“看穿”已观测表面**：
   - 选中视图的预测值约为真实值的 95–98 倍；
   - 其中 93% 位于智能体从该位置实际看到的表面之后（北立面底部、已观测地面之下的幻影面）；
   - 同一批幻影 cell 在 92% 的执行步里反复出现。
   - 因此 1–2 步规划器没有任何“局部已耗尽、需要远行”的信号。
3. **【事实】风险惩罚不是主要原因**：
   - 15 次重复中，H3 与 D1 的平台频率无显著差异（8 vs 5，p = 0.46）；
   - 从 H3 的平台状态换成 d1 后，往往与 H3 原轨迹逐步相同，持续 20–65 步；
   - 2 × 2 中去风险项对 All-14 的平均效应为 0（AUC@100 +0.001，Final +0.005，均不显著）。
4. **【事实】不是硬性的可达性陷阱**：
   - 第 10 步时换成 h0，4 个 H3 平台状态中 3 个能脱困；
   - 但陷得越久越难脱困（第 50 步只有 1/4），后期剩余步数不够完成绕行，此时可达性与预算成为约束。
5. **【事实】实现与前瞻机制正常**：
   - 回归逐位一致；
   - 想象的第二步 80–83% 可达；
   - 更深的搜索（D2–D4）仍有 1–2 / 5 个低平台起点。
   - **没有发现实现错误。**

**综合判断**：
- 平台是**场景几何**（远侧只能经长距离绕行到达）、**看穿已观测表面的预测**（局部耗尽后预测值仍高）与**短前瞻**三者叠加的结果。
- 主要类别依次是：**预测错误（看穿） > 局部路径选择（早期走向边界，由微小分数差异触发） > 可达性 / 预算（仅后期）**；风险项与搜索深度是次要因素。

**证据强度**：
- 第 1–5 点是直接测量或闭环事实；
- “看穿的幻影值是让智能体**留在原地**的原因”目前只有相关性与离线重排序证据，没有闭环干预。离线结果：只用过去观测的反证重打分，平台阶段 Top-1 从 0.35 到 0.45，ρ 从 0.14 到 0.28。
- 因此因果链的最后一环属于**实验支持的推断**，需要一个预注册的闭环干预来确认（见 FINAL_REPORT）。

**未解决**：
- H0 的 DistP1 规则为什么更少陷入平台（1/15 vs 5–8/15）？它的预测同样高估（H0 成功 episode 的后半程，预测值约为真实视图 value 的 12 倍，真实值按不限域计），且在 H3 的平台状态下也很少直接往南。差异的机制尚未定位。
