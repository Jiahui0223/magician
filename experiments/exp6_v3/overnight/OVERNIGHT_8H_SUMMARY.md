**归因**（只依据上表的证据）：
- **colosseum 的退化大部分来自 H2 的风险惩罚**：去掉它，Final 从 0.671 升到 0.771，平台从第 38 步推迟到第 48 步，水平探索范围也从 6.6 扩大到 9.8。H2 报告中已发现样本分歧与真实增益正相关（+0.45），风险惩罚会把真实的高增益方向一起压低。
- **剩余与 H0 的差距**（0.771 对 0.824）**尚未归因**：H3 系列走过的不同位置数与 H0 相当，但更早进入平台。更深的搜索（D2 / D3）把第 50 步的覆盖提高到 0.757，但 Final 没有再提高。
- **pisa**：去掉风险项后部分恢复（0.912）；depth 3 / 4 后完全恢复（0.934 / 0.935）。
- **colosseum 的逐起点结果是双峰的**：每条 episode 的 Final 要么约 0.81–0.85，要么停在约 0.61–0.67（只有 D1 起点 2 的 0.749 介于两者之间）。
  - 停在低峰的起点数：H0 0 / 5，H3 4 / 5，D1 1 / 5，D2 / D3 2 / 5，D4 1 / 5；
  - 停住的起点因策略而异，所以场景均值主要反映“落入低覆盖状态的概率”，而不是所有起点的平均退化；
  - 原因仍未定位，可能是某个局部区域把 H3 系列困住，但这只是推测。逐起点数值在 `COLOSSEUM_PISA_DIAGNOSIS.md`。

1. **规划器：用 D1（H3 去掉风险项）或原 H3 作为主规划器。**

2. **模型：如果论文要报告“模型 + 规划器”的最佳系统，YBEST-H3（Y50K + H3）是目前 All-14 最高的行**（0.427 / 0.770 / 0.911），相对 H3 的 AUC@100 与 Final 提升显著但很小。
