## 0. 一句话结论
- **Q1/Q2 DistP1 与真实覆盖增益的差来自四处口径差**（审计 §3）：新颖性尺度（1 体素 BAND 膨胀 vs 覆盖率 eps 5–13 体素，且 BAND 只沿 10% 射线）、z0 距离上限（覆盖率在射程内 ∝ 面积）、无入射角补偿、区域裁剪。
- **Q3 GT 深度下**：MP3D 的主要缺陷是新颖性尺度（S2h：dev 楼层被选动作的真实增益 1.038 → 1.079 pp，oracle 上限 1.099；Top-1 0.633 → 0.767），Macarons++ 的主要缺陷是 z0 上限（S1a / S1c：1.781 → 1.869 / 1.856 pp，上限 1.999；Top-1 0.671 → 0.727）。S3 室内小幅有效、室外中性。**两个数据集需要的修正不同**，相乘的 S4 在 GT 上最好（室外 S1aS2S3 1.889）但没有普适性。
- **Q4 迁移到预测深度**：室外 S1 迁移（B2 S1c 1.458 → 1.522 pp，T1 S1a 1.627 → 1.724；Top-1 +0.01 / +0.05），S2 室外反而更差；室内 S2 / S3 对 T1 迁移（0.944 → 0.982 pp），对 B2 迁移不稳（dev 一个楼层明显恶化）；S1 室内在预测深度上有害（远处预测噪声被 z² 放大）。
- **Q5 闭环（G3）**：**固定状态的改善没有兑现为室外的 AUC / Final**：B2 + S1c AUC 0.715 vs 0.730（−0.015 [−0.029, −0.000]）、Final 0.890 vs 0.906 → 退化；T1 + S1c 0.719 vs 0.712（+0.007 [−0.005, +0.019]）、Final 0.879 vs 0.883 → 无差异。**MP3D 上 T1 + S2S3（探索性）改善**：AUC 0.354 vs 0.331（+0.023 [−0.003, +0.049]，4/1 楼层）、Final 0.530 vs 0.508（+0.022，4/1），停滞 episode 5 → 2，达到 GT 深度规划器 C1 的水平（0.357 / 0.513）；B2 + S2S3 退化（0.323 / 0.472）。按冻结规则 MP3D 没有两个模型都通过的变体，这一结果标为 exploratory。

## 5. 结论与下一步
1. **评分器确实有改进空间，但改进点因数据集而异**：室内 = 新颖性尺度（S2）+ 薄前缘一致性（S3），室外 = 去掉 z0 上限（S1）。一个统一公式（S4）没有证据。
2. **一步排序改善 ≠ 闭环改善**（室外 S1c 两个模型都更准、闭环不升甚至降）；只有室内 T1 + S2S3 把一步改善兑现到了 AUC / Final，且幅度与 GT 深度规划器相当。
3. **建议**：把 S2S3 作为 V3-T1 室内规划器的候选默认评分（需在新的、未用过的楼层上做一次盲测确认，因 5 个评估楼层已多次使用）；室外保持 S0。若要继续评分器研究，优先解决 B2 对软新颖性的敏感性（远处预测噪声），而不是再加组件。
4. 本轮没有新增训练；V4 的架构 / Scratch vs Warm-start 不由本实验决定。
