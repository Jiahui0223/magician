## 2. 唯一的改动：学习率日程
- **原因**：原日程是 warmup 1000 步后余弦退火，在 40K 时已降到约 0（1.6e-13），无法直接续训。
- **新日程**：
  - 40000–40499：线性预热到 cont_peak = 2e-5（原峰值 1e-4 的 20%，与本项目 E2 / F1 微调的峰值相同）；
  - 之后余弦退火，在 55000 时归零。
- **其余全部不变**：数据（MP3D train + Train-6 去 S-c，D100 + TSDF 缓存，32 + 32 视角）、损失（L_FM + L_rec + β·KL，β = 0.02）、batch、EMA 0.999、梯度裁剪 1.0、bf16、架构。
- **早停**：关闭（原规则依赖于原总步数）。
- **验证**：每 5000 步一次（45K / 50K / 55K），使用固定的 VALSEL / S-c 子集，不使用 Test；同时保存里程碑 EMA。

## 3. 保存与恢复
- **训练器自身**：每 1000 步原子写入 `ckpt_last.pt`。
- **控制器**：每 1000 步复制一份 `ckpt_step<step>.pt`，滚动保留最近 3 份，并把 sha 写入 `checkpoint_manifest.json`；里程碑 `ema_<step>.pt` 永久保留。
- **故障恢复**：控制器每 60 秒检查一次；训练进程意外退出时从 `ckpt_last.pt` 自动续训，最多 2 次。
- **停止点**：`control.json` 中 stop_at = 50000（预算规则），到达后有序停止。之后仍可用同一命令续到 55000。
