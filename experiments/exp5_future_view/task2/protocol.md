## 3. V2-Mix 训练（`scripts/t21_*.py`、`t22_*.py`，`configs/train_mix_v1.json`）
**室内训练数据**：
- **轨迹**：在 1.0 m 网格上（与评估相同的网格、合法性规则和传感器）走 150 步。
  - 训练楼层每层 2 条：`rnv`（随机，优先未访问）和 `ogr`（GT 一步贪心，GT 只用来生成训练轨迹）；
  - 选择用的楼层每层 1 条（策略由种子决定）。
- **标签**：与 T1.1 相同的光栅化器，64 × 114 条打分射线的第一交点 t*；训练轨迹带 ±2 px 亚像素平移，选择集不平移。
- **取帧**：与闭环完全一致。每 10 步刷新一次，以刷新时的相机为中心取 n_win = 5 的区域；编码器的陈旧度不跨刷新。

**训练设置**：
- 从 V2 Original 的 EMA@60k 初始化，模型和 EMA 都从这里开始；
- 每个 batch 64 个视角，32 个室内 + 32 个室外；
- 损失与 Task 1 完全相同：rectified-flow 速度 MSE，对 batch 内所有有效的 M_unknown 射线取平均；
- AdamW，lr 2e−5，预热 500 步，余弦退火到 0，共 20k 步；weight decay 0.01，梯度裁剪 1.0，bf16，EMA 0.999，陈旧度增强 p = 0.5；
- 4 卡 DDP。

**冒烟**：
- 过拟合：一个固定 batch 跑 200 步，看损失下降和梯度检查；
- 短训练：1k 步，看损失下降、没有 NaN。

**checkpoint 选择**（训练前冻结）：
- 每 2.5k 步，以及第 0 步（= V2 Original），在 in_val（2,048 个视角）和 out_sc（2,048 个视角）上计算 EMA 的 fair ES（未知弧长坐标，体素）；
- score = ES_in / ES_in(0) + ES_out / ES_out(0)，取最小，同分取较晚的 step；
- 如果第 0 步最好，就如实报告"联合训练没有改善预测"，V2-Mix 仍取 score 最小的那个非零 step，参加闭环。
- **不看任何闭环结果。**

## 4. 共享动作协议
| | 室内（MP3D） | 室外（Macarons++） |
|---|---|---|
| 动作空间 | T0.12 网格：每格 1.0 m，俯仰 5 档 × 方位 8 档，官方 `get_neighboring_poses` | 官方 `settings.json` 网格与官方邻居 |
| 合法性 | 官方单线段 GT 检测；原地不是动作 | 官方：邻居 → `get_valid_neighbors`（优先未访问）→ GT 线段检测；没有合法动作时原地不动（hover） |
| "只走未访问位姿" | 由规划器执行：V2 的 NV 规则 = MAGICIAN 的 `get_valid_neighbors` | 环境的合法列表已经执行；所有组的规划器在同一个已过滤的列表上选择 |
| 起点 | T0.3 的起点站点，吸附到网格，俯仰 0°、方位 0° | 官方 5 个起点 |
| 传感器 | 冻结的 MAGICIAN 传感器 456 × 256、60°、量程 70 运行单位（10 m） | MAGICIAN 默认传感器（同分辨率） |
| 预算 | C0 + 150 次移动 = 151 帧 | C0 + 100 次移动 = 101 帧 |
| V2 区域 | n_win = 5（每 10 步以相机为中心刷新） | 整个场景（与 Task 1 相同） |

- **所有组拿到同一个模拟器生成的服务记录**（深度、掩码、10% 采样点、合法位姿列表），不会有哪个组多看一帧。
- **V2 的内部分辨率**：64 × 114 条射线、K = 4，与 MAGICIAN 想象高斯的计算量差异在报告中单独列出。

## 5. 指标
- **覆盖率**：
  - 室内：C_obs（T0.6 / T0.8 的评估器，单调）；
  - 室外：主口径为 `t25_out_cov.py` 的单调累积覆盖率（与官方同样的 GT 点、ε 和 visibility_ratio，但保留全部观测点）；次口径为模拟器的官方口径，它可能下降，原样报告。
- **AUC@T** = trapz(cov[0..T]) / T（梯形，端点各权重 1/2）；室内报告 AUC@100 和 AUC@150，室外报告 AUC@100。
- **最终覆盖率**：室内 Cov@150，室外 Cov@100。
- **Comp（只用于 MP3D）**：
  - 米制 GT 顶点（楼层框内、面片引用的顶点）到全像素观测点云的最近距离，复用 T0.8 的实现；
  - Comp@5cm（%）↑，Comp（cm）↓ 取**均值**，中位数作辅助；
  - 不可观测的顶点也计入分母；另报只算可见顶点的 Comp。
- **统计**：
  - 先在场景内对起点平均，再对场景平均；
  - 按场景聚类 bootstrap（10,000 次，seed 0）给出 95% CI；
  - 保存逐 episode 的原始值；
  - 室外 Test-3 和 Dev-3 分别报告，不合并。

## 6. 执行与审核
- **执行顺序**：
  1. 冻结评估部分；
  2. 室内 4 组 × 10 条 episode；
  3. 室外 4 组 × (Test-3 + Dev-3) × 5 个起点；
  4. 用独立脚本从保存的轨迹复算（室内 `t25_in_metrics.py`，室外 `t25_out_cov.py`）；
  5. 生成表和图。
- **审核内容**：步数、帧数、合法性、坐标单位、覆盖率复算一致（室内 |d| ≤ 1e−12；室外官方口径逐位一致）、场景与起点对应、规划器 guard 拒绝次数为 0。
- **失败处理**：episode 失败时重跑一次（室外可以续跑），仍失败就记录为 Incomplete，不删除、不补值。

## 7. 停止条件
数据划分泄漏、GT 进入规划器、评估协议无法成立、训练出现 NaN、或 V2-Mix 无法加载时，停止受影响的部分并向你汇报。
