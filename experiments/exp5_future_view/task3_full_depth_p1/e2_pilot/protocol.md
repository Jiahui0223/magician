# Task 3 / Experiment 2 — V2-Mix Fine-Tuning Pilot 协议 v1.0（2026-10-29，训练前冻结）

依据用户 10-29 的批准书。本协议在任何训练开始前写定；之后的修改只能记入偏差日志，不得改动判定标准。

## 1. 组别
| 组 | 训练条件输入 | 闭环规划器 | DistP1 评分 |
|---|---|---|---|
| **E2-D100** | D100 P1（`p1_full.P1FusionFull`）重建的训练数据 | B2 方式（D100 输入） | 稀疏 10% |
| **E2-S10** | Task 2 / T1.1 原稀疏数据（不重建） | B0 方式 | 稀疏 10% |
| B0 / B2 | 冻结 V2-Mix（不训练），分别使用 D10 / D100 输入 | — | 稀疏 10% |

**两组相同的部分**：
- 初始化：V2-Mix EMA@17.5k（`work_dirs/weights/W21_exp5_v2mix/W21-1_V2Mix_best/ema_017500.pt`，sha256 `343f41ab8d56…`）；
- 代码：冻结的 Task 2 训练器 `t22_train_mix.py`，只重定向配置和数据根目录（`e2_train.py`）；
- 训练轨迹、状态与视角列表、采样 RNG（numpy `[seed 0, rank]`，4 卡 DDP，按 rank 轮转分片）、噪声种子、监督目标的定义、损失、优化器、步数、评估集。

**唯一差别**：P1 中写入 BAND 的点（10% 采样 vs 全部有效像素）。

## 2. 数据
**范围**：使用**全部**合法训练轨迹。重建成本经冒烟实测可接受（见审计报告），因此不做子采样。

| 部分 | 内容 |
|---|---|
| MP3D 训练 | 61 个 train 房屋的 114 个楼层，228 条 150 步轨迹 |
| MP3D 评估集 | VALSEL：6 个 val 房屋的 9 个楼层，9 条轨迹 |
| Macarons++ 训练 | Train-6 去掉 S-c，138 条轨迹 |
| Macarons++ 评估集 | S-c，42 条轨迹 |

**不使用**：MP3D 官方 test、5 个评估楼层、Test-3、Dev-3、sofia_church。

**D100 重建**：用冻结的 `t21_build.py` / `t11_build.py`，只在进程内替换 P1 类。
- 状态 t 的 P1 只融合记录 0..t（与规划器相同）；候选相机的 t\* 只作为标签，不写入 P1。
- Macarons++ 的 T-L5 记录重放检查施加在同记录的稀疏孪生地图上，并要求稠密地图与孪生地图的 EMPTY 完全相同。

**标签**：
- **直接复用**：t\*（GT 第一交点，与 P1 无关）、候选位姿、抖动、视角列表。
- **随 P1 重算**（用冻结的 `encode_labels`，规则相同）：射线类别 cls、投影统计（t_known、d_lo、d_hi、L_u、n_seg）、标签类别 cat、b、y、监督掩码 lmask = UNKNOWN ∧ b ≠ 0。

这是 V2 任务的定义：模型只对本组地图中仍未知的射线预测"第一交点在未知区的位置"。两组的监督目标是**同一个函数**，作用在各自的输入地图上，所以被监督的射线集合和 y 的参数化不同。这与推理时的输入一致，不构成泄漏。

## 3. 训练（配置：`configs/e2_<arm>_v1.json`，其余字段与 Task 2 `train_mix_v1.json` 相同）
| 项 | 值 |
|---|---|
| 训练参数 | 全部参数 |
| 步数 | 5,000 次优化器更新 |
| 学习率 | AdamW lr 2e−5（β 0.9 / 0.99，wd 0.01，全新优化器）；前 500 步从 0 线性预热到 2e−5，之后余弦退火到 0（Task 2 的 `lr_at`） |
| batch | 全局 64 个视角 = 32 MP3D + 32 Macarons++（每卡 8 + 8），4 卡 DDP，梯度在卡间求和 |
| 其他 | bf16；EMA 0.999（模型与 EMA 都从同一个 V2-Mix EMA 权重初始化）；梯度裁剪 1.0；陈旧度增强 p = 0.5（≤ 9 步，不跨刷新）；seed 0 |
| 评估与 checkpoint | 每 1,000 步（含第 0 步）在本组密度的 VALSEL（2,048 视角）、S-c（2,048）及训练子集上评估，保存 EMA，即 step 0 / 1k / 2k / 3k / 4k / 5k |
| 主 checkpoint | **固定为 step 5,000 的 EMA**，两组相同，不做任何 checkpoint 选择；中间 checkpoint 只用于曲线 |
| 资源 | 两组各 4 张 L40S 并行（gpu117 + gpu115，同型号） |

## 4. 评估状态（开发集，不含最终测试场景）
| 数据集 | 来源 | 状态 |
|---|---|---|
| MP3D | VALSEL 9 条轨迹 × t ∈ {0, 5, 20, 25, 50, 55, 100, 105, 140, 145}（9 个楼层，场景单位 = 楼层） | 90 |
| Macarons++ | Dev-3（barts、pantheon、colosseum）在 E1.2 中的固定状态，S_B0 + S_B2 合并 | 约 270 |

**VALSEL 的 oracle**：
- 增益 = 候选第 t+1 帧 10% 采样新覆盖的 GT 点比例，GT 点用 `t21_traj` 的 10 万个按面积采样点，eps = 0.08 × k_I；
- 噪声种子 = `exp5-T3E2|valsel|<key>|<traj>|t<r>|k<k>`；
- 候选集与选择规则同 Task 2（未访问优先）。

**阶段划分**：同 E1.2 协议 §2，MP3D T = 150，Macarons++ T = 100。

**Test-3 和 MP3D 五个评估楼层只出现在 G3 闭环中**，不参与任何选择。

## 5. 关口（冻结）
### G1 预测（step 5,000；两个数据集分别判定）
预测指标（对 t\*）按以下射线集合分组：
- unknown：本组输入地图中 cls = UNKNOWN 的射线；
- truly-new：GT 点到历史 10% 采样点的距离 > eps；
- known：truly-new 的补集。

同时报告 K = 4 的相对离散度、命中不一致率，以及离散度与误差的 Spearman 相关。

**通过条件**：
- **G1-a**：E2-D100 的 unknown MAE ≤ B2，且 truly-new MAE ≤ B2（场景均值），两个数据集都满足。
- **G1-b**（不塌缩）：E2-D100 的相对离散度 ≥ 0.8 × B2；或离散度–误差 Spearman ≥ B2 − 0.02。两个数据集都满足。
- **G1-c**（训练正常）：两组损失有限；step 5,000 的 FM 验证损失在 VALSEL 和 S-c 上都不高于 step 0。

**不通过**：G1 判为 No-Go，不跑闭环；报告并提出调整方案。

### G2 排序（step 5,000，稀疏评分，开发集状态）
报告四个模型（B0、B2、E2-S10、E2-D100）：regret、Top-1、Spearman、Early / Middle / Late、逐场景结果。

**通过条件**：
- 两个数据集上，E2-D100 的整体 regret ≤ 1.05 × B2，且 Top-1 ≥ B2 − 0.03；
- 至少一个数据集上，E2-D100 的 Early regret ≤ B2。

G1 和 G2 都通过时，两组都运行 G3（E2-S10 作为对照）。

### G3 闭环（Task 2 / Task 3 协议：MP3D 10 条 × 150 步，Macarons++ 30 条 × 100 步）
**主比较**：E2-D100 − E2-S10。

**"有意义"**（与 Task 3 §4 相同，按数据集）：
- ΔAUC ≥ +0.010；
- ΔFinal ≥ +0.010；
- 场景胜数 ≥ 4/5 或 ≥ 4/6；
- 没有场景 ΔAUC < −0.030。

**"退化"**：ΔAUC ≤ −0.010 或 ΔFinal ≤ −0.010。

| Pilot 结论 | 条件 |
|---|---|
| **Go**（扩大全深度微调） | E2-D100 − E2-S10 在至少一个数据集上有意义、另一数据集未退化，**且** E2-D100 − B2 的 ΔAUC 在两个数据集上都 ≥ 0 |
| **Conditional Go** | E2-D100 − E2-S10 的 ΔAUC 在两个数据集上都 > 0 且都未退化（未达到全部"有意义"条件）；或有意义但 E2-D100 − B2 在某个数据集上 < 0 |
| **No-Go** | 其余情况，包括 E2-D100 相对 E2-S10 在任一数据集上退化 |

**同时报告**：
- E2-S10 − B0（额外训练的收益）、E2-D100 − B2（微调的收益）；
- Cov@10 / 20 / 50 / 100 / 150、逐场景结果、移动次数与重访率、每步时间、峰值显存；
- Macarons++ 的 Cov@20：E2-D100 − B2 的配对 CI；
- MP3D 中期停滞：t ∈ [30, 120] 内存在长度 ≥ 30 步、覆盖增长 < 0.01 的窗口的 episode 数（各组）。

## 6. STOP 条件
- 损失非有限或明显发散；
- 稠密数据的状态 / 视角列表与稀疏数据不同；
- 记录重放检查失败；
- 发现 GT 泄漏；
- 资源不足。
