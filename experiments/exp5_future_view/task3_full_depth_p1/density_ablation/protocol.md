## 3. 指标
- **排序**：在候选集 C 上，按 Task 2 选择规则（`ab_load.pick_of`）得到选点。
  - Top-1：选点增益 ≥ 最大增益 − 1e-4 × 100；
  - Oracle regret：最大增益 − 选点增益（百分点）；
  - Spearman / Kendall：分数与 oracle 增益在 C 上的相关；
  - 选点相对 I10、I100 的变化率；
  - 选点的真实增益。
- **聚合**：状态 → episode 均值 → 场景均值；场景级 bootstrap（10,000 次，seed 0）；所有比较都是同状态配对。
- **几何**（当前相机、候选相机）：
  - 体素比例；
  - t_known 有效率；
  - 深度一致率、中位误差；
  - 伪表面率，两种分母：所有有 GT 的射线、有 GT 且有已知表面的射线；容差为 m × TRUNC·k_M + 0.01·z，m ∈ {1, 2, 3}；
  - UNKNOWN 区段数和长度；
  - 时间与峰值显存。
- **深度量的定义**（单独报告，不混用）：
  - t_band_first：沿射线第一个 structure = BAND 的采样，最近体素，步长 0.5 体素；
  - t_zero：即 t_known，插值零交叉；
  - t_empty_end：第一个不是 EMPTY 的采样；
  - d_gt：GT 第一表面。
- **"入口零交叉"**：零交叉点之前半步（0.5 体素）的插值值 ≥ 0.9 TRUNC，即射线从 BAND 外直接进入负 SDF 区。
- **"深度边缘"射线**：3×3 邻域内存在 GT 深度 < 0.85 × 本射线 GT 深度的射线。
- **GT 新表面（像素级真值，仅评估用）**：候选像素的 GT 表面点到历史全部 10% 采样点（记录 0..t）的距离 > 覆盖容差 eps。
  - eps：MP3D 0.08 × k_I，Macarons++ 用 oracle 的 eps，均为运行时单位；
  - 与覆盖指标的判定规则相同。
- **新颖性掩码**：分别统计 GT 深度、D100 预测和本密度预测的命中点：
  - 被 BAND（膨胀前）和 `band_dil`（膨胀后）排除的比例；
  - 错误排除（真值为新、但被排除）；
  - 错误奖励（真值为旧、但判为新）。

  预测的错误排除再按"预测与 GT 一致（|Δz| ≤ tol）/ 不一致"拆分。
- **预测**（候选相机，K = 4，与 t* 比较；只用两者都有命中的像素）：
  - MAE、RMSE、AbsRel、命中一致率；
  - 按 z_gt / z0 分档：< 0.5、0.5–1、1–2、≥ 2；
  - 按 GT 新 / 旧表面分组；
  - K 间离散度（命中像素上的相对标准差、命中不一致率）；
  - 离散度与误差的 Spearman 相关。

## 4. 闭环筛选规则（冻结）
对 x ∈ {50, 75}，在每个数据集上用两层合并的全部状态，与 I100 场景级配对比较：

- **C1（早期排序改善）**：Early regret 的配对差 ≤ −10% × I100 的 Early regret，且场景胜数（regret 更低）≥ 4（MP3D 5 个楼层、Macarons++ 6 个场景）。
- **C2（整体不变差）**：整体 regret ≤ 1.05 × I100 的整体 regret，且整体 Top-1 ≥ I100 的整体 Top-1 − 0.03。

**判定**：
- 某一档"合格" = 在至少一个数据集上 C1 ∧ C2 成立，且在另一数据集上 C2 成立。
- 两档都合格时，选两个数据集上 Early regret 相对改善的平均值更大的一档。
- **只有合格的那一档进闭环**：使用 Task 2 / Task 3 闭环协议，Dx 输入 + 稀疏评分。
- 都不合格：不跑闭环。

## 5. 闭环判定与 E2 密度推荐（冻结）
- **闭环 Dx（若运行）**：
  - 相对 B0，按 Task 3 协议 §4 的四条标准判定；
  - 同时报告相对 B2 的配对差。
- **推荐 Dx 给 E2 的条件**：相对 B2，两个数据集的 ΔAUC 都 > 0，且 ΔFinal 都 ≥ −0.010。否则推荐 D100。
- **未跑闭环时**：推荐 D100（即 B2 的输入），并标明"尚未证明最优"。
- **备注**：若某档在固定状态上显示早期排序改善、但未进闭环，或闭环未达标，只能作为候选，不能称为最优。
