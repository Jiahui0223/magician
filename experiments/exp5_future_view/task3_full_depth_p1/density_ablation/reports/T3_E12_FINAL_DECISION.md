## 2. 对研究问题的回答
- **Q1 BAND 密度是否越高越好？**
  - 几何：是，但在 50% 基本饱和。
  - 输入端的排序：Macarons++ 上越密越好（I100 在 6/6 个场景优于 I10）；MP3D 上四档无可分辨差别。
  - 评分端：不是。见 Q5。
- **Q2 50% 或 75% 是否比 100% 更适合冻结的 V2-Mix？** 否。
  - MP3D：I75 的 Early regret 低 0.018，但几乎全部来自一个楼层，不满足冻结的筛选规则；
  - Macarons++：I50 明显更差，I75 略差于 I100。
- **Q3 密度如何影响各部件？**
  - 3D 编码器输入的 BAND 占比 ×1.6–2.4；射线特征中 t_known 有效率 +13 到 +24 个百分点，UNKNOWN 区段减少约 30%；
  - 预测：已观测表面的误差降低 30–40%，真正新表面的误差略升（+4% 到 +12%），K 个样本的离散度降低约 40%；
  - 候选排序：只在 Macarons++ 上有小而一致的改善。
- **Q4 100% BAND 的伪表面增加是什么？** 主要是深度边缘处前景表面的侧向加粗（体素化 + 截断带），属于表示层面的真实几何误差。
  - 不是阈值：容差放宽 3 倍只降低约 25%；
  - 不是首个 BAND 命中：`t_known` 本来就是零交叉，入口零交叉 < 0.3%；
  - 量级：全部 GT 射线的 2–4%。
- **Q5 DistP1 在高密度 BAND 下是否过度排除真实新表面？** 是。
  - 以 GT 深度作完美预测时，错误排除从 3.3% / 7.0% 升到 10.7% / 15.1%，同时错误奖励从 18.6% / 13.5% 降到 10.6% / 9.9%；
  - 室内净收益（S100 regret −0.035，5/5 个楼层），室外净损失（+0.047，2/4）；
  - 只有约 6–7% 的"真值新"表面属于"已被完整深度看到、但覆盖指标未计"的定义差异，两个数据集量级相同，不能解释方向相反。
- **Q6 E2 Pilot 使用哪个密度？** **D100**（即 B2 的输入）。按冻结规则，D50、D75 都不合格，不跑闭环，默认使用 100%。理由：
  1. 输入端排序在 Macarons++ 上随密度单调改善，100% 最好；MP3D 无差别；
  2. 50% 已拿到约 85% 的几何收益，但排序上不如 100%；
  3. 显存与密度无关，融合时间多约 75%（0.34 → 0.59 s / 步），可接受；
  4. 与 B2 闭环结果直接衔接：B2 闭环两个数据集的 Final 都提高。

  **标注**：100% 是"冻结模型下的默认选择，尚未证明对微调后的模型最优"。

## 4. 对 E2 设计的含义
- **评分端保持稀疏 10%**（任务书原则）。本轮显示：
  - 稠密评分对 MP3D 有益、对 Macarons++ 有害；
  - 效应是"稀疏 vs 非稀疏"的阶跃，与具体密度无关；
  - 若以后要改评分端，应作为单独的问题研究（例如按场景尺度调整排除带宽），不在 E2 中混入。
- **E2 能检验的问题**：
  - 冻结模型在稠密输入下对真正新表面的预测略变差、样本更趋一致，这是可以通过微调解决的分布外问题；
  - E2 的核心检验是：微调后，新表面误差和 Early 排序能否同时改善。
