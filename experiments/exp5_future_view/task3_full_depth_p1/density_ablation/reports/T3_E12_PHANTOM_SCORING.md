**结论（Q4）**：
1. **不是诊断阈值造成的**：容差放宽到 3 倍只降低约 25%；伪表面的中位位置在 GT 前方 9–21 个截断距离，远超任何截断带宽。
2. **不是首个 BAND 命中与零交叉的差异**：`t_known` 本来就是零交叉；"射线从带外直接进入负 SDF"的入口零交叉只占 0.1–0.3%。
3. **主要是深度边缘处前景表面的侧向加粗**：深度边缘射线只占约 5%，却贡献约一半的伪表面；边缘射线的伪表面率（27–39%）是非边缘射线的约 20 倍。
   - 机理：经过前景物体轮廓附近的射线，落入前景表面 BAND 的体素（体素化 + ±3 体素截断带的侧向范围），在背景表面之前得到零交叉。
   - 稠密化让更多轮廓像素写入 BAND，所以伪表面随密度上升。细长结构是极端情况（bridge s1 t80：拉索，候选相机 32%）。
4. **因此它是 P1 表示本身的几何误差**（真实深度经体素化后的边缘膨胀），而不是统计口径造成的表观差异。量级不大：全部 GT 射线中约 2–4%。

## 3. 三种深度的对比（中位偏差，单位 TRUNC，负 = 在 GT 之前）
| 量 | MP3D 当前相机 D10 → D100 | MP3D 候选相机 | Macarons++ 当前相机 | Macarons++ 候选相机 |
|---|---|---|---|---|
| t_zero（零交叉） | +0.11 → +0.005 | +0.49 → +0.27 | +0.84 → +0.74 | +0.99 → +0.87 |
| t_band_first（首个 BAND 体素） | −0.74 → −1.27 | −0.42 → −0.90 | −0.32 → −0.56 | −0.05 → −0.33 |
| t_empty_end（EMPTY 结束） | −20.0 → −20.4 | — | −9.5 → −9.8 | — |

- **首个 BAND 命中系统性偏近**：约 1 个截断距离，正是截断带的前沿，越密越接近 −1。模型使用的零交叉不受影响，反而随密度更接近 GT。
- **EMPTY 结束远在表面之前**（约 10–20 TRUNC），四档相同，因为 EMPTY 规则不变。原因是冻结的挖空规则在表面前 3 体素停止，且射线间留有未挖空的 UNKNOWN 间隙（与 `p1-porous-band` 的发现一致）。它不是表面深度估计，不能与 t_zero 混用。

## 4. DistP1 是否过度排除真实新表面（Q5）
**是**，从 10% 换到任何更高密度时都发生，而且在 50% 就基本饱和。

以 GT 深度作为完美预测（全部状态）：
| 数据集 | 错误排除 | 错误奖励 |
|---|---|---|
| MP3D | 3.3% → 10.7% | 18.6% → 10.6% |
| Macarons++ | 7.0% → 15.1% | 13.5% → 9.9% |

**四类原因分别核查**：
| 原因 | 证据 | 判断 |
|---|---|---|
| P1 本身的错误几何 | 伪表面只占全部 GT 射线的 2–4%；仅被稠密地图排除的像素中，位于深度边缘的只有 9–13% | 次要 |
| 首个 BAND 命中与零交叉的差异 | DistP1 用的是**体素成员关系**（命中点所在体素是否在 `band_dil` 中），与零交叉无关；但截断带 ±3 体素再加 1 体素膨胀，使紧贴已观测表面的新表面落入排除区 | 机制之一（带宽本身） |
| 评分掩码过度排除 | 稠密 BAND 的膨胀区比稀疏的连续得多。膨胀前 BAND 已排除 5.6% / 9.6% 的真值新射线，膨胀后为 10.7% / 15.1%，膨胀约翻倍 | 主要 |
| 统计定义造成的差异 | 覆盖指标只用 10% 采样点。被"看见过"（距历史完整深度点 ≤ eps）却仍算作"新"的真值新表面：MP3D 6.3%，Macarons++ 6.8%；随探索推进上升（Early 4–5% → Late 15–17%） | 存在但较小，两个数据集量级相同，不能解释室内外方向相反 |

**室内外方向相反的原因**：两个数据集的过度排除幅度相近（+7.4 / +8.1 个百分点），差别在收益端和分数结构。
- 室内稀疏 BAND 的空洞带来大量错误奖励（膨胀后 18.6%），稠密化减少 8.0 个百分点；
- 室外只减少 3.6 个百分点；
- 室外候选分数常接近并列，少量错误排除即可翻转选点（Fig 5 neuschwanstein：39 条真新射线被排除，regret 0 → 7.9 pp）。

**75% 是否比 100% 少犯这种错**：几乎没有。错误排除 MP3D 9.9% vs 10.7%，Macarons++ 14.7% vs 15.1%；排序 S75 ≈ S100。
