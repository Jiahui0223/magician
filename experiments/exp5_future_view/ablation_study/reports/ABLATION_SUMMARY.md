# EXP5 Ablation A1 / A2 总结（2026-10-28）

**详细报告**：`../A1_prediction_scoring/A1_REPORT.md`、`../A2_stochastic_future_views/A2_REPORT.md`。

**协议与偏差**：`../protocol.md`（v1.0，正式运行前冻结）、`../DEVIATIONS.md`。

**数据**：
- MP3D：368 个固定状态，5 个 val 楼层 × 2 个起点；
- Macarons++：1,093 个固定状态，Test-3 + Dev-3 × 5 个起点；
- 状态来源：Task 2 中 V2O、V2M、MAG-G、MAG-B 的真实闭环轨迹，时间点为任务书时间 + 5 步；
- 模型：V2 Original（`a379c0fb…`）与 V2-Mix（`343f41ab…`），只加载，不重训、不重选。

**Test-3 的身份**：Task 2 已解封。本次的分析结论不再属于盲测。

## 1. 一句话结论
**预测确实在改善排序**：V2-Mix 让同一状态下的一步选点明显更接近 oracle。

**但离"完美选点"还差的部分中**：
- **室内**约一半是**评分 / 规划区域**的问题，即使深度完全正确也选不对；
- **室外**仍以**预测误差**为主；评分误差中有一部分来自 P1 地图空洞（已覆盖却被当作新表面）。

**4 个随机样本的作用**：在当前"取均值再 DistP1"的用法下，K = 4 几乎不改变决策。它们的分歧其实是有信息量的不确定性，但目前没有被利用。

## 2. Prediction Quality → Ranking Quality → Camera Selection
| | MP3D | Macarons++ |
|---|---|---|
| Fair ES：V2O → V2M | 27.8 → 10.7 | 16.2 → 9.6 |
| Brier：V2O → V2M | 0.214 → 0.107 | 0.171 → 0.126 |
| Spearman(score, oracle gain)：V2O / V2M / GT 深度 | 0.43 / 0.55 / 0.66 | 0.52 / 0.61 / 0.75 |
| Top-1（并列容差 0.01 pp）：V2O / V2M / GT 深度 / 随机 | 0.41 / 0.56 / 0.69 / 0.26 | 0.49 / 0.55 / 0.69 / 0.23 |
| 一步 regret (pp)：V2O / V2M / GT 深度 / 随机 | 0.210 / 0.119 / 0.064 / 0.352 | 0.607 / 0.482 / 0.160 / 1.268 |
| V2M − V2O regret（场景 CI） | −0.091 [−0.134, −0.051] | −0.124 [−0.227, −0.039] |
| V2M regret 中评分误差（GT 深度）的占比 | 54% | 33% |

**1. 预测 → 排序：成立。**
- 同一状态、同一候选集、同一噪声下，V2-Mix 的 Spearman、Top-1 和 regret 在所有场景上都好于 V2 Original（MP3D 5/5，Macarons++ 6/6），CI 不含 0。
- 但逐状态看，ES 的改善与 regret 的改善只弱相关（Spearman：MP3D 0.20，Macarons++ 0.06）。两个模型 regret 相同的状态约占 60%（MP3D）和 70%（Macarons++）。

**2. 评分的上限：完美深度也有约 31% 的状态选错。**
- **室内主因：规划区域裁剪。**
  - GT 深度选错的状态里，oracle 最优候选平均 53% 的增益在 V2 的 13 m 规划区域之外；
  - 只计区域内增益时，GT 深度的 Top-1 从 0.69 升到 0.81；
  - 平均只有 26% 的剩余未覆盖表面在当前区域内。
- **室外**：DistP1 会把两类表面当作新表面：
  - 规划器地图（P1）中的小空洞：已观测表面上，因 10% 采样在 P1 里仍是"未知"，但覆盖评估已算作覆盖；
  - 不在评估点集里的表面，例如靠近相机的地面。
  - 统计：GT 深度选错的状态里，被选候选的新表面只有 74% 与评估相关，选对时为 88%。在射线计数上过滤不相关表面，Top-1 从 0.52 升到 0.58；再过滤已覆盖表面，升到 0.62。
  - 案例（pantheon t = 55）：GTD 选中的候选，新表面中 88% 已被覆盖、12% 不在评估点集里，增益为 0。
- **距离权重本身是有益的，而且作用最大**：去掉后 Top-1 降到 0.55 / 0.58；只计"有用"射线但不加距离权重，Top-1 也只有 0.55 / 0.62，仍不如 DistP1 的 0.69。

**3. 排序 → 闭环：一步排序更好，不等于闭环更好。**
- 以 MP3D 为例，V2-Mix 把一步 regret 降低了 43%，但 Task 2 的闭环 AUC@150 只提升 0.007。
- MAGICIAN 实际执行动作的一步 regret（MP3D 0.79 pp）远差于 V2，但闭环差距小得多。它的 beam 规划会牺牲一步增益。
- 这些"Exec"比较各自用自己轨迹的状态，只能作为间接证据。

## 3. Stochastic Future View Sampling → Decision Value
- **多样性真实存在**：MP3D 上约 23–27% 的标签射线，4 个样本对是否命中不一致；新表面两两相距 11–19 cm。V2-Mix 更分散，也更准。
- **多样性是有信息量的不确定性**（V2-Mix 尤其明显）：
  - 样本分歧与误差的 Spearman：MP3D 0.79 / 0.84，Macarons++ 0.39 / 0.73。V2 Original 的分歧与 Brier 几乎无关（0.16）。
  - 4 个样本分数的标准差与 |预测 − GT 深度 DistP1| 的相关为 0.71–0.79。
- **但对决策的价值很小**：
  - 平均 85–92% 的单样本选点与 K = 4 选点相同；
  - K = 4 的 regret 与单样本平均几乎一样：MP3D V2M 0.119 对 0.129；V2O 0.210 对 0.203，K = 4 反而略差；
  - 独立种子集的 K ∈ {1, 4, 8, 16} 消融见 §4。
- **失败是系统性的，不是采样噪声**：
  - 高分失败状态中，被选候选的最大样本占比（约 0.30）与全体状态相同；
  - 去掉最高样本后，选点改变的只有 12–17%；
  - 4 个样本一致地高估同一个候选。
- **幻象遮挡物**：在 GT 第一个交点就是已知表面的射线上，单个样本有 31–39% 的概率在其前方的未知区里生成表面。V2-Mix 比 V2 Original 更多：MP3D +0.066 [0.048, 0.083]，Macarons++ +0.036 [0.017, 0.064]。即 V2-Mix 在"漏检"上大幅改善的同时，更倾向于填补未知区。

## 4. K 消融（任务书时间点：MP3D 170 个状态、Macarons++ 506 个状态；4 组独立种子集）
| | MP3D V2O | MP3D V2M | Macarons++ V2O | Macarons++ V2M |
|---|---|---|---|---|
| Regret K = 1 / 4 / 8 / 16 (pp) | 0.188 / 0.181 / 0.187 / 0.185 | 0.129 / **0.101** / 0.103 / 0.100 | 0.616 / 0.610 / 0.615 / 0.622 | 0.477 / 0.463 / 0.466 / 0.472 |
| 选点稳定性 K = 1 → 16 | 0.85 → 0.95 | 0.79 → 0.94 | 0.87 → 0.97 | 0.82 → 0.95 |
| 每候选耗时 K = 1 / 4 / 16（s，非独占） | 0.037 / 0.071 / 0.242 | 同左 | 0.032 / 0.059 / 0.228 | 同左 |

- **唯一显著的改善**：V2-Mix 在 MP3D 上从 K = 1 到 4，regret −0.029 pp [−0.064, −0.009]，Top-1 +0.025。
- K > 4 没有额外收益，其余组合都不显著。
- 增加 K 主要让选点更可重复，而不是更好。

## 5. 对 V3 的启示（按优先级；带"推测"的是假设，需实验验证）
1. **规划视野 / 区域，优先级最高，尤其是室内。**
   - 室内剩余 regret 中约一半来自评分 / 区域：GT 深度在区域裁剪下仍有 31% 选错，且错误主要来自区域外增益。
   - 这与 T0.12-C 和 Task 2 的观察一致：n_win 从 3 改为 5，AUC 从 0.266 升到 0.315；TbHJ 上 MAGICIAN 仍领先。
   - 只提升预测质量，室内的一步 regret 最多还能从 0.119 降到 0.064 pp。
   - 方向：整层或多区域的候选评估、超出区域的收益估计、多步规划。
2. **评分函数：保留距离权重，并对准"有用的表面"。**
   - 距离权重是排序质量最重要的因素之一，不应去掉。
   - 在室外，DistP1 有一部分分数来自规划器地图（P1）空洞里实际已覆盖的表面，以及评估不计分的表面（地面等），过滤后（不加权）排序有改善。
   - 推测：带距离权重、且只计目标表面的计分方式能进一步缩小室外的评分缺口。这需要先在固定状态上离线检验，再进闭环。
   - 注意：直接对齐评估点集有"按指标调参"的风险，需在另一组场景上验证。
3. **预测仍是室外的主要瓶颈（约 2/3 的 regret）。**
   - VAE / Cross-Attention 这类改进在室外的潜在收益更大；
   - 在室内，收益上限受第 1、2 条限制；
   - 应重点处理幻象遮挡物与近墙预测过远的问题：远处的错误表面会被距离权重放大。
4. **利用样本分歧而不是取平均（推测）。**
   - 样本分数的离散度能指示均值分数的可靠性，但 K = 4 取均值几乎不改变决策；
   - 可以先在固定状态上离线比较风险敏感的评分（例如均值减去 λ·标准差）或基于分歧的探索项，再决定是否保留 K = 4；
   - 如果都无益，K = 1 可以把推理成本降为 1/4。

## 7. 局限
- **场景数量少**：MP3D 只有 5 个楼层；Macarons++ 只有 6 个场景，且每个划分（Test-3 / Dev-3）只有 3 个场景，CI 可靠性有限。
- **Test-3 不再是盲测**：本次分析用到了它。
- **一步 oracle 不等于长期价值**："一步 regret → 闭环"的关系目前只有间接证据。建议下一步做 **GT 一步贪心闭环上界**：在同样 10 条室内 episode 上用 oracle 一步增益选点，与 V2M 和 MAGICIAN 对比。
- **附加诊断不在冻结协议中**：区域、相关性、幻象遮挡和 GTDn 都是附加诊断（DEVIATIONS #6–#10），只作解释，不改变协议指标。
- **案例只是示例**：案例按事先规则自动挑选，有两个是退化状态，已如实说明。挑选规则偏向绝对增益很小的后期状态。
