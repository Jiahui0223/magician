## 3. A1 — 三种评分与排序指标
### 3.1 三种评分
- **S_pred(m)**：模型 m 的 K = 4 样本 DistP1 均值，即线上规划实际使用的分数（`v2_plan_core.score_state`）。
- **S_GTD**：真实深度 DistP1。
  - t* = 候选位姿下 64 × 114 条打分射线与 GT 网格的第一个交点（jitter 0，T1.1 / T2.1a 的渲染器）；
  - 超过 tmax 的视为无交点；
  - 送入冻结的 `new_set_from_depth`：同一几何、同一扩张 BAND、同一体素去重、同一距离权重 min(1, (z/z0)²)；
  - 这正是 Task 1 的 `truedepth_distp1` 规则；
  - 落在已知 BAND 或区域外的交点不计入；
  - 只作离线诊断。
- **G_oracle**：真实一步覆盖增益，单位为覆盖率（报告时 ×100 = 百分点）。
  - **MP3D**：冻结的 C_obs 评估器，规则与 T0.12-C 的 `t12c_oracle.py` 相同：
    - 用冻结传感器渲染候选位姿，按模拟器第 t+1 帧的种子做 10% 采样；
    - 增益 = 新覆盖的可见 GT 点 / 全部可见 GT 点；
    - 回放覆盖必须与保存曲线一致（误差 ≤ 1e-12），被执行候选的采样必须与记录 t+1 逐位一致，否则 STOP。
  - **Macarons++（主口径）**：Task 2 的单调覆盖评估器（`t25_out_cov.py` 的规则）。
    - 增益 = 新覆盖 GT 点 / |GT| / 可见比例；
    - 动作评估用 T7a 的快照 / 恢复评估器（`m_gain_eval`，种子为 t+1）。
  - **Macarons++（次口径）**：官方覆盖增益（每格有上限，可能为负）。
  - **室外检查**：官方覆盖回放必须与保存曲线相同；合法 key 列表必须相同；被执行动作的采样和覆盖必须与记录 t+1 相同。

### 3.2 选择规则（与线上相同）
- **MP3D**：在候选集上取 argmax，并列取最小索引；全部 ≤ 0 时，用 `exp5-T0.10|NV|T2|<group>|<tag>|<t>` 种子随机选。
- **Macarons++**：`m_score.choose`，即 argmax、并列取最小索引；全为 0 时按 `m_common.fallback_choice`。
- 预测分数和 GTD 分数都用这套规则选点。

### 3.3 排序指标
- **Spearman**：分数与 G_oracle 的平均秩相关。
  - 候选少于 2 个、或任一方为常数时无定义，单独计数，不当作 0。
- **Top-1（主口径，考虑并列）**：G(选中) ≥ max G − τ，τ = 1e-4（0.01 个百分点）。同时报告严格 Top-1（τ = 0）。
- **Pairwise accuracy**：只看 |ΔG| > τ 的候选对；方向一致计 1，分数并列计 0.5。
- **Oracle regret**：max G − G(选中)，单位百分点。同时报告归一化 regret = regret / max G（仅 max G > τ 的状态）。
- **一致率**：预测最优、GTD 最优、oracle 最优三者两两一致的比例（考虑并列）。
- **随机参照**：期望 Top-1 = 并列最优数 / |C|，期望 regret = max G − mean G。
- **误差分解**：
  - 预测保真度 = Spearman(S_pred, S_GTD)；
  - 评分保真度 = Spearman(S_GTD, G_oracle)；
  - 可归因于预测的 regret = regret(pred) − regret(GTD)。

### 3.4 预测质量（每个候选，再在状态内对候选集取平均）
- **标签**：`geometry.encode_labels`。只用 M_unknown 且有标签的射线（lm = M_unknown ∧ b ≠ 0），与 Task 1 / 2 选择集的评估口径相同。
- **fair ES**：未知弧长坐标（体素）下的 K = 4 fair Energy Score，公式与 `t12_train.eval_samples` 相同，只是按单个视角计算。
- **Brier**：命中概率 p = K 个样本中命中的比例，对 HIT 标签计算。
- **假表面率**：标签为 NOHIT 的射线上 p 的均值。
- **漏检率**：标签为 HIT 的射线上 1 − p 的均值。
- **深度相对误差**：样本与标签同为未知区命中的射线上 |t̂ − t*| / t*。

### 3.5 汇总
- **层级**：状态 → episode（场景 × 起点 × 第一来源）→ 场景（楼层）。
- **均值**：场景均值的平均。
- **置信区间**：MP3D 在 5 个楼层上 bootstrap（10,000 次，seed 0）；Macarons++ 在 6 个场景上 bootstrap，另报 Test-3 / Dev-3 各自的场景均值（各 3 个场景，不给 CI）。
- **配对差**：V2M − V2O 按场景配对。
- **分层**：场景、t（early / mid / late）、当前覆盖率、max G、|C|、刷新步 / 陈旧步、来源组。

## 4. A2 — 随机未来视角假设
- **保存的数据**：每个状态、每个合法候选、每个模型的 4 个样本：
  - 原始 (b, y)、解码深度 t̂ 和未知区命中掩码；
  - 每个样本的 DistP1；
  - 射线类别：新预测命中、未知区命中但不算新（落在扩张 BAND 中）、已知表面命中、无命中、无效；
  - 标签类别、t*，以及 GT 的新表面掩码。
- **逐样本质量**：假表面率、漏检率、新命中精度、深度相对误差、到 GT 新表面的 Chamfer 距离。
- **多样性**（附定义，单位见报告）：
  - Hit 分歧：K 个样本命中不一致的 lm 射线比例，以及样本两两之间的不一致率；
  - 条件深度多样性：两样本都命中的射线上 |t̂_i − t̂_j|，换算到运行单位（MP3D 换算为米）；
  - 几何多样性：两两新表面点云的对称 Chamfer 距离；体素 Jaccard 距离作为辅助指标。
- **样本对选点的影响**：
  - 每个样本单独打分（K = 1）的选点，与 4 样本均值（K = 4）选点的一致率；
  - 留一法：去掉某一个样本后选点是否改变（"关键样本"）；
  - 被选候选的最大样本占比；
  - K = 4 的 regret 与 4 个 K = 1 regret 的平均值对比。
- **K 消融**：
  - K ∈ {1, 4, 8, 16}；4 组相互独立的种子集（`exp5-ABL|K|<sid>|r<r>|k<k>`），每组 16 个样本，组内取前 K 个；
  - 嵌套前缀之间相关，选点稳定性用不同种子集之间的选点一致率计算；
  - 每个候选的耗时取 r = 0 的单独计时，在共享 GPU 上测得，非独占计时。

  - 同一状态下各候选的四种分数和 oracle 增益；
  - 选中候选与 oracle 最优候选的对照；
  - ES / Brier 与 regret 的关系；
  - 场景级 regret 与 Top-1。
- **A2**：
  - 统一色标的 2D 深度面板：GT 与 4 个样本；
  - 3D 叠加：灰色为已观测几何，4 种颜色为 4 个样本的新表面，黑色为 GT 新表面；
  - 标注每个样本的 DistP1、均值、选中 / 最优候选、增益和 regret。
- **案例按事先规则自动挑选**（不挑对 V2-Mix 有利的）：
  - 成功：选中 = 最优，max G 最大；
  - 预测失败：V2M 归一化 regret ≥ 0.5 且 GTD 选对，取 regret 最大者；
  - 评分失败：GTD 归一化 regret ≥ 0.5，取最大者；
  - 随机歧义：4 个 K = 1 选点中至少 3 个不同，或存在关键样本，取被选候选样本占比最大者；
  - 某类不存在时如实报告。
