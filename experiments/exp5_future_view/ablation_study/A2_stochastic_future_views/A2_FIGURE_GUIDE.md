# A2 图阅读指南（v2，2026-10-28，按用户设计重做）

**位置**：
- 案例图：`A2_stochastic_future_views/figures/v2/`；
- 统计汇总图：`figures/fig_quality_diversity.png`；
- 旧版的 depth_ / 3d_ / orbit_ 图已删除。

**生成**：`a2v2_render.py`（渲染 RGB 和深度）+ `a2v2_viz.py`（作图）。

**数据来源**：图中所有深度和 3D 点都来自真实模型输出（4 个样本解码后的深度）和真实 GT。照片是用冻结传感器的相机参数渲染的：
- MP3D：带纹理的 matterport_mesh。候选位姿是网格位姿，没有对应的真实照片。
- Macarons++：MAGICIAN 渲染器。

当前相机的渲染深度与保存的观测记录一致：MP3D 最大差约 1e-4，Macarons++ 完全相同。

## 1. 一张图是什么
- **一张图 = 一个固定状态下的一个候选相机。**
- **文件名**：`<数据集>_<案例>_<模型>_<角色>_j<候选编号>.png`。
- **角色**：
  - `pick`：该模型选中的候选；
  - `best`：oracle 最优（真实一步覆盖增益最大）；
  - `gtdpick`：用真实深度算 DistP1 时会选的候选（只在它与前两者不同时才画，主要用于评分失败案例）。
- **模型**：`V2M` 是 V2-Mix，`V2O` 是 V2 Original。两者在同一状态、同一噪声下比较。
- **标题第 2 行**：
  - 这个候选的 oracle 增益及其排名；
  - 真实深度下的 DistP1；
  - 模型的平均 DistP1（线上实际使用的分数）及其排名；
  - 模型选了谁、oracle 最优是谁、regret。

## 2. 版式（3 行 × 6 列）
| | 第 1 列：当前相机（第 t 步） | 第 2–5 列：样本 1–4（候选相机） | 第 6 列：候选相机的真实情况 |
|---|---|---|---|
| 第 1 行 | 当前相机的照片 | 每个样本的数字（见 §4） | 候选位置的照片 |
| 第 2 行 | 当前深度（全部已观测，灰度：浅 = 近） | 预测深度 | 同一组射线上的真实深度 |
| 第 3 行 | 到第 t 步为止观测到的所有点（灰），● 当前相机，▲ 候选相机及朝向 | 预测深度反投影出的 3D 结构 | 真实深度反投影出的 3D 结构 |

阅读顺序：从左到右是"现在看到什么 → 模型想象候选位置会看到什么 → 候选位置实际会看到什么"。

## 3. 颜色（第 2、3 行，第 2–6 列）
| 颜色 | 含义 |
|---|---|
| 灰色（固定） | 已经观测过的表面 |
| 黄 → 紫渐变 | 还没观测过的表面，颜色表示深度：黄 = 近，紫 = 远。4 个样本和真实值**共用同一色标**（底部色条） |
| 白色 | 量程内没有表面；对预测而言，也包括 V2 规划区域之外（模型在区域外不做预测） |
| 第 6 列的红色虚线 | 真实的未观测表面在 V2 规划区域之外：真实存在、能带来覆盖增益，但 V2 看不到 |

- **深度定义**：沿光轴的 z 深度；MP3D 单位为米，Macarons++ 为场景单位（非米制）。
- **"已观测"的判定**：
  - 预测：射线打到规划器地图（P1）里的已知表面；
  - 真实值（区域内）：真实交点在 P1 已知表面上；
  - 真实值（区域外）：交点附近（覆盖评估的 eps 内）有已观测点。
- **射线网格**：第 2 行的样本与真实深度都是 64 × 114 打分射线网格，每格对应原图 4 × 4 像素块的中心。照片和第 1 列深度是全分辨率。
- **灰色与彩色交错的细碎斑点**：已观测表面上，规划器地图里有小空洞（远处只有 10% 的点被采样）。这些空洞在 P1 里算"未知"，所以真实深度也会把它们画成彩色。它们正是评分失败的来源之一（见 §6）。

## 4. 第 1 行每个样本的数字
"真实新表面"指第 6 列中区域内的彩色射线。

| 项 | 含义 |
|---|---|
| DistP1 | 该样本单独的打分。线上使用 4 个样本的平均 |
| predicted new-surface rays | 该样本在未观测区域预测出表面的射线数 |
| of them really new surface | 其中真实也是"区域内新表面"的比例，即精度。低说明大多是幻象 |
| true new surface recovered | 真实新表面被该样本预测到的比例，即召回。低说明漏检多 |
| median \|depth error\| | 预测与真实都有新表面的射线上，深度误差的中位数 |
| phantom on observed rays | 真实是已观测表面的射线中，样本在它前面"造"出新表面的比例（幻象遮挡） |

## 5. 怎么判断"好坏"
1. **看第 2 行**：样本的彩色区域是否和第 6 列一致。
   - 位置一致：结构对了；
   - 颜色一致：深度对了；
   - 样本是彩色而真实是灰色：**幻象**；
   - 真实是彩色而样本是白 / 灰：**漏检**；
   - 第 6 列红色虚线内：V2 看不到的区域外收益。
2. **看第 3 行**：每个样本重构出的 3D 结构是否像第 6 列。可以看出墙、地面是否连续，是否有悬空的面，以及深度是否被推远。
3. **比较 4 个样本之间**：4 列形状接近，说明预测确定；差异大，说明不确定。某一个样本远离其他 3 个、DistP1 又特别大，就是单样本主导。
4. **最后看标题**：模型排名与 oracle 排名不一致时，结合 GTD 判断。
   - GTD 排对了，问题在预测；
   - GTD 也排错，问题在评分或区域。

## 6. 案例速查（V2M）
| 图 | 应该看到什么 |
|---|---|
| `indoor_success_V2M_pick_j3` | 早期 t = 5，增益 5.95 pp。样本的大块彩色区域与真实一致，模型选对 |
| `indoor_prediction_fail_V2M_pick_j1` / `_best_j8` | 后期 t = 140，所有增益都很小（最优 0.013 pp）。所选候选的样本只有零散的彩色碎片 |
| `indoor_scoring_fail_V2M_pick_j5` / `_gtdpick_j3` | **区域裁剪**：所有候选在区域内都没有真实新表面（GTD 都为 0）。最优的 j5 在第 6 列右上有一大片**红色虚线圈出的远处表面**（区域外），增益 0.292 pp。V2M 碰巧选对；GTD 全为 0，只能退回默认选择，所以选错（j3，增益 0） |
| `indoor_stochastic_nondegenerate_V2M_pick_j2` / `_best_j1` | j2：真实左侧是**黄色近墙**（约 0.5 m），4 个样本都画成青绿到紫色（2–4 m），3D 行里是房间中间悬空的面；深度误差中位数 1.1–2.5 m，DistP1 103–416。j1（最优）：真实下半部是近处地面，样本大片漏掉 |
| `outdoor_success_V2M_pick_j5` | t = 0，增益 17.9 pp，4 个样本与真实一致 |
| `outdoor_prediction_fail_V2M_pick_j0` | 第 6 列**整片灰色**：视野里全是已观测表面，没有新东西。4 个样本都画出大片彩色表面，精度 0%，幻象遮挡 38–42%，regret 1.49 pp |
| `outdoor_scoring_fail_V2M_gtdpick_j5` | GTD = 246，但增益为 0。第 6 列的"新表面"由两部分组成：建筑表面上的**细碎斑点**（P1 地图空洞），以及底部一条**地面带**。核算这个候选的真实新表面射线：88% 落在评估点集上，但这些点**100% 已被覆盖**，只有约 12% 不在评估点集里（地面）。DistP1 把"地图空洞"当作新表面，是这里的主要失败原因 |
| `outdoor_stochastic_nondegenerate_V2M_pick_j7` | sample 4 把上半部预测成**很远的表面**（紫色），真实情况是近处（黄绿色），深度误差中位数 7.07（其他样本 2.3–3.1）。远处被距离权重放大，DistP1 = 2200（其他约 400），一个样本把均值抬过了最优候选 |
| `*_stochastic_*`（按规则选出） | 退化状态（分数和增益都约为 0），仅为如实保留 |

## 7. 统计汇总图 `fig_quality_diversity.png`
| 列 | 内容 | 怎么读 |

## 8. 局限
- 3D 散点没有遮挡关系，第 3 行用统一的斜后方视角；前后层次以第 2 行为准。
- 已观测 / 未观测按规划器地图（P1）判定，与覆盖评估的"已覆盖"并不完全相同，前述空洞斑点就是两者的差异。
- 案例只是示例，结论以统计表为准；失败案例的挑选规则偏向绝对增益很小的后期状态。
