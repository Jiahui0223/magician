## 2. 回答任务书的问题
### Q1 预测指标改善是否对应排序改善？
**是。** 在同一状态、同一候选集、同一噪声下，V2M − V2O 的场景配对差如下：

| 指标 | MP3D | Macarons++ |
|---|---|---|
| ES | −17.1 | −6.6 |
| Brier | −0.107 | −0.045 |
| Spearman | +0.124 [0.108, 0.145] | +0.085 [0.046, 0.134] |
| Top-1 | +0.142 [0.096, 0.197] | +0.057 [0.019, 0.101] |
| Regret | −0.091 pp [−0.134, −0.051] | −0.124 pp [−0.227, −0.039] |

- **场景方向一致**：MP3D 5/5 个楼层、Macarons++ 6/6 个场景都是 regret 下降、Spearman 上升；bridge 的 regret 只降了 0.008。
- **预测保真度 ρ(pred, GTD)**：MP3D 从 0.612 升到 0.807，Macarons++ 从 0.615 升到 0.709。

**但逐状态看，关系很弱**：
- ΔES 与 Δregret 的 Spearman 在 MP3D 上只有 0.20，在 Macarons++ 上只有 0.06；
- V2M 比 V2O regret 更低的状态只占 29%（MP3D）和 19%（Macarons++），更高的占 11%，其余状态两者 regret 相同；
- 预测改善是整体平移，只在部分状态上改变了选点（图 `fig3_pred_vs_rank.png`）。

### Q2 V2-Mix 是否比 V2 Original 更接近 oracle？
**是。**
- **MP3D**：V2M 把"预测造成的 regret"（regret − GTD regret）从 0.145 降到 0.054 pp，即消除了约 63%；与 oracle 最优一致的比例从 0.413 升到 0.555。
- **Macarons++**：从 0.447 降到 0.322 pp，只消除了约 28%。室外的预测仍是主要误差来源。

### Q3 GT 深度 DistP1 与 oracle 差多少？
即使深度完全正确，DistP1 仍有约 **31%** 的状态选不到 oracle 最优（两个数据集的 Top-1 都约为 0.69）：

| 指标 | MP3D | Macarons++ |
|---|---|---|
| Spearman | 0.657 | 0.750 |
| Regret | 0.064 pp（归一化 0.18） | 0.160 pp（归一化 0.14） |

### Q4 是否存在明显的 Scoring Gap？
**存在，而且在 V2-Mix 之后，室内已与预测误差同量级**。V2-Mix 的 regret 可分解为"GTD 的评分误差 + 预测误差"：

| 数据集 | V2M regret | 评分误差（GTD） | 预测误差 | 评分误差占比 |
|---|---|---|---|---|
| MP3D | 0.119 pp | 0.064 | 0.054 | 54% |
| Macarons++ | 0.482 pp | 0.160 | 0.322 | 33% |

**评分误差集中在哪里**（GTD 的归一化 regret，`fig5_strata.png`）：

| 阶段 | MP3D | Macarons++ |
|---|---|---|
| 早期 | 0.105 | 0.085 |
| 后期 | 0.241 | 0.285 |

最优一步增益最小的三分位里，MP3D 为 0.274。也就是说，探索后期、各候选增益都很小且接近时，DistP1 与真实覆盖的排序最容易不一致。

**原因**（有证据的部分）：
- **不是距离权重**：去掉距离权重（GTDn）后排序明显变差。MP3D Top-1 从 0.693 降到 0.552，regret 从 0.064 升到 0.170；Macarons++ 同样变差。距离权重 min(1, (z/z0)²) 是在帮忙。
- **室内：规划区域裁剪是主要来源**（附加诊断 `a1_region_diag.py`，DEVIATIONS #7）。按 T0.12-C 的拆法，把每个候选的 oracle 增益分成 V2 规划区域（n_win = 5，约 13 m）内、外两部分：
  - **GTD 选错时最优候选的增益多在区域外**：在 GTD 选错的 115 个状态里，oracle 最优候选平均 **53%** 的增益落在区域外；选对的状态里只有 20%。
  - **只看区域内增益，GTD 的排序明显变好**：Top-1 从 0.688 升到 **0.813**，Spearman 从 0.658 升到 0.731。V2M 也一样：Top-1 0.554 → 0.636。
  - **区域只覆盖少数剩余表面**：当前所有尚未覆盖的可见表面中，平均只有 **26%** 位于当前规划区域内。
  - 这与 T0.12-C 的结论一致：V2 看不到区域外的收益，而真实覆盖会计入整层。

  （诊断里 oracle 增益由独立的 numpy 实现重算，总增益与 S1 完全一致；选点用候选集上的 argmax，状态级平均。）
- **室外：DistP1 会把"评估认为已覆盖或不计分"的表面当作新表面**（附加诊断 `a1_relevance_diag.py`，DEVIATIONS #8）。
  - **案例**（`fig6_case_outdoor_scoring_fail.png`、`../A2_stochastic_future_views/figures/v2/outdoor_scoring_fail_V2M_gtdpick_j5.png`）：GTD 选中的候选 GTD = 246，增益却为 0。它的真实"新表面"射线中：
    - 88% 落在评估点集上，但这些点**全部已被覆盖**。它们是规划器地图（P1）里的小空洞：已观测表面上，远处只有 10% 的点被采样；
    - 其余约 12% 不在评估点集里，主要是底部靠近相机的地面带。
  - 先前（10-28 初版）把这个案例的原因写成"地面"，现已更正：主因是地图空洞，地面是次要部分。
  - **统计**：把 GT 新表面射线的命中点与覆盖评估的 GT 点集比较（eps 内有评估点 = 相关；且该点尚未覆盖 = 有用）：
    - Macarons++ 中整体 86% 相关。GTD 选错时，被选候选的相关比例只有 0.74；选对时为 0.88，对应的 oracle 最优候选为 0.86。
    - 在不加权的射线计数下，过滤相关性、再排除已覆盖表面，排序逐步变好：

      | 射线计数方式 | Top-1 | Regret (pp) | Spearman |
      |---|---|---|---|
      | 全部新表面射线 | 0.516 | 0.558 | 0.62 |
      | 只计相关射线 | 0.585 | 0.481 | 0.71 |
      | 只计有用射线 | 0.621 | 0.432 | 0.76 |

    - 但不加权的计数仍不如带距离权重的 DistP1（Top-1 0.693，regret 0.160）。**距离权重是更大的因素**，相关性过滤是第二位的。
    - MP3D 中 98% 的 GT 新表面都与评估相关，相关性不是室内的问题；只计有用射线的 Top-1 也只有 0.546，同样不如 DistP1 的 0.688。
    - 带距离权重的相关性过滤 DistP1 需要每条射线的 z 深度，本次没有做。

**可能原因**（未隔离）：
- 扩张 BAND 把与已知表面相邻的新表面排除了；
- 1.1 cm 体素计数与"10% 采样点在 eps 内覆盖 GT 点"的饱和方式不同。

## 3. 附加观察：一步排序与闭环表现
表中"Exec:<组>"一行，是各组在**自己轨迹的状态上**实际执行动作的一步 regret（MP3D / Macarons++）：

| 组 | MP3D | Macarons++ |
|---|---|---|
| V2O | 0.274 | 0.943 |
| V2M | 0.307 | 0.762 |
| MAG-G | 0.640 | 1.678 |
| MAG-B | 0.791 | 1.738 |

MAGICIAN 的一步选择明显更差，但它在 Task 2 闭环中的差距小得多：
- MP3D AUC@150：MAG-B 0.292，V2O 0.315；
- Test-3 Cov@100：MAG-G 0.907，反而高于 V2M 的 0.889。

说明**一步 regret 只是闭环表现的弱代理**：
- beam 规划刻意牺牲一步增益来换取后续增益；
- 贪心选法会把附近的表面先"吃完"。

这与 Task 2 的观察一致：
- V2M 在固定状态上把 MP3D 一步 regret 降低了约 43%（0.210 → 0.119 pp）；
- 但闭环 AUC@150 只提升 0.007。

注意：Exec 各行的状态集合不同，不能逐行严格比较。

## 4. 哪些结论有明确证据，哪些只是推测
- **有证据**：
  - V2-Mix 的预测改善确实转化为更好的一步排序：同状态、同噪声，两个数据集所有场景方向一致，CI 不含 0；
  - 完美深度下 DistP1 仍有约 31% 的状态选错；
  - 室内的评分误差已与预测误差同量级，室外仍以预测误差为主；
  - 距离权重有益，而且是排序质量最重要的因素之一；
  - 室内评分误差的主要来源是规划区域裁剪（附加诊断）；
  - 室外有一部分评分误差来自评估不计分的表面（附加诊断，效应小于距离权重）。
- **推测**：
  - 扩张 BAND、1.1 cm 体素计数与点覆盖饱和方式不同对评分误差的贡献，未做隔离实验；
  - "一步 regret 改善不转化为闭环提升"，目前只有间接证据（Exec 行与 Task 2）。最直接的检验是 GT 一步贪心的闭环上界实验（本次未做）。
