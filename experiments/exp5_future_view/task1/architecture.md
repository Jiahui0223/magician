# EXP5 Task 1 架构说明 v1.0（V2：相机条件的随机未来视角预测）

> 2026-10-22，与 `protocol.md` v1.0 同时冻结。
> - 参数量和耗时是设计值。实现后的实测值追加在 §8，设计正文不改。
> - 不跑 V1，也不重新生成完整的 K 个 3D TSDF 世界（修改 1）。

```text
Observed Partial TSDF（P1：EMPTY / UNKNOWN / BAND，场景网格 X × Y × 256）
  ├─ A. 共享几何编码器（每次刷新算一次）─────────────────────────────→ h_t
  └─ 每个合法候选 a（M = 3–10 个）
       B. 确定性候选投影（已知几何，§2）──────────────────────────────→ C_a
       C. 沿射线读取 h_t（§3）──────────────────────────────────────→ F_a
       D. 相机条件的随机视角预测：2D 条件 rectified flow（§4）
          K 个噪声 ε_k，10 步 Euler ───────────────────────────────→ x̂₁ = (b̂, ŷ)
       E. 确定性解码（§5）─────────────────────────→ 每条射线的命中 / 深度（K 份）
       F. NBV 评分：DistP1 / U_raw / DistU / GU（protocol §4）→ Greedy 选一个动作
```

## 1. 共享几何编码器 A

**输入**：P1 结构按 8³ 体素分块统计，得到 [4, X′, Y′, 32]。
- 4 个通道：块内 EMPTY 比例、BAND 比例、域内比例、块中心 z / 32。UNKNOWN 比例 = 域内比例 − EMPTY − BAND，不单列。
- X′ = ⌈X / 8⌉，并补齐到 4 的倍数；Y′ 同理；z 方向 256 / 8 = 32。
- 例子：dunnottar 的 1110 × 1588 × 256 → [4, 140, 200, 32]；barts 的 256³ → [4, 32, 32, 32]。

**网络**：全卷积 3D U 形结构（GroupNorm + SiLU）。
- 场景尺寸可变；不依赖窗口划分，所以多窗口场景不存在对齐问题。

| 层级 | 输出 | 说明 |
|---|---|---|
| L0 | [32, X′, Y′, 32] | stem 3³ conv + 2 个残差块 |
| L1 | [64, X′/2, Y′/2, 16] | 步长 2 下采样 + 2 个残差块 |
| L2 | [96, X′/4, Y′/4, 8] | 步长 2 下采样 + 2 个残差块（空洞 2），提供大范围上下文 |
| 上采样 | F0 [32, L0 分辨率] = L0 + 上采样(L2→L1→L0)；F1 [64, L1 分辨率] | 输出两个特征体 |

**输出** h_t = (F0, F1)：分辨率分别为 8 个和 16 个体素，即 0.088 和 0.176 模型单位。
**设计参数量**：约 1.5M。

**刷新**：
- R10 模式：h_t 只在 t ∈ {0, 10, …, 90} 用当时的 P1 计算；
- Native 模式：每步计算。
- 训练时的陈旧度增强（protocol §3.2）对应 R10 下最多 9 步的陈旧度。

## 2. 确定性候选投影 B（protocol §2.3）
- **射线**：
  - 规划时用冻结的 114 × 64 块中心射线（`abl_score.pose_rays`），与 B0 逐位相同；
  - 训练时整体平移 [−2, 2)² 像素。
- **沿射线步进**：与 `SceneCaster.cast` 同样每半个体素一步。读取：
  - P1 结构（最近体素）和域；
  - 只含观测的投射体上的第一个交点 t_known。
- **C_a**：[11, 64, 114]，内容如下。

| 通道 | 内容 |
|---|---|
| 0–2 | 射线类别 one-hot：M_unknown / M_known / M_empty |
| 3 | t_known / t_cap（截到 1，∞ 记为 1） |
| 4–5 | d_lo / t_cap、d_hi / t_cap（第一个、最后一个未知采样点；没有时取 1） |
| 6 | L_u / t_cap（未知弧长） |
| 7 | min(n_seg, 3) / 3（未知段数） |
| 8 | 射线方向的 z 分量（世界坐标 z-up） |
| 9 | 相机中心 z / 2.816 |
| 10 | ln(t_cap)（量程，模型单位） |

- **另存每条射线的未知采样索引表**：用于解码，不作为网络输入。
- **遮挡**：步进到 t_known 停止，墙后的 UNKNOWN 不进入 U。
- 投影只读当前 P1，不读任何未来信息或 GT。

## 3. 射线上下文 C
- **取样**：每条射线取 N = 32 个点，t_j = (j + 0.5) / 32 · t_cap。这与 C_a 的归一化一致，所以第 j 个点的含义在所有射线上相同。
- 每个点对 F0、F1 做三线性取样，得到 32 + 64 = 96 维；再加一个"在网格内且在域内"的标志，共 97 维。网格外的点取 0。
- **射线编码器**（权重在所有射线间共享）：
  - Conv1d(97→64, k3) → Conv1d(64→64, k3, s2) → Conv1d(64→64, k3, s2) → 展平 [64 × 8] → Linear(512→64)；
  - 激活为 SiLU。
- **输出** F_a：[64, 64, 114]。
- **设计参数量**：约 0.07M。
- **作用**：
  - 投影 C_a 给出视锥内的精细已知几何，但只沿一条射线；
  - F_a 给出视锥外的结构上下文，例如墙在别处的延续、BAND 的分布和场景边界。

## 4. 随机视角预测 D：2D 条件 rectified flow

**流变量** x ∈ R^{2×64×114}，每条射线一对 (b, y)。

| 变量 | 含义 | 取值 |
|---|---|---|
| b | 有符号命中比特（analog bit） | HIT 为 +1；NOHIT / KNOWN 为 −1 |
| y | 未知弧长上的位置 | HIT 为 2s − 1，s ∈ (0, 1)；NOHIT / KNOWN 为 **+1**（s = 1） |

**为什么用有符号比特，而不是 v1 的 {0, 1} 目标加 "n̂ > 0" 判定**（修改 2）：
- v1 的目标是 0 / 1，但判定阈值取 0，正好落在"不命中"那一类目标值上。网络输出只要在 0 附近有一点噪声，就会被当成命中，产生误墙。
- 改为 ±1 的模拟比特之后，两类目标对称地分布在 0 两侧，阈值 0 就是两类的中点。这是 Analog Bits（Chen et al., 2022）的标准做法，生成的 b̂ 通常集中在 ±1 附近。
- 我们另外报告"模糊比特率" P(|b̂| < 0.5)，作为诊断。

**为什么不用独立的命中分类头**：
- 逐射线独立的 Bernoulli 采样在射线之间没有联合结构。同一个样本里会出现椒盐状的墙，这会扭曲 DistP1 的唯一体素计数，命中分歧也会退化成逐射线的 4p(1 − p) 噪声。
- 联合生成 (b, y) 保留了"一整面墙要么存在要么不存在"的空间一致性。

**为什么 y 在不命中射线上取 +1，并且参与损失**：
- 如果只在 HIT 射线上监督 y，那么不命中射线上 y 的速度场就没有定义。训练时 x_τ 的 y 通道（目标值的插值）与推理时网络自己积分出的 y 不一致，这会干扰 b 通道的条件分布。
- 取 +1 有明确含义："在全部未知弧长内都没有命中"，相当于 s = 1，是 s 的自然边界。它是有定义的编码，而**不是**"在最大深度处有一面墙"的深度监督。
- 解码规则要求 b̂ > 0 **且** ŷ < 1 才算命中，两个通道都必须支持命中。所以一个模糊的样本最多落在未知弧长的末端，而不是在半空中生成一面假墙。
- b̂ 与 ŷ 互相矛盾的比例（b̂ > 0 但 ŷ ≥ 1）作为诊断报告。

**概率映射**：p̂_hit(r) = (1/K) Σ_k 𝟙[样本 k 在 r 上命中]，即蒙特卡洛估计。用 K = 16 的可靠性曲线、Brier 和 ECE 检查校准（protocol §3.7）。

**网络**：2D U-Net，输入补齐到 64 × 128（补齐的列在输入和损失中都屏蔽）。
- **输入**：x_τ（2）⊕ C_a（11）⊕ F_a（64）⊕ 有效像素标志（1）= 78 通道。
  - 非 M_unknown 射线的 x_τ 置 0。
- **通道**：(64, 128, 192, 256)，每层 2 个残差块，GroupNorm + SiLU。
- **注意力**：只在最低分辨率 8 × 16 上使用，4 头。
- **时间嵌入**：τ 的正弦编码 → MLP(256)，以 FiLM 的 scale / shift 方式注入每个残差块。
- **输出**：速度 [2, 64, 114]。
- **设计参数量**：约 10M。

**推理**：
- 10 步均匀 Euler：x_{i+1} = x_i + 0.1 · v̂(x_i, i / 10)，x_0 = ε_k；
- 所有候选 × K 个样本拼成一个 batch，即 M·K 个视角；
- 共享编码器只算一次（R10 下每 10 步一次）。

## 5. 确定性解码 E（protocol §2.4）

**对 M_unknown 射线**：
- 命中 ⇔ b̂ > 0 且 ŷ < 1；
- s̃ = clip((ŷ + 1) / 2, 0, 1 − 1e−6)，i = ⌊s̃ · n_u⌋，t̂ = ts_{U[i]}，恰好落在一个 UNKNOWN 采样点上；
- 不命中时，结果 = t_known（有限时）或无命中。

**对 M_known / M_empty 射线**：直接用投影结果。

**输出**：
- 射线距离 t̂ [M, K, 7296]（模型单位）和命中 Ĥ [M, K, 7296]；
- 需要时再换算：z = t̂ · k_M · dz（运行单位）。

**按构造保证**：
- 不会在已观测 EMPTY 中命中；
- 不会在已知表面之后命中；
- 不会在框外或域外命中；
- 天空、超量程、离开域的射线不会被强行预测成墙，因为"不命中"是一个独立的结果。

**这是计划书 §9.2 允许的"硬投影"**：它不会把本该是 UNKNOWN 的区域锁死，UNKNOWN 内任何位置都可以命中，也可以不命中。

## 6. 训练（protocol §3）
- **损失**：只在 M_unknown 且标签有效的射线上，计算速度 MSE ‖v̂ − (x₁ − ε)‖²，两个通道同权。
- **优化**：
  - 每 batch 64 个视角，来自 8 个状态 × 最多 8 个候选；编码器每个状态只算一次；
  - AdamW 2e−4，余弦退火，60k 步，bf16，EMA 0.999。
- **预计耗时**：
  - 每个视角前向约 17 GFLOP，所以每步（前向 + 反向，64 个视角）约 3.3 TFLOP；
  - 加上编码器和射线取样，每步预计 0.1–0.2 s，60k 步约 2–4 h（L40S）。以实测为准。
- **数据**：常驻内存。投影统计量 + 标签约 16 GB，粗网格约 10 GB（压缩后更小）。

## 7. 每步推理的计算分解（计时项，protocol §4.7）

| 分项 | V2 | B0 / B2 中的对应部分 |
|---|---|---|
| ① 共享编码 | 3D CNN 处理粗网格（R10 每 10 步一次） | 世界生成：K 个 256³ 窗口 × 10 步 flow + 解码 |
| ② 候选投影 | M 个视角 × 7,296 条射线的步进 + obs-only 投射 | 构建 cast 体 |
| ③ K 次生成 | M·K 个视角 × 10 步 U-Net | 无，世界本身就是样本 |
| ④ 解码与 DistP1 | 解码 + 唯一体素去重 | K·M 次三维投射 + 去重 |
| ⑤ 完整决策 | ① 摊销 + ② + ③ + ④ + 选择 | ① 摊销 + ② + ④ + 选择 |

- **设计估计**：M = 8，K = 4 时，③ 约 32 × 10 次 U-Net 前向，约 5.4 TFLOP，预计 < 0.2 s。
- 都在同一型号 GPU、相同候选动作数量、相同输出要求下实测，不从张量尺寸推算。

## 8. View Latent 的可行性分析（修改 6）
**问题**：能否不经过几何解码，直接在未来视角的特征空间比较 K 个预测的差异？

**分析**：
1. **V2 的流状态 x̂₁ 本身就是一个显式的视角 latent**：
   - 空间上与 7,296 条射线一一对齐；
   - 两个通道按构造分别对应命中和未知弧长上的位置（§5），与深度和命中的联系是确定的，不需要另外学习。
   - 因此 **U_flow**（M_unknown 射线上 x̂₁ 的方差）是一个不需要解码的分歧度量，可以直接解释。代价几乎为零。
   - 它与 U_raw 的区别：U_raw 先阈值化成事件，再用 DistP1 的"新命中"规则；U_flow 保留连续值。
2. **U-Net 的中间特征**（最后一层解码特征，[64, 64, 128]）：
   - 空间对齐，但与几何的联系没有被约束。
   - 只作诊断：报告它在 K 个样本间的方差 U_feat 与 U_raw / DistU / 真实增益的秩相关，以及线性探针重建 (b, y) 的 R²。
   - **不**称为几何不确定性或信息增益。
3. **单独学习一个压缩 latent**（例如 2D VAE 把 [2, 64, 114] 压到 [8, 16, 29]，再在 latent 里做 flow）：
   - 需要多训练一个 VAE，两阶段训练，增加训练复杂度；
   - DistP1 仍然需要显式深度，所以对主实验 V2-G 并不能省去解码；
   - V2 的像素空间只有 2 × 64 × 114 ≈ 1.5 万个数，本来就比常见的 latent 小。
   - **结论**：本轮不做，只在报告中讨论。

## 10. 考虑过但不采用
- **逐射线独立的类别分布或命中分类头**：理由见 §4。
- **256 × 456 全分辨率输出**：DistP1 只读 114 × 64 条射线，更高分辨率没有用处。
- **以原始历史深度为输入的编码器**：信息量多于 B0，会造成混杂。可以以后作为单独的变体。
- **跨视角一致性损失**：只作诊断（同一状态里两个候选视锥重叠时，比较同一 k 与不同 k 的重投影一致率），不进损失。
