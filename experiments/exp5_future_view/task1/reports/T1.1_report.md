## 4. 偏差（`DEVIATIONS.md`）
- **DEV-1**：magician 环境实际没有 embree（之前的记录有误）。标签改用冻结传感器同一个 PyTorch3D 光栅化器（不剔除背面、z_clip 0.5），配自定义内参，使 64 × 114 的像素中心恰好是打分射线。`max_faces_per_bin` 设为网格面数，避免 bin 溢出（第一次测试时出现过溢出警告，溢出只打印不报错；改后为 0 次）。**标签定义不变**，T-L0 / T-L6 / T-L3 验证了精度。
- **实现说明**：
  - data v1 `code/` 快照的清单路径是相对路径，在快照位置解析不到，改为 import 原始 Task 0 脚本（三个文件 sha256 相同）；
  - 构建时每块 GPU 跑两个进程（反向场景顺序），输出确定，重复处理只会写出相同文件。
