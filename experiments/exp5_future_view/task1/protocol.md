## 2. Task 1.1：输入构造、合法候选与训练标签

### 2.1 状态与候选
- **状态**：data v1 的 180 条 Train-6 轨迹，每条 t = 0 … 99，共 18,000 个决策状态。
- **P1 状态**：从 L1 服务记录 t = 0 … t 依次用冻结 `P1Fusion` 重放得到。
  - 在关键帧上，重放结果必须与 L3 状态（`t0_state_io.load_state`）**逐位相同**，否则 STOP。
- **候选**：记录 t 中的全部合法动作（`legal_idx` / `legal_R` / `legal_T`）。不增加、不删除、不固定为 8 个。
- **几何**：`t5_diagnostic.scene_geometry(scene)` 给出 `SceneFrame`、网格尺寸和域。

### 2.2 射线
- **规划和评估**：冻结的 114×64 块中心射线。由 `abl_score.pose_rays(caster, R, T)` 生成，与 B0 **逐位相同**（测试 T-R1）。
- **训练**：
  - 每个候选视角加一个整体亚像素平移 (δu, δv) ∈ [−2, 2)²；
  - 种子为 `sha256("exp5-V2|jitter|<scene>|<traj>|<t>|<a>")`；
  - 射线 = `m_common.pixel_rays(R, T, u_c + δu, v_c + δv)`。
- **留出集 S-c 和所有评估**：δ = 0。
- **G1 ES 匹配查询**：δ = (+0.5, +0.5)，即整数像素 (4j + 2, 4i + 2)。

### 2.3 确定性投影（每条射线；只读当前 P1 状态）
记 P1 结构为 S（EMPTY / UNKNOWN / BAND）。`caster = SceneCaster(frame, dims, dom, P1.input_volume())`。

**采样位置**：与 `SceneCaster.cast` 相同。
- t_min = 进入场景网格框的位置（≥ 0）；
- t_max = min(离开框的位置, t_cap)，t_cap = 70 / dz / k_M；
- 采样点 ts_j = t_min + h·j，h = VS / 2，j = 0 … M − 1，只保留 ts_j ≤ t_max 的点。

**每条射线计算的量**：

| 量 | 定义 |
|---|---|
| `t_known` | `caster.cast(caster.obs_surf 投射体)` 的域内第一个交点；没有交点为 ∞。与 B0 投射中"已观测命中"的语义相同（测试 T-P1） |
| 未知采样集 U | {j : 采样点 p_j = o + d·ts_j 的体素 floor(p_j / VS) 在网格内、在域内、S = UNKNOWN，并且 ts_j < t_known} |
| n_u | \|U\|；未知弧长 L_u = n_u · h |
| d_lo / d_hi | U 中第一个 / 最后一个采样点的 ts |
| n_seg | U 中连续段的个数 |

**射线类别**：
- **M_unknown**：n_u > 0；
- **M_known**：n_u = 0 且 t_known < ∞；
- **M_empty**：其余。

**遮挡**：t_known 之后的 UNKNOWN 不计入 U，所以墙后不会被当成可预测区域。

**输入通道**（11 个，见 `architecture.md` §2）：
- 类别 one-hot（3）；
- t_known、d_lo、d_hi、L_u，都除以 t_cap，截到 [0, 1]，没有时取 1；
- n_seg / 3（截到 1）；
- 射线方向的 z 分量；
- 相机高度 / 2.816；
- ln(t_cap)。

**共享编码器的输入**：P1 结构按 8³ 统计的 EMPTY 比例、BAND 比例、域内比例，加上 z 坐标通道（见 `architecture.md` §1）。

### 2.4 训练标签（只用 Train-6 GT 网格；magician 环境；评估侧进程）

**求交**：
- GT 网格 = `P.scene_dir(scene)` 唯一的 .obj，trimesh 读入后顶点 × 10（与 `T0EpisodeSim` 相同），即 y-up 运行坐标。
- 沿运行坐标射线（原点 = 相机中心，方向 = `pixel_rays` 的单位方向）用 embree 求第一交点，正反面都算。
- 求交距离 / k_M = 模型单位的射线距离 t*。

**类别**：按以下顺序判定，容差 τ_tol = 1 体素 = VS。

| 类别 | 条件 | 目标 |
|---|---|---|
| BLOCKED | t* < t_min − VS（框外物体先挡住） | 无效，不进损失 |
| NEAR | t*·k_M·dz < 0.5（近裁剪） | 无效 |
| NOHIT | t_max 之内没有交点（天空、超量程、离开框） | b = −1 |
| KNOWN | t* ≥ t_known − VS（已知表面先到或重合） | b = −1 |
| HIT | 设 j* = U 中离 t* 最近的采样点，\|ts_j* − t*\| ≤ VS | b = +1，s = (rank_U(j*) + 0.5) / n_u |
| INFEASIBLE | 其余情况：真实命中落在已观测 EMPTY、未被投射命中的 BAND，或域外。按落点的 S 状态记子类 | 无效；逐视角计数并报告比例 |

- 只有 M_unknown 射线有训练目标。M_known / M_empty 射线的 t* 只保存，供评估使用。
- **编码**：x₁ = (b, y)。
  - b ∈ {−1, +1}；
  - y = 2s − 1 ∈ (−1, 1)，用于 HIT；
  - **y = +1 用于 NOHIT 和 KNOWN**，含义是"s = 1：在全部未知弧长内都没有命中"。这是一个有定义的值，不是一个深度声明，并且参与损失（理由见 `architecture.md` §4）。
- **解码**（推理）：
  - 命中 ⇔ b̂ > 0 **且** ŷ < 1；
  - 命中时 s̃ = clip((ŷ + 1) / 2, 0, 1 − 1e−6)，索引 i = floor(s̃ · n_u)，t̂ = ts_{U[i]}，即恰好落在一个未知采样点上；
  - 不命中时，结果 = t_known（有限时）或无命中；
  - M_known / M_empty 射线直接用投影结果。
  - 因此预测命中**按构造**只会落在 UNKNOWN 体素内，并且在已知表面之前（测试 T-D1 用断言检查）。
- **采样权重**（事先固定，不读 GT 覆盖率）：
  - 每个状态等权，t ≤ 20 的状态权重 × 2；
  - 每个状态内，从其合法候选中无放回均匀抽取最多 8 个。

### 2.5 留出集划分（事先固定）
- **S-c（起点级留出）**：每个场景留出 3 个起点，其全部轨迹都不进训练。
  - 用 `numpy.random.default_rng(int(sha256("exp5-V2|holdout|<scene>")[:15], 16))`，从 4 个 A 起点中取 1 个，从 11 个 B 起点中取 2 个。
  - 起点的定义是 t = 0 记录的 `pose_idx`；同一起点下所有策略的轨迹一起留出。
- **LOSO 探针**：pisa 的全部 30 条轨迹从训练中移除；其余 5 个场景用相同的 S-c 规则。
- 结果写入 `frozen_values.json`：每个场景的留出起点和轨迹列表。

### 2.6 T1.1 正确性检查（训练前必须全部通过，否则 STOP）

| # | 检查 | 通过标准 |

## 3. Task 1.2：模型与训练

### 3.1 生成目标与损失
- **条件 rectified flow**：
  - x_τ = (1 − τ)ε + τ x₁，ε ~ N(0, I)，τ ~ U(0, 1)；
  - 网络预测速度 v̂(x_τ, τ, cond)，目标 x₁ − ε。
- **损失**：MSE，只在 M_unknown 且标签有效（HIT / NOHIT / KNOWN）的射线上，两个通道同权。
- **非 M_unknown 射线和补齐像素**：输入的 x_τ 在训练和推理时都置 0，不计损失。
- **无效射线**（BLOCKED / NEAR / INFEASIBLE）：输入的 x_τ 照常加噪，x₁ 取 (−1, +1)，**损失权重为 0**。
- **不对 K 个输出各自施加同一张 GT 的 L1**。
- **推理**：10 步均匀 Euler，τ_i = i / 10；K 个独立噪声 ε_k ∈ R^{2×64×114}。

### 3.2 编码器陈旧度增强（让同一个 checkpoint 同时服务 R10 和 Native）
- 每个状态以 0.5 的概率让编码器输入改用 t − Δ 时刻的粗网格，Δ ~ U{1, …, min(9, t)}；t = 0 时 Δ = 0。
- 投影和标签始终来自当前时刻 t。

### 3.3 优化（固定，不搜索）
| 项 | 值 |
|---|---|
| 优化器 | AdamW，lr 2e−4，betas (0.9, 0.99)，weight decay 0.01 |
| 学习率 | 1k 步线性预热 + 余弦退火到 0 |
| 训练长度 | **60k 步** |
| batch | 64 个候选视角（8 个状态 × 最多 8 个候选；候选不足时多抽状态补齐） |
| 其他 | bf16 autocast，梯度裁剪 1.0，EMA 0.999，seed 0 |
| checkpoint | 每 5k 步保存 |

- **最终 checkpoint 事先定为 EMA@60k**，不按任何验证指标挑选，不延长训练。
- LOSO 探针用完全相同的配方，只换训练集。

### 3.4 冒烟阶梯（每一级通过才进下一级）
1. §2.6 的全部检查。
2. **单 batch 过拟合**：200 步内损失下降 > 90%，采样的 b 的符号与标签一致率 > 95%。
3. **梯度检查**：没有 NaN；编码器、射线模块、U-Net 的每个参数组梯度范数都 > 0。
4. **单相机采样**：M_known / M_empty 射线在 K 个样本间完全相同；同一种子重复采样逐位相同；预测命中都落在 UNKNOWN 体素内（断言）。
5. **2k 步短训练**：损失下降、没有数值问题后，开始正式训练。

### 3.5 学习曲线（Train-only）
每 2.5k 步用 EMA 权重评估以下固定子集：

| 子集 | 内容 |
|---|---|
| train-sub | 1,024 个训练视角 |
| S-c-sub | 2,048 个留出视角，各场景等量 |
| pisa-sub | LOSO 探针专用：2,048 个 pisa 视角 |

- **确定性指标**：固定 τ ∈ {0.1, 0.3, 0.5, 0.7, 0.9}、固定 ε 下的 FM 损失。
- **采样指标**（每 10k 步，K = 4）：
  - 命中 Brier；
  - 误墙率 P(预测命中 | NOHIT)；
  - 命中率比值；
  - M_unknown 射线上的 fair ES，单位体素，不命中取 t_max；
  - 两两分歧。

**过拟合 / 欠拟合诊断**：报告 train 与 S-c 的差距随步数的变化，以及最后三分之一训练中 S-c 损失的趋势。只报告，不改变 checkpoint。

### 3.6 LOSO 探针与"数据不足 / 架构问题"的区分（必须执行）
**比较三个量**（同一批 pisa 视角）：
- ① 主模型的 train-sub 拟合；
- ② 主模型在 pisa 留出起点上的表现（场景见过，起点没见过）；
- ③ 探针在相同 pisa 视角上的表现（场景完全没见过）。

**分层**：t = 0、t ≤ 20、低观测覆盖档（GT 覆盖率 < 10% 和 10–20%，只在评估侧读取 `cov_gt_diagnostic`）。

**解读规则**（事先写定）：
- ① 本身就差 → 优先归因于架构或优化；
- ① ≈ ② 但 ③ 明显差 → 跨场景泛化缺口，归因于训练场景数量和多样性不足。

**条件追加**（事先写定）：
- 触发条件：在 pisa 的 S-c 视角上，③ 的 M_unknown fair ES 比 ② 差 > 25%。
- 动作：再训练一个"3 场景"探针（从其余 5 个场景中按种子取 3 个；pisa 仍留出；配方相同），看泛化性能是否随场景数单调变化。
- 3 场景探针只用于这个诊断，不进入闭环。

## 4. Task 1.3：评分定义、固定状态诊断与计时

### 4.1 DistP1(a)：语义固定
- **新入口** `new_set_from_depth(caster, rays, t, hit, z0)`：把 `SceneCaster.cast` 的 (t, hit) 换成预测值，其余步骤逐行沿用冻结代码：
  - 命中点 p = o + d·t → `ijk = floor(p / VS)`，截到网格；
  - `hit &= domain[ijk]`；
  - `new = hit & ~band_dil[ijk]`；
  - 场景网格线性索引 → `torch.unique` 去重；
  - z = t·k_M·dz，w = min(1, (z / z0)²)，每个体素取最大权重（scatter amax）。
- **分数**：G = 新体素权重之和；K 个样本取平均。
- **z0** = `abl_common.z0_of(scene)`（MAGICIAN scene_scale / 2），Dev-3 上断言等于冻结的 Z0。
- **测试 T-S1（逐位等价）**：在 S-a 的 73 个状态、全部合法候选、K = 4 个已归档 T1-C 世界上，把 `caster.cast(cast_volume(world))` 的 (t, hit) 输入新入口，ids 和 weights 必须与 `abl_score.new_set` **逐位相同**。
- **测试 T-S2**：解码出的命中所在体素的 P1 状态都是 UNKNOWN，违例为 0。
- **选择规则**：沿用 `m_score.choose`（argmax，并列取最小下标；全为 0 时用带种子的回退）。

### 4.2 分歧评分：U_raw 与 DistU（同一个模型、同一组样本、同一套已知几何约束）

**样本事件**：对候选 a、射线 r、样本 k：
- e_k(r) = 1，当且仅当样本 k 在 r 上的解码结果是 DistP1 意义下的新命中：域内、z ≤ 70、3³ 邻域内没有已观测 BAND；
- t_k(r) 为该命中的射线距离（模型单位），z_k(r) = t_k·k_M·dz 为相机 z 深度（运行单位）。
- 解码规则保证 e_k 只可能在 M_unknown 射线上为 1；预测命中在 3³ 邻域内有已观测 BAND 时，e_k = 0，与 DistP1 一致。

**两两分歧**（K = 4，共 P = 6 对）：

  d_ij(r) = 𝟙[e_i ≠ e_j] + 𝟙[e_i = e_j = 1] · min(1, |t_i − t_j| / (δ·VS))

| 情况 | d_ij |
|---|---|
| 一个样本有新墙，另一个没有（在这条射线上看到空或已知表面） | 1：这类分歧**有价值**，不能当作无信息 |
| 两个都有新墙 | 截断深度差 min(1, Δ / δ)，Δ 是**射线距离**之差，单位体素 |
| 两个都没有新墙 | 0：一致 |

**分量**（同一个分母）：
- 命中分歧 c_H(r) = (1/P) Σ_{i<j} 𝟙[e_i ≠ e_j]；
- 深度分歧 c_D(r) = (1/P) Σ_{i<j} 𝟙[都有新墙] · min(1, Δ / δ)；
- c(r) = c_H(r) + c_D(r)。

**U_raw(a)** = (1/R) Σ_r c(r)，R = 7,296 是固定分母，不重新归一化，与 P2 相同。

**DistU(a)** = (1/R) Σ_r (1/P) Σ_{i<j} w_ij(r) · d_ij(r)：
- w_ij(r) = max{ min(1, (z_k(r) / z0)²) : k ∈ {i, j}，e_k = 1 }，即这一对中实际出现的新墙的 DistP1 距离权重，取较大者；
- e_i = e_j = 0 时 d_ij = 0，权重无关；
- z 与 z0 都是运行单位的相机 z 深度，与 DistP1 相同。

**单位**：深度差用射线距离（体素）；距离权重用相机 z 深度（运行单位）；z0 也是运行单位。由测试 T-L2 保证换算正确。

**分别报告**：U_raw^H、U_raw^D、DistU^H、DistU^D 四个分量。

**δ 的事先规则**（只用 V2 自身的预测，不读 GT，在 S-c 上确定）：
- 取 S-c 校准状态的全部候选中"两个样本都有新墙"的样本对，计算深度差 Δ 的中位数；
- δ = {2, 4, 8, 16} 中不小于该中位数的最小值，都不满足时取 16；
- 同时报告各 δ 下的饱和比例 P(Δ ≥ δ)。
- δ 对 U_raw 和 DistU 相同。

**K = 1**：没有样本对，U 无定义。所有 U 实验组都用 K = 4。

**表述**：U 是"预测的可观测分歧"，**不是**期望信息增益，也不是几何不确定性的校准度量。

### 4.3 GU：DistP1 与 DistU 的组合
- **分数**：GU(a) = r(DistP1)(a) + λ · r(DistU)(a)。
  - r(·) 是同一状态候选之间的平均秩，缩放到 [0, 1]：(rank − 1) / (M − 1)，M = 1 时为 0。
- **选择**：
  - DistP1 和 DistU 全为 0 时，用带种子的回退；
  - 否则取 argmax GU，并列取最小下标。
- **λ** ∈ {0.25, 0.5, 1, 2}，**不含 0**，所以 GU 一定是真正的组合。
  - 在 S-c 校准状态上，按"对真实一步增益的平均遗憾最小"选取，并列取较小值；
  - 同时报告 λ = 0（即纯 DistP1）的遗憾，作为参照。
