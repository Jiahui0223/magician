# EXP5 Task 0.5 报告：室内（MP3D）与室外（Dev-5）匹配对照（固定状态）

> 2026-10-23 14:27 – 10-24 18:20。
> **协议**：`protocol_v1.2_outdoor.md`，在产生室外 Task 0 模型输出之前冻结。
> **数据**：
> - 室内 = T0.4 的 M 协议 157 个状态，11 个房屋；
> - 室外 = Dev-5 的 85 个状态（16 / 22 / 23 / 24），5 个场景，来自冻结的 EXP3b T5 回放 t = 0..50。
> - 两边用同一份代码和同一套定义：标签、共享指标、DistP1、3D 指标。

> 室外只有 5 个聚类，CI 很宽；**结论是探索性的**。
>
> **分析**：`scripts/t045_analyze.py` 的 `M_vs_O` / `by_t` / `O_split`；误差类型见 `t047.json`，事后诊断见 `phantom.json`。

## 1. 结论
1. **主口径（相同覆盖区间）下，室内没有比室外更好；多数指标是室内略差，或两者相当。**
   - 3D 的 F@2 两边相当：Frozen 0.172 对 0.185，T1-C 0.205 对 0.215。
   - 但组成不同：
     - 室内精度低得多：P@2 低 0.13，CI 不含 0；
     - 召回略高：R@2 高 0.01–0.02，不显著；
     - 落在已观测 EMPTY 里的预测表面更多：+0.035，CI 不含 0。
   - 命中 Brier 和 false confidence：室内高约 0.05。false confidence 对两个世界模型显著。
   - CRPS：室内高 2.6–9.7 体素，CI 都含 0。
   - 一步排序的 Spearman：总体上室内反而略高（+0.02 – +0.12），不显著；只有 c20-40 中两个世界模型是室内更低（−0.13 / −0.15，不显著）。
2. **极低覆盖（c01-05）**：
   - Frozen Seen2Scene 在室内的 CRPS、Brier 都略差，P@2 低 0.14，F@2 相同，都不显著或接近边界；
   - 排序 Spearman 室内略高（0.678 对 0.595，不显著）。
   - **没有证据表明原版 Seen2Scene 在室内极低覆盖时更好。**
3. **室内特有的误差是"误墙"**：
   - 标签不命中而样本命中的比例，室内约 0.30（三个模型都是），室外 0.09–0.15；
   - 世界模型在已观测 EMPTY 里放表面的比例，室内也更高；
   - 事后诊断：被选中候选的 DistP1 增益中，来自已观测 EMPTY 体素的比例室内为 21%，室外为 9–12%。
4. **V2 的室内外差异**：
   - V2 在 MP3D 室内排序正常（Spearman 0.591），但在 Macarons++ 的两个"室内"摄影测量场景（barts、sestino）上明显差（0.225，CRPS 55）；
   - 世界模型在这两个场景上 Spearman 为 0.46–0.49；
   - 只有 2 个场景，不能推广。

## 5. 误差类型（M_unknown 射线；见 T0.4 §6）

| 方法 | 漏墙率 室内 / 室外 | 误墙率 室内 / 室外 | 双命中 \|误差\| 中位数（体素） 室内 / 室外 |
|---|---|---|---|
| Frozen | 0.276 / 0.291 | **0.304 / 0.103** | 2.9 / 7.2 |
| T1-C | 0.227 / 0.235 | **0.304 / 0.089** | 2.3 / 4.6 |
| V2 | 0.168 / 0.186 | **0.319 / 0.145** | 16.6 / 20.9 |

- **漏墙率**：两个域相当。
- **误墙率**：室内高 2–3 倍，三个模型都是。这说明它来自域本身，而不是某个模型。可能的原因：
  - 室内 3 × 3 窗口的区域边界离相机更近，射线在区域内常常走到门洞或开放空间；
  - 室内网格有缺口（玻璃、镜面，T0.3 F8）。R 协议中 V2 的误墙率也是 0.31，所以网格缺口不是主因。
- **双命中时的深度误差**：室内反而更小，对两个世界模型都是。
