# EXP5 Task 0 协议 v1.3 增补：室内 100 步闭环（T0.6，M 协议）

> 2026-10-23。在任何正式闭环 episode 运行之前冻结。场景、传感器、覆盖率和动作规则沿用 v1.0。

## 1. 可行性（冒烟时已检查）
- **动作集**：全景站点图上的移动（≤ 3 m，三条视线射线无遮挡），加上原地方位 ±1 档、俯仰 ±1 档。
  - 这是**室内专用**规则，与室外 MAGICIAN 的 3D 网格飞行不同，两者的闭环数值只能分别解读；
  - 合法列表为空时原地悬停（同 MAGICIAN 的死路规则）。
- **碰撞**：移动只沿站点图的边进行；三脚架位置一定是自由空间，视线由 GT 网格检查（只在模拟器侧）。
- **评估器**：整层 C_obs（v1.0 §3），每步一个值，共 101 个。
- **隔离**：规划器是子进程，只收到 {t, 服务记录路径}。
  - LeakGuard：EXP3b 原有规则 + MP3D 路径（数据集、覆盖率 / 网格缓存、标签、`traj.json`、`.house`、`episode.json`）；
  - 守卫只要拒绝过一次就判 INVALID。
- **可复现**：V2K4 的 12 步冒烟，重跑后执行位姿、覆盖率和全部候选分数都逐位相同。

## 2. 组
| 组 | 内容 |
|---|---|
| frozen | Frozen Seen2Scene，K = 4 个世界 + DistP1 + Greedy，R10（B0 规则：刷新时以当前相机为中心建区域并生成世界，刷新之间在该区域内用当前 P1 和 PoseScorer 评分） |
| C | T1-C@2000，同上 |
| V2K4 | V2，K = 4，R10（刷新时更新区域、编码器和噪声，每步投影当前 P1）+ DistP1 |
| V2K1 | 同上，K = 1 |
| 参考 | v1.0 的随机参考策略轨迹（已有），只作参照 |

- **种子**：世界键 `T0CL|<episode>|t<t_r>`；V2 噪声 `exp5-V2|task0cl|<episode>|t<t_r>|k<k>`；回退 `exp5-T0CL|<episode>|<t>`。
- **选择**：argmax，并列取最小下标；分数全为 0 时用带种子的均匀回退。

## 3. Episode
- **范围**：22 个楼层，每层取 `t03_select` 选出的第一个起点，共 22 个 episode × 4 组 = 88 条，每条 100 步，1 个重复。
- **成本**：世界模型每条约 10 次刷新 × 约 15 分钟。

## 4. 报告
- Cov@10 / 20 / 50 / 100、AUC@100（trapz / 100）；
- 每条 episode 的墙钟时间、决策时间和刷新时间，以及 GPU-h；
- 配对差（组间、组对参考策略）：在 22 个 episode 上按房屋做聚类 bootstrap（10,000 次，seed 0），同时给出每个 episode 的完整表；
- 只有 11 个房屋，结论是探索性的。
