`W` = `work_dirs/exp5_future_view/task0`，`D` = `/bsushare/yzhang-shared/data/matterport3d/v1/scans`

## 1. 数据
- **房屋**：MP3D 官方 val 的 11 个房屋。test 的 18 个封存；train 的 61 个不使用。
- **GT 网格**：`matterport_mesh` 的 textured `.obj`，只取几何。坐标为 z 向上的米制。
- **相机约定**（T0.3 F6）：undistorted `.conf` 是 OpenGL 相机、图像原点在左下角。本协议只用全景站点的位置，不用真实帧。

## 2. 场景、尺度与传感器
- **楼层**：
  - 地面和天花板 = 该层全部全景站点竖直向下 / 向上射线首次命中高度的中位数，层高上限 4.5 m；
  - 平面范围 = 站点包围盒外扩 2 m，再裁剪到 `.house` 楼层框之内。
- **运行坐标**：y 向上，1 m = 7 个运行单位（`S_RT = 7`）。
  - k = 层高（运行单位）/ 2.816，沿用 E-M2 的单层窗口规则；
  - 冻结传感器的量程 70 = 10 m，近裁剪 0.5 = 7 cm。
- **传感器**：冻结的 MAGICIAN 传感器，在室内网格上复现，T0.3 已验证与室外归档服务记录逐位相同。
  - 456 × 256，竖直 FoV 60°，zbuf、mask、10% 采样规则与室外一致；
  - 种子：`sha256("exp5-T0|<楼层>|<起点>|<t>|<用途>")`。
- **位姿**：该层全景站点 × 俯仰 {−30°, 0°, +30°} × 方位 8 档。
- **合法动作**：
  - 原地方位 ±1 档、俯仰 ±1 档；
  - 或保持朝向，移动到全景站点图的相邻站点。相邻 = 距离 ≤ 3 m，且在站点高度上，中心和左右各偏 0.15 m 的三条射线都没有被网格挡住。

## 3. 覆盖率、轨迹和状态（已按此规则生成，结果见 `W/manifests/`）
- **C_obs**（整层尺度）：
  - GT 点 = 楼层框内面片上按面积加权的 30 万个采样点；
  - 可见点 = 从全部位姿看得到的 GT 点；
  - 已覆盖 = 距离某个已观测 10% 采样点不超过 ε 的 GT 点，ε = 0.08 模型单位（室内约 6–13 cm）；
  - C_obs = 已覆盖的可见点 ÷ 可见点。
- **起点**：每层在站点图最大连通分量中、度数 ≥ 1 的站点里，用种子选 2 个；最大连通分量少于 4 个站点的楼层排除（本次没有被排除的楼层）。共 22 层、44 个起点。
- **参考轨迹**：100 步，在合法动作中均匀随机，优先选未访问过的位姿（带种子）。重跑逐位一致。
- **状态**：每条轨迹在 [1, 5)、[5, 10)、[10, 20)、[20, 40) % 每个区间中，取第一次进入该区间的那一步；取不到就记"缺失"，不补。
  - 结果：157 个状态（32 / 38 / 43 / 44），每个区间 11 个房屋都有；缺失 19 个"轨迹 × 区间"组合。

## 4. 评估区域
- 每个状态以当前相机为中心，取 3 × 3 个官方窗口（每轴 2.816 × (1 + 2 × 0.8) × 0.99 个模型单位），裁剪到楼层范围。
- 用冻结的 P1 把服务记录 0..t 重放进这个区域网格。四个方法用**同一个区域、同一个 P1**。
- 预测、射线段终点 tmax 和 DistP1 的新体素都只在这个区域内计算。

## 5. 方法（全部零样本，权重和配置都冻结）
| 名称 | 内容 |
|---|---|
| frozen_K4 / frozen_K1 | Frozen Seen2Scene（S0-F），E-M2 配置，K = 4 个世界（K1 = 第 0 个世界），世界键 `T0|<状态>` |
| C_K4 / C_K1 | T1-C@2000（sha `102f44cc…`），同上 |
| V2_K4 / V2_K1 | EXP5 V2 主 checkpoint（sha `a379c0fb…`），K = 4 个样本（K1 = 第 0 个），δ = 4，种子 `exp5-V2|task0|<状态>|k<k>` |
| V2_Uraw / V2_DistU | 同一组 V2 样本上的 U_raw / DistU |
| Frontier | 每条 M_unknown 射线都在第一个 UNKNOWN 采样处命中，+ DistP1（下限参照） |

规划侧进程只读场景卡片（楼层框、k、站点位置和站点图，不含 GT 几何）和白名单服务记录。

## 6. 指标
- **共享指标**（跨架构比较的重点；`scripts/t04_metrics.py` 的定义）：
  - 射线：每个合法候选的 64 × 114 条评分射线中，P1 投影为 M_unknown 的射线；
  - 标签：t* ≤ tmax 记为命中，否则记为不命中、取值 tmax；
  - 世界模型的样本 = 投射得到的第一交点；V2 的样本 = 解码出的 UNKNOWN 命中，否则取已知表面，否则取 tmax；
  - 指标：fair CRPS、每视角 ES、MAE、命中 Brier、false confidence（K 个样本一致但都错）、spread、预测 / 标签命中率。单位为体素。
- **规划指标**：DistP1（K4 / K1）、V2 的 U_raw / DistU、Frontier，与真实一步增益比较：
  - 真实增益 = 100 × (执行该候选后的 C_obs − C_obs(t))，候选的 10% 采样用第 t + 1 步的种子；
  - 指标：Spearman、top-1、遗憾、零增益状态；
  - 并列取最小下标；分数全为 0 时用带种子的均匀回退。
- **3D 指标**（只适用于世界模型）：
  - 区域内 UNKNOWN 体素中，预测表面（|w| < 1 体素）与 GT 表面密集采样点的 P / R / F@1、F@2 体素；
  - 已观测一致性：BAND 体素上世界与 P1 TSDF 的差；
  - 与已观测 EMPTY 的冲突率。
- **分层**：覆盖区间、房屋、楼层、t。统计以房屋为单位做聚类 bootstrap（10,000 次，seed 0）。

## 7. 停止条件与隔离
- **GT 隔离**：GT 只在模拟器侧和评估侧使用（渲染、站点图视线检查、标签、覆盖率、3D 指标）。
- **停止受影响部分的条件**：泄漏、坐标或单位错误、生成的世界尺寸与网格不一致、非有限值。
- **失败**：保留原因，不静默剔除。世界模型返回 EmptyObservation 时记为 A2，该方法此状态的分数记为 0，并报告。
