# EXP5 Task 0 协议 v1.2 增补：室外匹配对照（T0.5，固定状态）

> 2026-10-23。在任何室外 Task 0 模型输出产生之前冻结。
> **目的**：用与室内**同一份代码和同一套定义**重算室外指标，不直接比较口径不同的旧数值。

## 1. 场景与轨迹
- **场景**：Dev-5（barts、colosseum、eiffel、pantheon、sestino_museum）。barts、sestino_museum 是 Macarons++ 里的室内摄影测量场景，二级分析中单独列出。
- **轨迹**：冻结的 EXP3b T5 MAGICIAN 回放服务记录，5 个起点 × t = 0..50（`work_dirs/exp3b_macaronspp_transfer/task5_feasibility/validation/replay/C/svc`），合法动作列表来自 MAGICIAN（GT 碰撞检测）。
- **实现方式**：用符号链接只读引用这些记录，不复制、不修改。

## 2. 场景卡片与区域
- **卡片**：
  - 场景框 = settings.json 的 scene 框（OBJ 单位，转成 z 向上）；
  - 运行单位 = OBJ × 10（S_RT = 10），所以 k = 场景高度（运行单位）/ 2.816，等于冻结的 E-M2 k_M（断言）；
  - z0 = MAGICIAN scene_scale / 2（断言等于 `abl_common.z0_of`）。
- **区域**：与室内相同，以当前相机为中心取 3 × 3 个窗口，边长 × 0.99，裁剪到场景框。barts、eiffel 本身只有 1 个窗口。

## 3. 覆盖率与状态
- **C_obs**：
  - GT 点 = 场景框内面片上按面积加权的 30 万个采样点（同室内）；
  - 已覆盖 = 距某个已观测 10% 采样点不超过 ε 的 GT 点，ε = 0.08 模型单位（同室内）；
  - 归一化：C_obs = 已覆盖点 ÷ GT 点 ÷ MAGICIAN 的 `visibility_ratio`，上限 1。室外的全量位姿有 1–3 万个，逐个计算可见性代价太高，所以改用 MAGICIAN 自己的可见比例。室内的分母则是实算的可见点。两者都是"可观测表面占比"，口径的差别写进报告。
- **状态规则**：同室内，每条轨迹在 [1, 5)、[5, 10)、[10, 20)、[20, 40) % 每个区间里取第一次进入的那一步，t ≤ 50。

## 4. 标签与方法
- **标签**：同室内。
  - 真值深度用 EXP5 T1.1 标签渲染器在 Macarons++ 网格（× 10）上求得；
  - 真实一步增益 = 用冻结传感器渲染候选位姿，按第 t + 1 步的种子取 10% 采样点，算 C_obs 增量 × 100。种子沿用 EXP3b 的 `derived_seed(scene, start, t + 1, "sample")`。
- **方法**：与室内相同的 6 个预测组（frozen / C / V2 × K4 / K1）和 U、Frontier，配置和种子规则相同，世界键 `T0|<状态>`。
- **脚本**：加 `--protocol O`，轨迹目录 `W/preprocessing/outdoor_traj`，输出 `W/fixed_state_out`。

## 5. 对照口径（报告时分别给出）
1. **相同覆盖区间**（主口径）：室内 157 个状态对室外状态，逐区间比较，按场景 / 房屋做聚类 bootstrap。
2. **相同观测帧数 t**：室内和室外都按 t 分档描述，不配对。
3. **相同物理 / 模型尺度**：室内每个模型单位约 0.75–1.6 m；室外 k = 4.4–33.7，即每个模型单位约 0.44–3.4 个 OBJ 单位，室外本身不是米制。这一口径只能定性讨论，并标明限制。
4. **二级分析**：Macarons++ 的"室内"场景（barts、sestino）与室外场景分开列出。
