## 3. 为什么 B2 在室外更好、E2 在室内更好
### 3.1 已证实的差异（事实）
1. **训练 / 评估输入密度不一致**【代码 + 报告】：
   - B2 的整个谱系都在 S10 上训练，评估却输入 D100，所以是**分布外输入**。粗网格 BAND 占比：室内 0.0085 → 0.0191（×2.2），室外 0.021 → 0.033（×1.6）（`T3/reports/T3_E1_GEOMETRY.md:35-41`）。
   - E2-D100 在 D100 上训练，训练与评估一致。
2. **监督集合不同**【报告】：E2-D100 只监督 D100 下仍为 UNKNOWN 的射线，y 在这个集合上重新参数化，HIT 目标更少（`E2_AUDIT.md:41-51`）。
3. **继续混合训练**【代码】：E2 在两个域上用 32 + 32 继续训练了 5k 步。损失按射线数加权，室内射线占多数（约 0.54）。
4. **选择规则**：B2 = ES 规则选出的 17.5k；E2 = 固定 5k。

**两个方向的 ΔAUC 的 CI 都包含 0**（`E2_G3_REPORT.md:29-39`；`E2_G12_REPORT.md:40-107`）。也就是说，“E2 室内更好、B2 室外更好”在 G3 上**都不显著**。

**报告原文给出的解释**【报告】：
- 室内：“全深度微调带来了一致、但幅度中等的闭环提升 … B2 的中期停滞消失 … 单纯多训练（E2-S10 − B0）也有 +0.025，因此全深度本身的贡献约为 +0.017”（`E2_G3_REPORT.md:79-82`）。停滞的 episode：B2 4 个，E2D 2 个。
- 室外：“两个微调组都不如冻结模型 … 与 Task 2 记录的‘混合微调对室外略有遗忘’一致”（:83-86）。Task 2 中 S-c ES 从 3.08 → 3.15（+2%）。
- G2：“在当前混合数据上继续微调，本身就对室外排序略有不利，D100 又放大了这一点。预测指标与排序指标在室外不一致”（`E2_G12_REPORT.md:91`）。室外候选分数常接近并列，少量错误排除即可翻转选择（E1.2）。
- `E2_G12_REPORT.md:104`：“Macarons++ 的排序随训练变长而变差”。step 1k 时 Dev-3 本可以通过 G2。

### 3.3 尚未验证的假设（不能当结论）
- **H1（室外遗忘）**：在以室内射线为主的混合损失上继续训练，导致室外排序漂移。支持证据：没有密度变化的 E2-S10 室外也下降了（−0.010）。
- **H2（并列放大）**：D100 重标签减少了 HIT 目标，降低了 spread–error 相关（MP3D 0.424 → 0.377，Dev-3 0.357 → 0.328）。在室外分数接近并列的情况下，MAE 变好，排序却变差。
- **H3（室内修复更多）**：B2 室内的密度失配更大（×2.2 vs ×1.6），所以 D100 微调在室内能修复得更多。
- **H4（噪声）**：只有 5 个楼层、6 个场景，单次运行，CI 都包含 0；相当一部分差异可能是噪声。
- **H5（checkpoint 时机）**：固定在 5k 有影响；1k 时室外排序更接近 B2。

**结论**：
- **目前不存在与 B2 只差架构的干净对比**。每一对 V3+ / V4 / V5 vs B2 至少混淆了四个因素：初始化与预算、域配比、输入密度（以及由此变化的标签集合）、选择规则。
- **比较接近干净的配对**：
  - V3-T1 vs V3-T0：只差交叉注意力；
  - V3.1 vs V3-T0：只差数据域；
  - V5 vs V4C：同父模型、同数据、同步数，但 V5 多了损失项，新模块的 LR 也不同；
  - V4C vs V4：只差继续训练。
- **缺少 U0**（V2 架构 + D100 + 40k + 只室外，不加交叉注意力），所以 V4 的 RayXAttn 效应无法单独隔离（`X4/FROZEN_PROTOCOL.md:52` 已指出）。
